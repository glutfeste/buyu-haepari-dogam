# 잔다라·세계일주 개편 실행 체크리스트

> 상태: **실행 중**
>
> 최우선: **잔다라 갈대해파리 → 첫그물 → 진화론/장기 기록 → 새 등기 전용**
>
> 후순위: 현초의 정확한 편 번호와 전체 세계일주 세부 항로. 이 배치는 작품 전체를 다시 보며 나중에 유동적으로 바꿀 수 있으며, 잔다라 핵심 작업의 블로커로 취급하지 않는다.
>
> 선행 아이디어 메모: [[잔다라·첫그물·세계일주 전개 개편 메모]]

## 작업 규칙

- [x] **중요도 순서로 작업한다.** 단순 번호·링크 불일치가 발견되어도 핵심 설정·전개보다 먼저 붙잡지 않는다.
- [x] 지리·선후관계를 말하기 전에 관련 정본 파일을 직접 확인한다. 기억이나 기존 지도만으로 추정하지 않는다.
- [x] 이번 개편에서 기존 지리 문서는 필요하면 개편 대상이다. 다만 사용자가 새로 확정한 지리 관계와 직접 확인된 사건 인과는 보존한다.
- [x] 브랜치를 만들지 않고 `main`에 직접 반영한다.
- [ ] 최종 단계에서는 `정본 설정 → 에피소드 → 인물/세력/생태 → 줄거리 → 투고 문서 → 원고` 순으로 전역 감사를 끝낸다.

# 1. 잔다라 핵심 — 고정 완료

## 1-1. 잔다라행의 연구 동기

- [x] 갈대해파리는 잔다라 특산종이 아니라 여러 부초의 물 많은 습지에 널리 퍼진 흔한 종이다.
- [x] 벡실리아 대학 자연사실에는 해도청·항구 자연사실에서 들어온 오래된 잔다라 유영체·기저판 표본이 있다.
- [x] 표본은 서로 다른 현지명으로 적혀 있지만 유영체의 막·촉수·접착세포와 생활사는 일반 갈대해파리와 잘 맞는다.
- [x] 이상한 것은 기저군체의 넓은 부착면, 두꺼운 점액·광물층, 성장 가장자리와 봉합 반응이다.
- [x] 오래된 표본은 채집 위치·수질·생식 기록이 불완전해 별종·지역형·분화 중 집단 중 어느 것인지 확정할 수 없다.
- [x] 넬라는 대학 재학 중 이 표본군을 본 적이 있고 도감 준비 노트에 번호·도해·측정값·현지명을 베껴 둔다.
- [x] 포르도레에서 다음 답사지를 정할 때 그 필사·인용 기록을 다시 보고 잔다라 현지 조사를 선택한다.
- [x] 넬라는 최신 진화론을 바탕으로 자연선택과 인위선택을 모두 가설로 검토한다.
- [x] 인간에게 식량·약재·섬유·연료·농업상의 이익이 거의 없고 수로에서는 오히려 성가시기 때문에 인위선택의 우선순위를 낮춘다.
- [x] 초기 가설은 `잔다라의 특수한 늪 환경이 같은 종의 집단을 다른 방향으로 밀고 있으며 종분화 전 단계일 수도 있다`이다.
- [x] 이 초기 판단은 당시 정보에서 합리적이며, 반전을 위해 넬라가 멍청하게 추리한 것으로 만들지 않는다.

## 1-2. 갈대해파리의 실제 생태와 첫그물 육종

- [x] 야생 갈대해파리의 기저군체도 수질·수위 변화에 반응해 얇은 광물성 층을 만든다.
- [x] 이 층은 미래의 계절이나 사건을 의도적으로 기록하는 기관이 아니라 부착면을 유지하는 생리 과정의 흔적이다.
- [x] 첫그물은 수백 년 동안 좋은 군체를 골라 다음 재배군으로 남기는 경험적 육종을 해 왔다.
- [x] 주 선택 목적은 **습지 기반시설의 결속과 닻점 안정**이다.
- [x] 넓은 기저군체가 갈대뿌리·진흙·수몰 목재를 묶어 침식을 줄인다.
- [x] 철목·석조 닻점과 거주망·현수로·기록망의 지지 기반을 안정시킨다.
- [x] 빠른 봉합은 수문 작업·부유물 충돌 뒤 기저군체가 통째로 벗겨지는 것을 줄인다.
- [x] 수분 유지와 화재 확산 지연은 중요한 부가효과다.
- [x] 수문을 지나치게 막거나 뿌리에 피해를 주거나 회복이 느린 계통은 폐기한다.
- [x] 잔다라 재배계통은 야생형과 같은 종이며 생식적 단절이 없다.
- [x] 수문층의 두께·연속성도 이 장기 선발 과정에서 함께 강화된 부산물이다.

## 1-3. 수문층의 인과

- [x] 첫그물이 갈대해파리를 **등기용으로 육종한 것이 아니다.**
- [x] 옛 아라와트 맹약에도 갈대해파리 등록지나 층판 등기 절차가 없었다.
- [x] 옛 맹약은 인간 문서·수위표·측량 자료와 첫그물 기록망으로 수문권·안전통행·관리 책임을 보존했다.
- [x] 넬라가 여러 갈대밭·수질표·수위표를 대조해 물의 유입 순서를 외부 조사자가 다시 읽을 수 있는 판독법으로 처음 체계화한다.
- [x] 절단·이식·소각·약품 파괴도 봉합층·방향 불일치·파괴면으로 흔적이 남는다.
- [x] 넬라의 첫 기저판 표본·수질표·사진 사본·판독 초고가 포획 전에 아쿠아 알타로 나간다.
- [x] 마량은 이 비가역성과 외부 표본을 이용해 `일행을 죽여도 포획과 수문 조작의 흔적은 지워지지 않는다`고 처형의 전제를 뒤집는다.
- [x] 마량이 아라와트 맹약의 **옛 권리 구조** 위에 넬라의 **새 생물학적 판독법**을 결합하여 현대 등록 제도를 발명한다.
- [x] 여덟 등록 갈대밭은 둘째 물길 협정에서 처음 지정된다.
- [x] 최종 인과는 `갈대해파리 생리 → 첫그물 장기 재배 → 넬라의 과학적 판독 → 마량의 법적 등기 전용`이다.

## 1-4. 09편의 1차 반전

- [x] 독자와 일행은 베라사 세늪민을 먼저 실제 인간 집단으로 믿는다.
- [x] 주장 인구에 비해 음식물·배설물·가축·기생충·어린이 흔적이 적다.
- [x] 대리인의 언어는 오래된 문서 문법과 지나치게 같고, 여러 사람이 같은 문장을 같은 순서로 반복한다.
- [x] 인간 손이 닿기 어려운 높이에 실·수지·진동 신호와 수문 조작 흔적이 이어진다.
- [x] 수문비버의 여러 댐에 동일한 시작 구조가 삽입되어 누군가 비버를 유도하고 있음을 보여 준다.
- [x] 갈대해파리 층판은 인간 취락 밖의 숨은 수문이 먼저 작동했음을 보여 준다.
- [x] **1차 반전은 숨은 수문 너머에서 대형 거미들이 기록망을 읽고 복제하는 모습을 직접 보고, 인간 부족이라고 믿었던 세늪민이 첫그물의 대외 위장이었다는 사실을 깨닫는 순간이다.**
- [x] 첫그물 정체를 알기 전에 첫그물이라는 이름과 진상을 선공개하지 않는다.
- [x] 이 순간 넬라는 `인간 외의 선택자` 가능성을 떠올릴 수 있지만, 아직 첫그물이 갈대해파리를 실제로 재배했다는 증거는 없다.
- [x] 정체를 본 뒤 퇴로가 닫히고 일행 전원과 보글이가 포로가 된다.

## 1-5. 10편의 2차 반전과 협정

- [x] 넬라가 첫그물을 문명이라고 정확히 설명하는 말은 협상 가능성을 열면서 동시에 `넬라는 외부에 우리 존재를 증명할 수 있다`는 처형론을 강화한다.
- [x] 마량은 넬라의 생물학을 갑자기 다 이해한 사람이 아니라 `해파리는 절반도 모르겠소. 등기는 알아들었지`라고 말할 수 있는 기록·법률 독해자로 유지한다.
- [x] **2차 반전은 죽여도 물의 흔적과 외부 표본을 지울 수 없다는 역전이다.**
- [x] 인간 사본과 첫그물 기록망을 합쳐 아라와트 맹약의 두 당사자, 여덟 물길, 관리 책임과 안전통행 권리를 복원한다.
- [x] 옛 조약의 복원과 새 갈대해파리 등록 발명을 분리한다.
- [x] 사라크와 세르마가 실제 협상 당사자로 권리·위험·비밀 공개 범위를 조정한다.
- [x] 둘째 물길 협정이 새 여덟 등록 갈대밭을 만든다.
- [x] 일행 전원의 안전통행을 새 제도의 첫 등록으로 삼는다.

## 1-6. 해파리 기록관과 3차 생물학적 반전

- [x] 별도 정본 인물 [[베라사 해파리 기록관]]을 만들었다.
- [x] 기록관은 성체 암컷 잔다라매듭거미다.
- [x] 개인 이름은 아직 정하지 않고 직책·역할만 확정했다.
- [x] 정치 대표나 석방 협상자가 아니다.
- [x] 석방과 제한 교류가 이미 승인된 뒤 `조건은 아닌데 꼭 만나고 싶어 한다`는 개인 요청으로 넬라와 만난다.
- [x] 기록관이 수백 년을 산 것이 아니다. 선대 기록관들의 기록망을 계승하여 같은 재배계통을 여러 세대에 걸쳐 읽는다.
- [x] 원하는 군체를 남기고 나쁜 군체를 폐기하는 경험적 육종을 정확히 이해한다.
- [x] 최신 진화론은 모른다.
- [x] 그 무지는 지능 부족이 아니라 첫그물의 장기 은폐와 외부 학술망 단절 때문에 생긴 지식 유통의 한계다.
- [x] 넬라는 자연선택·인위선택·집단 변화라는 최신 이론과 여러 부초의 비교표본을 제공한다.
- [x] 기록관은 수백 년의 재배계통·선발 이유·형질 변화라는 시간축을 제공한다.
- [x] 둘의 관계는 `가르치는 넬라 / 배우는 거미`가 아니라 **넓게 보는 연구자 / 오래 보는 연구자**의 상호 교환이다.
- [x] **3차 생물학적 반전은 잔다라 특이형이 자연적으로 갈라진 새 종이 아니라 첫그물이 장기 인위선택한 같은 갈대해파리 재배계통이었다는 확정이다.**
- [x] 넬라의 초기 관찰은 `집단이 실제로 다른 방향으로 변화했다`는 점에서는 맞고, 선택압의 주체를 자연환경으로 본 점이 수정된다.

## 1-7. 첫그물의 일상과 아기거미

- [x] 포획·재판 뒤 제한 교류 구간에서 알방·먹이 저장망·수지 작업장·자연기록 구역·갈대해파리 재배지를 본다.
- [x] 어린 거미들이 짧은 실과 나무틀로 기본 매듭·진동 신호를 배우는 생활상이 있다.
- [x] 어린 거미들이 `그거 뭐예요?`, `먹어도 돼요?`라고 넬라의 표본·장비를 묻는다.
- [x] 한 어린 거미가 보글이를 먹는 생물이냐고 묻고, 넬라가 **같이 여행하는 동료**라고 바로 설명한다.
- [x] 보글이 인물 문서에도 이 장면을 반영했다.
- [x] 이 장면은 첫그물을 희화화하지 않고 `위협적인 숨은 세력`에서 `아이와 연구자와 생활이 있는 사회`로 시야를 넓힌다.

## 1-8. 도감으로의 회수

- [x] 『[[부유 해파리 도감(저서)|부유 해파리 도감]]』의 갈대해파리 항목에 야생형과 잔다라 재배계통을 같은 종 안에서 구분한다.
- [x] 대학의 오래된 잔다라 표본, 넬라의 현장 표본·수질표, 첫그물의 장기 재배자료가 결론의 서로 다른 근거로 기록된다.
- [x] 첫그물의 수도 좌표·군사 수문·기록망 부호 등 제한 정보는 공개 도감에서 제외한다.
- [x] 기록관이 제공한 장기자료와 넬라의 비교자료가 함께 결론을 만들었다는 출처를 남긴다.
- [x] [[후일담 첫 인쇄본]]에서 넬라가 약속한 저자 증정본 한 권을 둘째 물길 협정의 지정 교류 경로로 베라사 해파리 기록관에게 보낸다.
- [x] 이 부탁은 넬라가 도감을 만드는 새 동기가 아니라 이미 가진 목표에 생긴 뜻밖의 독자·동료 연구자의 회수다.

# 3. 세계일주 순서 — 후순위·가변

> 이 단계를 잔다라 핵심의 완료 조건으로 사용하지 않는다.

현재 작업본의 편 번호는 다음과 같지만 **현초의 정확한 위치는 다시 바꿀 수 있다.**

`09 잔다라 1부 → 10 잔다라 2부 → 11 코룬 → 12 자마르 → 13 유랑방주 → 14 현초 → 15 탈라푸람 → 16 메루아 → 17 임모타 → 18 하늘길 → 19 골롬트 → 20 스톨`

### 바꾸더라도 지켜야 할 확인된 관계

- [x] 현초는 잔다라 인근권이다.
- [x] 잔다라에서 발흥한 옛 세력이 현초를 정복할 수 있었던 거리권이다.
- [x] 코룬과 자마르는 같은 [[아비도라]] 부초다.
- [x] 코룬과 자마르 사이에 다른 부초의 독립 에피소드를 넣지 않는다.
- [x] 자마르에서 받은 [[응화]] 때문에 `자마르 → 유랑방주`는 직접 이어진다.
- [x] `하늘길 → 골롬트`는 대칸의 오르다 권역 안에서 직접 이어지는 하나의 연쇄다.
- [x] 스톨은 아우렐리아 부초의 후반 구간이다.
- [ ] 현초의 최종 편 번호는 전체 리듬을 다시 볼 때 결정한다.
- [ ] 현초를 움직이면 파일명·앞선 편·이어지는 편·지리·줄거리·인물 링크를 그때 전역 동기화한다.
