# A. 이번 개편의 고정 방향

## A-1. 잔다라행의 연구 동기

- [ ] 갈대해파리는 여러 부초의 물 많은 습지에 널리 퍼진 **흔한 종**으로 유지한다.
- [ ] 잔다라 깊은 늪에서 전해진 표본/기록에는 갈대해파리와 매우 닮았지만 특정 기관·기저군체 형질이 비정상적으로 발달한 집단이 존재한다.
- [ ] 넬라는 이 집단이 별종인지, 지역 변이인지, 종분화로 향하는 집단인지 확인하기 위해 잔다라에 간다.
- [ ] 넬라는 자연선택과 인위선택을 모두 가설로 생각하지만, **인간에게 쓸모가 거의 없다는 이유로 인위선택 가설을 처음에는 낮게 평가한다.**
- [ ] 넬라의 초기 판단은 당시 정보에 비추어 합리적으로 보이게 한다. `틀리기 위해 일부러 멍청한 추리`를 하게 만들지 않는다.

## A-2. 잔다라 갈대해파리의 진상

- [ ] 잔다라의 특이 집단은 별도 종이 아니라 **첫그물이 오랜 세월 인위선택해 온 갈대해파리 재배계통**으로 확정한다.
- [ ] 야생형과 교배/계통상 같은 종이지만 여러 세대의 선택으로 특정 형질이 크게 발달한 상태로 정리한다.
- [ ] 첫그물은 진화론을 몰라도 경험적으로 좋은 군체를 골라 남기고 나쁜 군체를 폐기하는 재배·육종 기술을 갖고 있다.
- [ ] 육종 목적은 인간의 식량·농업 효율이 아니라 **첫그물의 늪·실·철목 기반 생활에 유용한 생태공학적 기능**이어야 한다.
- [ ] 현재 우선안: 기저군체가 갈대뿌리·수몰 목재·진흙을 결속해 침식과 붕괴를 줄이는 `습지/닻점 안정화`를 주기능으로 검토한다.
- [ ] 현재 우선안: 많은 수분을 머금어 실·목질 구조 주변의 불 확산을 늦추는 `화재 억제`를 중요한 부가효과로 검토한다.
- [ ] 최종 육종 목적을 확정하기 전에 첫그물의 기존 도시 구조·수문 운용·화재 취약성과 충돌하지 않는지 확인한다.

## A-3. 수문층의 의미

- [ ] 수문층은 자연적으로 `등기를 위해 진화한 기관`이 아니다.
- [ ] 수문층은 첫그물이 `등기를 위해 의도적으로 육종한 기관`도 아니다.
- [ ] 첫그물이 습지 안정화 등에 유리한 생리 형질을 골라 온 결과, 물의 성분과 유입 순서가 광물성 층에 남는 성질이 과발달한 것으로 정리한다.
- [ ] 넬라가 이 부산물을 **수문 조작의 순서를 판독할 수 있는 생물학적 기록**으로 처음 해석한다.
- [ ] 마량이 그 판독법을 **협정 이행을 검증하는 살아 있는 등록/등기 장치**로 법적 전용한다.
- [ ] 의미의 단계가 `생리 → 첫그물의 재배 → 넬라의 과학적 판독 → 마량의 법적 전용` 순서로 보이게 한다.

## A-4. 첫그물 에피소드의 반전 순서

- [ ] 1차 반전은 반드시 **인간 집단이라고 생각했던 베라사 세늪민의 실체가 지능 거미 문명 첫그물의 대외 위장이었다**는 정체 폭로다.
- [ ] 첫그물 정체 공개 전에는 인간 취락의 생활 흔적, 오래된 문서 문법, 반복되는 대사, 인간이 닿기 힘든 실·진동 신호 등 미스터리 단서를 쌓는다.
- [ ] 정체를 본 뒤에야 일행이 포획되고 처형 여부가 논의된다.
- [ ] 넬라의 `문명이니 협상 가능하다`는 설명이 오히려 `이 인간은 우리 존재를 증명할 수 있다`는 판단을 강화해 처형론이 세지는 역설을 유지한다.
- [ ] 2차 반전은 **첫그물이 일행을 죽여도 갈대해파리 수문층과 외부 표본 때문에 활동 흔적을 지울 수 없다**는 마량의 역전이다.
- [ ] 아라와트 맹약의 두 당사자와 공동 수문권을 복원하고, 세르마·사라크가 실제 당사자로 협상하는 구조를 유지한다.
- [ ] 일행 전원의 안전한 귀환을 둘째 물길 협정의 첫 등록으로 삼는 구조를 유지한다.
- [ ] 협정/석방 결정 뒤 첫그물 내부를 둘러보며 **3차 발견: 특이 갈대해파리가 첫그물의 재배계통**이었다는 진상이 완성되게 한다.

## A-5. 진화론의 시대적 위치

- [ ] 진화론은 세계의 상식이 아니다.
- [ ] 넬라가 대학에 다니던 바로 그 시기에 등장한 **학문 최전선의 최신 이론**으로 정리한다.
- [ ] 생물학자·자연학자 사이에서도 아직 널리 합의된 정설이 아니라 논쟁 중인 가설/이론으로 취급한다.
- [ ] 최근 100년 안팎에 장거리 교통·통신·표본 교환이 급격히 발달하며 서로 먼 부초의 생물을 비교할 수 있게 된 것이 이 이론의 등장 배경과 맞물리게 한다.
- [ ] 넬라는 최신 이론을 배웠지만 모든 생물의 진화사를 이미 아는 사람처럼 쓰지 않는다.
- [ ] 첫그물의 해파리 연구자는 장기간의 재배·계통 기록을 갖고 있지만 **자연선택/인위선택을 일반 생물학 원리로 묶는 진화론 개념은 모른다.**
- [ ] 이 차이를 거미 연구자의 지능 부족으로 묘사하지 않고, 서로 고립된 학문 전통과 지식 유통의 한계로 묘사한다.

## A-6. 첫그물 해파리 연구자와 지식 교환

- [ ] 첫그물 내부에 해파리를 유난히 좋아하고 오래 연구한 자연학자/연구자를 둔다. 이름·직책은 정본화 단계에서 결정한다.
- [ ] 이 인물은 일행 석방의 협상 카드가 아니다. **석방/교류가 이미 결정된 뒤 개인적으로 넬라를 만나고 싶어 한 사람**이다.
- [ ] 거미 연구자는 수백 년짜리 갈대해파리 재배계통·표본·선발 기록을 넬라에게 보여준다.
- [ ] 넬라는 거미 연구자에게 최신 진화론과 선택의 일반 원리를 간단히 설명한다.
- [ ] 거미 연구자는 그 이론을 통해 자기 문명이 해 온 재배가 세대에 걸쳐 집단 형질을 바꾸었다는 의미를 새로 이해한다.
- [ ] 넬라는 반대로 거미의 장기 계통기록을 통해 최신 이론을 실제 수백 년 자료에 대조하는 경험을 얻는다.
- [ ] 둘의 관계는 `넬라가 무지한 거미를 가르친다`가 아니라 **넬라는 넓게 보고, 거미 연구자는 오래 보며 서로의 빈칸을 채우는 동료 연구자**로 만든다.
- [ ] 거미 연구자는 세계를 자유롭게 돌아다닐 수 없기 때문에 넬라의 도감 완성을 진심으로 기대한다. 이것이 넬라가 도감을 만드는 새 동기가 되지는 않는다.

## A-7. 첫그물의 일상과 아기거미

- [ ] 협정 뒤 첫그물 내부를 처음 편하게 둘러보는 장면을 둔다.
- [ ] 알방, 기록망, 수지 저장실, 갈대해파리 재배지, 어린 거미의 교육/생활 등 `숨은 괴물 기지`가 아니라 실제 생활 세계임을 보여준다.
- [ ] 호기심 많은 아기거미들이 넬라의 표본·장비·보글이에 관심을 갖는 짧은 장면을 넣는다.
- [ ] `그거 뭐예요?`, `먹어도 돼요?` 같은 어린 개체의 질문으로 앞선 포획/재판의 긴장을 풀되, 첫그물을 희화화하지 않는다.
- [ ] 보글이와 아기거미의 반응도 활용할 수 있다. 보글이를 먹이/표본으로만 취급하지 않고 동료 개체라는 현재 정본과 맞춘다.

## A-8. 세계일주 순서

- [ ] `잔다라에서 마량 합류 → 바로 현초에서 마량 개인서사 해결`의 현재 순서를 폐기하는 방향으로 진행한다.
- [ ] 잔다라 다음에는 아비도라/코룬 방면을 우선 검토해 **요런을 먼저 합류시키고 벨테린을 일찍 획득**한다.
- [ ] 벨테린 획득은 작은 초반 비행선에서 본격적인 세계일주선으로 넘어가는 구조적 전환점으로 삼는다.
- [ ] 마량은 합류 후 여러 지역을 함께 여행하며 독자가 말투·기록 습관·권력 풍자·과거 회피에 익숙해지도록 한다.
- [ ] 현초 개인서사는 충분한 축적 뒤로 미룬다.
- [ ] 현초의 최종 위치는 아직 확정하지 않는다. 메루아/임모타 이후 하늘길 전후를 우선 후보로 두고, 지리·감정축·보레아 장기선과 함께 비교한다.

## A-9. 독자 노출 용어: `비행선` / 기술 용어: `양소`

- [ ] **양소와 양소 기낭 설정 자체는 삭제하지 않는다.** 세계관의 비행 원리는 유지한다.
- [ ] 서술·대화에서 독자가 탈것을 이해하기 위해 굳이 기술 분류를 알아야 하지 않는 경우 기본 호칭은 `비행선`, `배`, `소형 비행선`, `수송선` 등으로 쓴다.
- [ ] 초기 원고에서 `양소선`이라는 생소한 분류명을 독자에게 먼저 가르치거나 반복 설명하지 않는다.
- [ ] `양소선`이 단순 탈것 이름으로 쓰인 곳은 전역 검토 후 자연스러운 `비행선/배`로 바꾼다.
- [ ] 기술 문서·기관사 업무·기낭 정비·선박 구조처럼 **양소라는 물질/기낭의 실제 기능이 장면의 핵심일 때만 기술 용어를 사용**한다.
- [ ] 양소 원리는 요런이 합류하고 벨테린을 정비·개장하는 에피소드에서 행동과 정비를 통해 자연스럽게 처음 깊게 보여주는 방향으로 설계한다.
- [ ] `부초 위에서는 양소 기낭이 비행에 필수적이고, 대양 공역에서는 양소 기낭이 보조 부양 장치로 작동한다`는 새 운용 방향을 기존 비행선/부상석/대양 설정과 대조해 정확한 정본 문장으로 확정한다.
- [ ] 위 차이를 설명하기 위해 새 물리 법칙을 즉흥적으로 발명하지 않는다. 기존 세계 설정과 충돌 여부를 먼저 확인한다.
- [ ] 독자가 앞부분에서 알아야 하는 것은 `이것은 하늘을 나는 배다` 정도로 충분하다는 원칙을 원고 전반에 적용한다.

# B. 실행 단계

## 0단계 — 현재 영향 범위 지도 만들기

- [ ] 현재 `main` 기준으로 갈대해파리, 첫그물, 베라사, 둘째 물길 협정, 진화/분류, 비행선/양소선, 코룬, 현초, 마량, 요런, 벨테린 관련 정본 파일을 목록화한다.
- [ ] `갈대해파리`의 현재 `계절을 판정하도록 진화했다` 설명과 새 인위선택 설정이 충돌하는 모든 참조를 찾는다.
- [ ] 첫그물 문서에서 갈대해파리 재배/습지 관리와 연결될 수 있는 기존 생활·수문·화재 취약 설정을 추적한다.
- [ ] 현재 에피소드 09·10·11·12 및 전체 줄거리에서 `잔다라 → 현초 → 코룬` 순서에 의존하는 문장을 목록화한다.
- [ ] 인물 문서에서 마량이 `합류 직후 현초`를 전제로 하는 부분과 요런/벨테린 획득 시점을 전제로 하는 부분을 목록화한다.
- [ ] 원고/전개/설정 전체에서 독자 노출 용어 `양소선`의 사용처를 검색하고 `단순 탈것 호칭 / 기술적으로 필요한 용례 / 법적·설정상 분류명`으로 나눈다.
- [ ] 코드 검색 인덱스만 믿지 말고, 이미 알려진 파일과 디렉터리를 직접 확인한다.

### 0단계 종료 조건

- [ ] 영향 파일 목록이 체크리스트에 추가되어 있고, 어떤 파일을 왜 바꿔야 하는지 설명할 수 있다.

## 1단계 — 진화론·자연학 지식사 정본화

- [ ] 진화론을 어느 설정 문서에 둘지 결정한다. 기존 자연분류/학문 문서에 통합할지 별도 문서를 만들지 검토한다.
- [ ] 넬라 대학 재학 시기 등장한 최신 이론이라는 연대·인지 범위를 정본화한다.
- [ ] 일반인, 전통 자연학자, 대학 생물학자, 넬라의 지식 수준을 구분한다.
- [ ] 장거리 교통·통신·표본 교환 발달과 비교생물학의 발전을 세계사와 맞춘다.
- [ ] 넬라 인물 문서에 최신 분류학/진화론을 접한 젊은 연구자라는 범위를 필요한 만큼 반영한다.
- [ ] 이후 어떤 인물이 진화론을 자연스럽게 알고 말해도 되는지 지식 타임라인을 점검한다.

### 1단계 종료 조건

- [ ] 첫그물 연구자가 진화론을 모르는 것이 설정상 자연스럽고, 넬라가 아는 것도 시대상 자연스럽다.

## 2단계 — 갈대해파리 생태 전면 개편

- [ ] 갈대해파리가 여러 부초에 널리 퍼진 종이라는 기본 분포를 확정한다.
- [ ] 야생형의 기본 기저군체·생활사와 잔다라 재배계통의 과발달 형질을 구분한다.
- [ ] 첫그물의 육종 주기능을 최종 결정한다.
- [ ] 화재 억제, 습지 결속, 닻점 안정, 수분 유지 등 부가기능의 인과를 정리한다.
- [ ] 인간에게는 경제적 가치가 낮거나 농경/수로 관리에 불편하다는 점을 구체화한다.
- [ ] 넬라가 표본만 보고 `다른 종일 수도 있다 / 분화 중일 수도 있다`고 의심할 형질을 정한다.
- [ ] 넬라가 인위선택 가설을 잠정 기각할 근거를 장면에서 사용할 수 있게 정리한다.
- [ ] 기존 `계절 판정 목적으로 자연 진화` 서술을 제거하거나 새 체계와 양립하도록 전면 수정한다.
- [ ] 수문층의 비가역성·훼손 흔적·외부 표본 대조라는 기존 법적 회수는 보존한다.

### 2단계 종료 조건

- [ ] 갈대해파리의 `야생형 / 잔다라 재배계통 / 수문층 / 첫그물 이용 / 넬라의 오판`을 한 설명 안에서 모순 없이 말할 수 있다.

## 3단계 — 첫그물 사회와 해파리 재배 정본화

- [ ] 첫그물 세력 문서에 갈대해파리 재배지가 생활 인프라에서 맡는 역할을 반영한다.
- [ ] 수문직조자·기록관·장력관 등 기존 직무 중 누가 재배를 담당하는지, 별도 직군이 필요한지 결정한다.
- [ ] 해파리 연구자의 직책·이름·전문 영역을 정한다.
- [ ] 연구자가 보존한 수백 년짜리 계통자료의 매체를 첫그물 기록망 문화에 맞게 설계한다.
- [ ] 연구자가 직접 세계 답사를 못 하는 사회적·물리적 이유를 과장 없이 설정한다.
- [ ] 어린 거미의 생활/교육과 연구실 출입이 기존 첫그물 사회 구조에 맞는지 반영한다.
- [ ] 첫그물의 화재 취약성과 갈대해파리의 화재 억제 기능을 채택할 경우 군사/생활 설정과 동기화한다.

### 3단계 종료 조건

- [ ] 첫그물이 왜 이 해파리를 수백 년 길렀는지, 누가 관리했는지, 어떻게 기록했는지 답할 수 있다.

## 4단계 — 잔다라/첫그물 에피소드 09·10 재설계

- [ ] 아쿠아 알타에 도착한 넬라가 이미 `잔다라 특이 갈대해파리`를 찾아온 명확한 연구 목적을 갖게 한다.
- [ ] 현지 표본/진술과 실제 조사 사이의 차이를 단계적으로 보여준다.
- [ ] 베라사 세늪민을 인간 집단이라고 믿게 하는 정보와, 그 믿음을 흔드는 단서를 배치한다.
- [ ] 첫그물 정체 폭로를 1차 반전으로 충분히 살린다.
- [ ] 포획 이후 넬라의 설명이 오히려 처형론을 세게 하는 역설을 유지한다.
- [ ] 마량의 2차 역전에서 넬라의 외부 표본/판독 자료와 비가역적 수문층이 모두 필요하게 한다.
- [ ] 마량이 생물학 자체를 갑자기 전문가처럼 이해하지 않고, 넬라의 설명에서 `기록/등기`로 전환 가능한 부분을 정확히 기억한 사람으로 쓴다.
- [ ] 아라와트 맹약 복원과 세르마·사라크의 실질 협상을 유지한다.
- [ ] 일행 생환을 첫 등록으로 삼는 결착을 유지한다.
- [ ] 석방 이후 첫그물 내부 탐방을 배치한다.
- [ ] 해파리 연구자와 넬라의 학술 교환에서 3차 발견인 재배계통 진상을 밝힌다.
- [ ] 넬라가 진화론을 설명하고 거미 연구자가 장기 재배기록을 제공하면서 양쪽 모두 새로 깨닫는 구조를 만든다.
- [ ] 아기거미와 보글이 장면을 긴장 해소와 첫그물 생활상 공개에 사용한다.
- [ ] 에피소드가 `정치 협정 이야기`로만 끝나지 않고 **처음의 해파리 질문에 답하면서 닫히는지** 확인한다.

### 4단계 종료 조건

- [ ] 09·10을 요약했을 때 `해파리 미스터리 → 인간인 줄 알았던 이들이 거미 → 죽여도 흔적은 남음 → 협정 → 재배계통 진상과 학술 교류`가 자연스럽게 이어진다.

## 5단계 — 잔다라 이후 항로와 현초 위치 결정

- [ ] 잔다라 다음에 코룬으로 가는 지리·연료·항로상 개연성을 확인한다.
- [ ] 기존 소형 비행선이 코룬 즈음 수명을 다하는 흐름이 23화까지의 손상/성능과 잘 이어지는지 확인한다.
- [ ] 요런과 벨테린을 이 시점에 얻을 때 이후 각 지역 에피소드의 배 성능·정비·승선 인원과 충돌하지 않는지 확인한다.
- [ ] 마량의 현초행을 어디까지 미룰지 후보를 2~3개 비교한다.
- [ ] 후보마다 `독자가 마량에게 익숙해지는 시간 / 지리적 동선 / 마량의 감정 축적 / 보레아 장기선 간섭 / 세계일주 완성 시점`을 비교한다.
- [ ] 현초 최종 위치를 결정한 뒤에만 에피소드 순서를 확정한다.

### 5단계 종료 조건

- [ ] 새 전체 여행 순서를 번호 없이 장소/사건 순서로 한 줄로 적을 수 있고, 각 이동 이유가 설명된다.

## 6단계 — 코룬·요런·벨테린 개편

- [ ] 요런이 더 일찍 합류해도 개인서사의 핵심 `에티엔의 사적 종복 → 자기 판단으로 명령 거부 → 자기 과거를 직접 찾기로 함`이 약해지지 않게 한다.
- [ ] 벨테린 조기 획득이 요런의 선택과 연결되게 한다.
- [ ] 벨테린이 본격 세계일주가 가능한 튼튼한 배라는 인상을 실제 항해/정비 장면으로 보여준다.
- [ ] 이 에피소드에서 비행선 구조·기낭·양소 운용을 요런의 실무를 통해 처음 자연스럽게 깊게 보여준다.
- [ ] 독자에게 기술 교과서처럼 설명하지 않고 고장·수리·개장·적재·부양 조정 속에서 기능을 이해시키게 한다.
- [ ] `부초 위 / 대양 공역`에서 양소 기낭 역할 차이를 기존 세계 설정과 정합시킨다.

### 6단계 종료 조건

- [ ] 독자는 `양소선`이라는 분류명을 외우지 않아도 벨테린이 어떻게 나는 배인지 장면으로 이해할 수 있다.

## 7단계 — 마량 장기 동행과 현초 회수

- [ ] 현초에 가기 전 여러 에피소드에서 마량의 말투·기록 습관·문헌 독해·풍자 감각을 자연스럽게 축적한다.
- [ ] 마량이 특정 글자/아버지 이야기를 피하는 습관을 너무 노골적인 떡밥 표시 없이 반복한다.
- [ ] 다른 사람의 역사와 기록에는 날카롭지만 자기 과거는 피해 다니는 모순을 장기적으로 보여준다.
- [ ] 현초 에피소드가 왔을 때 독자가 마량을 충분히 알고 있어 과거 공개의 감정 무게가 커지는지 확인한다.
- [ ] 현초 이동으로 인해 먹물해파리·흑수왕터·마원의 제단 관련 생태/지리 설정이 끊기지 않게 한다.

## 8단계 — 에피소드 번호 재배치

> **잠금:** 1~7단계가 완료되기 전에는 시작하지 않는다.

- [ ] 확정된 장소/사건 순서에 따라 에피소드 번호를 새로 배정한다.
- [ ] 파일명을 이동/변경한다.
- [ ] 각 에피소드의 `순서`, `앞선 편`, `이어지는 편` 메타데이터를 갱신한다.
- [ ] 인물·생태·세력·지리 문서의 에피소드 링크를 전역 동기화한다.
- [ ] 삭제된 옛 번호 링크가 남지 않았는지 직접 확인한다.
- [ ] `줄거리.md`의 전체 차례를 새 순서로 갱신한다.

### 8단계 종료 조건

- [ ] 같은 사건이 두 번호로 남거나, 옛 번호가 살아 있는 링크가 없다.

## 9단계 — 독자 노출 `양소선` 전역 감사

- [ ] 현재 원고 01화부터 최신 원고까지 `양소선` 및 양소 기낭 설명을 전부 점검한다.
- [ ] 독자가 기술 분류를 알 필요 없는 문장은 `비행선 / 배 / 소형 비행선 / 수송선`으로 바꾼다.
- [ ] 인물 대사에서 일반인이 자연스럽게 `양소선`을 전문 분류명처럼 남발하지 않게 한다.
- [ ] 법적 문서·선박 등록·기관사 기술 대화 등 전문명이 실제로 필요한 경우만 남긴다.
- [ ] 설정 문서의 `양소선`은 기술 분류로 유지할지 `비행선` 문서 아래 하위 방식으로 재정리할지 결정한다.
- [ ] 원고 초반에서 양소의 물리·구조 설명을 삭제한 결과 장면 이해가 안 되는 부분이 없는지 읽는다.
- [ ] 요런/벨테린 에피소드에서 뒤늦은 설명이 `사실 앞부분에 꼭 필요했던 정보`처럼 보이지 않고 자연스러운 심화 정보로 기능하는지 확인한다.

### 9단계 종료 조건

- [ ] 초반 독자는 `하늘을 나는 배`만 이해하면 이야기를 따라갈 수 있고, 양소 기술을 몰라도 사건 인과를 놓치지 않는다.

## 10단계 — 후속 세계일주 에피소드 정합성 점검

- [ ] 자마르, 유랑방주, 탈라푸람, 메루아, 임모타, 하늘길, 골롬트, 스톨의 새 선후관계를 확인한다.
- [ ] 벨테린을 이미 보유한 상태가 각 에피소드의 선박/승선/정비 묘사와 충돌하지 않는지 수정한다.
- [ ] 현초 위치 변경으로 각 지역의 출발지·도착지·항로 설명을 조정한다.
- [ ] 마량이 현초 해결 전/후에 어떤 상태인지 각 에피소드에서 일관되게 유지한다.
- [ ] 보레아는 중반부터 모든 에피소드를 지배하는 전쟁선이 아니라 간헐적으로 침투하는 장기 위협으로 유지한다.
- [ ] 세계일주와 생태 탐사가 작품의 중반 본체라는 실제 비중을 보존한다.

## 11단계 — 인물/세력/생태 정본 동기화

- [ ] 넬라 베린디스: 잔다라행 동기, 최신 진화론 지식, 거미 연구자와의 학술 교환을 반영한다.
- [ ] 마량: 합류 뒤 장기 동행, 현초 해결 시점 변경, 첫그물에서의 역할을 반영한다.
- [ ] 요런 펠트만: 합류 시점과 벨테린 조기 획득을 반영한다.
- [ ] 아멜리 모렐: 새 항로 순서가 세계일주·항행 기록 목표와 충돌하지 않는지 확인한다.
- [ ] 테오도어 린트너: 벨테린 획득 시점과 계약 종료/재합류 시점이 새 순서에서도 맞는지 확인한다.
- [ ] 마르톤 케메니: 벤체·자마르·현초 이동 순서 변화가 개인 아크에 미치는 영향을 확인한다.
- [ ] 보글이: 첫그물 내부/아기거미 장면이 지능·행동 정본과 맞는지 확인한다.
- [ ] 첫그물: 재배 갈대해파리·해파리 연구자·어린 거미 생활상·협정 이후 교류를 반영한다.
- [ ] 갈대해파리: 새 생태/재배계통을 최종 정본으로 동기화한다.
- [ ] 둘째 물길 협정: 수문층이 `원래 등기 기관`이 아니라 사후 법적 전용이라는 인과를 명확히 한다.
- [ ] 비행선/양소/벨테린 관련 설정 문서: 독자 노출 정책과 기술 정본을 분리해 정리한다.

## 12단계 — 전체 줄거리와 투고 문서 재작성

> **잠금:** 앞 단계의 정본·번호·원고 동기화가 끝난 뒤에만 시작한다.

## 13단계 — 최종 전역 감사

- [ ] `갈대해파리 = 잔다라에서만 사는 특수종`처럼 옛 설정을 암시하는 문장이 남지 않았는지 확인한다.
- [ ] `수문층이 계절 판정을 위해 자연 진화했다`는 폐기 원인이 남지 않았는지 확인한다.
- [ ] `첫그물이 등기용으로 갈대해파리를 육종했다`는 잘못된 인과가 생기지 않았는지 확인한다.
- [ ] 첫그물 정체가 에피소드 서술에서 반전 전에 선공개되지 않는지 확인한다.
- [ ] 해파리 연구자가 진화론을 몰라서 멍청한 인물처럼 보이는 문장이 없는지 확인한다.
- [ ] 넬라가 진화론을 세계의 확정 상식처럼 말하는 장면이 없는지 확인한다.
- [ ] 마량이 생물학 전문가처럼 문제를 혼자 해결하는 구조가 없는지 확인한다.
- [ ] 첫그물 협정에서 세르마와 사라크의 실제 당사자 역할이 삭제되지 않았는지 확인한다.
- [ ] 현초가 옛 번호/옛 순서로 참조되는 문장이 없는지 확인한다.
- [ ] 벨테린 획득 전후의 선박 묘사가 모두 맞는지 확인한다.
- [ ] 원고 독자 노출에서 불필요한 `양소선` 용어와 초기 기술 설명이 남지 않았는지 확인한다.
- [ ] 기술 정본에서는 양소 설정이 실수로 삭제되거나 `비행선`과 모순되지 않았는지 확인한다.
- [ ] 투고 시놉시스가 중반 이후를 혁명전쟁 일변도로 과장하지 않고 세계일주/생태 탐사의 실제 비중을 반영하는지 확인한다.
- [ ] 모든 체크박스를 다시 훑고 미완료 항목이 0개인지 확인한다.
