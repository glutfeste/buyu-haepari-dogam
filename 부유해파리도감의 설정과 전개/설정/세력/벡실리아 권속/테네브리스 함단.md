# 테네브리스 함단

| 테네브리스 함단 ||
|---|---|
| 🏛️ **지위** | [[🤝 구성국]] |
| 🚩 **상태** | [[🟢 현존]] |
| 👑 **종주** | [[벡실리아 공화국]] |
| 🏙️ **수도** | 포르투스 테네브리스 |
| 👤 **지도자** | 함단장 |
| 🗺️ **지배 지역** | [[잔다라]] |

> 잔다라를 통일한 토착 연합이 벡실리아에 가맹해 성립한 함단.

## 성립

대택 멸망 뒤 잔다라로 돌아온 항해 집단들은 여러 부족과 항구로 나뉘어 살았다. 이 가운데 일부가 [[잔다라 무역회사]]와 군사·운송 협약을 맺고 부초의 항구와 수로를 통합했다. 통일 세력은 회사가 보유하던 선단, 창고, 계류장, 장부 조직과 대외 계약을 인수했다.

통일 세력은 벡실리아 기본협약에 가맹하여 테네브리스 함단(Classis Tenebris)을 세웠다. 회사의 직원과 용병은 함단의 행정관, 선원과 병사로 편입되었고, 회사의 특허와 법인격은 가맹과 함께 소멸했다.

## 통치

함단장(Praefectus Classis)이 잔다라의 항로, 항구, 습지 수로와 변경 방위를 통솔한다. 본거는 포르투스 테네브리스(Portus Tenebris, 약 5만)이며, 잔다라 전체 인구는 약 30만이다.

함단은 항해 집단과 정착 공동체의 대표를 행정에 참여시키고, 선단 운용과 수로 관리를 함단 관청에서 조정한다. 벡실리아의 대외 교역망을 이용하면서도 잔다라 안개의 항법, 철목 조선과 습지 토목을 자체적으로 운용한다.

## 현재의 잔다라

인구 증가와 항구 확장으로 경작지와 건축지가 넓어지고 있다. 함단 관청은 수로를 준설하고 습지를 개간하며 새 정착지를 배정한다. 댐을 짓는 대형 습지 동물과 개간지의 수위가 충돌하는 지역에서는 선단과 수리 인력이 동원된다.

이 정책과 그에 따른 분쟁은 테네브리스 함단의 행정에 속한다. 잔다라 무역회사는 함단 성립 이전의 기록에서만 등장한다.
