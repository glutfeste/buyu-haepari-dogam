# 테네브리스 함단

| 테네브리스 함단 ||
|---|---|
| 🏛️ **지위** | [[🤝 구성국]] |
| 🚩 **상태** | [[🟢 현존]] |
| 👑 **종주** | [[벡실리아 공화국]] |
| 🏙️ **수도** | 포르투스 테네브리스 |
| 👤 **지도자** | 함단장 |
| 🗺️ **지배 지역** | [[잔다라]] |

> 부초 잔다라의 변경을 관할한 벡실리아의 함단. 무역회사에서 함단으로 재편되었다.

테네브리스 함단(Classis Tenebris)은 [[벡실리아 공화국]]의 함단 가운데 하나로, 부초 [[잔다라]]의 변경을 관할한다. 본래 이 부초의 교역을 독점하던 특허회사 잔다라 무역회사(Societas Mercatoria Zandara)로 출발했고, 회사가 통치하던 땅과 선단이 공화국에 편입되며 함단으로 재편되었다. 함단장(Praefectus Classis)이 통솔하며, 본거는 항구 도시 포르투스 테네브리스(Portus Tenebris, 약 5만)다. 잔다라의 인구는 약 30만이다.
