# 벤다발 함단

| 벤다발 함단 ||
|---|---|
| 🏛️ **지위** | [[🤝 구성국]] |
| 🚩 **상태** | [[🟢 현존]] |
| 👑 **종주** | [[벡실리아 공화국]] |
| 🏙️ **수도** | 벤다발 |
| 👤 **지도자** | 함단장 |
| 🗺️ **지배 지역** | [[아이스투아리아]] |

> 옛 왕국이 공화국에 가맹해 이루어진 강력한 자치 함단. 벡실룸과 오래 다툰 역사가 있다.

벤다발 함단(Classis Vendaval)은 [[아이스투아리아]]의 함단으로, [[벡실리아 공화국]] 안에서 특히 강력한 자치 함단이다. 전신은 왕정을 이룬 선단 가문의 나라 [[벤다발 왕국]]으로, 벡실룸과 식민지를 두고 오래 다투었다. 내부 봉기로 왕정이 붕괴하고 공화정이 수립된 뒤, 투표를 거쳐 공화국에 가맹해 대등한 함단이 되었다. 경제력은 벡실룸과 포르타노바 다음이다. 중심 도시는 동명의 벤다발(약 11만)이다. 옛 왕국의 말과 전통을 보존하며 함단의 자치를 강하게 주장한다.

벤다발은 부초의 수직 가장자리를 따라 큰 비행선 [[항구]]를 갖추고 있다. 접안층이 절벽 위아래로 이어지고 대형 상선은 부초 영향권 밖의 난바다 공역에 떠 있는 채 선체 옆으로 접안한다. 절벽 안쪽의 화물 승강기와 창고가 각 층을 도시와 연결하며, 부상력이 처지는 선박을 붙들 보조 부상석과 양소 예인선도 상시 배치한다.

도시 안쪽에는 오렌투스 수계로 이어지는 강부두가 따로 있어, 비행선에서 내린 사람과 화물이 육상 통로와 승강기를 거쳐 강배로 갈아탈 수 있다. 외곽의 수직 비행선 항구와 수면을 따라 놓인 강부두가 한 도시에서 서로 다른 교통망을 잇는다.
