# 구문 분류

> 구문이 대상에 무엇을 하는지로 구분하는 값. 증폭·방출·관측·사역·변성·부여로 나뉜다.

구문 분류는 한 구문이 대상에 일으키는 작용으로 구분하는 값이다. 한 구문이 둘 이상의 분류에 속하기도 한다.

## 분류

| 분류 | 뜻 |
| --- | --- |
| [[💪 증폭]] | 대상이 보유한 물리량을 증대시킨다 |
| [[🔥 방출]] | 에너지와 물질을 생성하여 방출한다 |
| [[🔮 관측]] | 대상을 그대로 둔 채 상태를 판독한다 |
| [[🕹️ 사역]] | 신호를 기입하여 대상을 운용한다 |
| [[⚗️ 변성]] | 물질의 성질을 다른 성질로 변환한다 |
| [[💎 부여]] | 사물에 절차를 봉입하여 기물을 제작한다 |

## 이 분류의 구문

```dataview
TABLE WITHOUT ID file.link AS "구문", 분류 AS "분류"
WHERE 분류
SORT file.name
```
