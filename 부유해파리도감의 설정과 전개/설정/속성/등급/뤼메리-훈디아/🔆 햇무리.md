# 🔆 햇무리

두 왕관 훈장의 1등급(Couronne Solaire)이자 최고 등급. 여명을 받은 구문사가 그 위의 큰 공적을 세워야 오르며, 어깨에 큰 띠를 두르고 흉장을 패용한다. 지금 살아 있는 수훈자는 넷이다.

## 이 등급의 인물

```dataview
TABLE WITHOUT ID file.link AS "인물", 소속 AS "소속", 구문 AS "주요 구문"
WHERE contains(list(훈장), this.file.link)
SORT file.name
```
