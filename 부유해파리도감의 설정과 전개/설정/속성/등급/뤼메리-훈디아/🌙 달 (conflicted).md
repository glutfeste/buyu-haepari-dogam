# 🌙 달

두 왕관 훈장의 1등급(Lune)이자 최고 등급. 하늘에 달이 다섯이듯 정원이 다섯으로 고정되어, 결원이 발생해야 별 수훈자 가운데서 승급한다. 목에 경식장을 걸고 어깨에 큰 띠를 두른다. 지금 다섯 자리가 모두 차 있어, 세간이 그 수훈자들을 제국의 다섯 기사라 부른다.

## 이 등급의 인물

```dataview
TABLE WITHOUT ID file.link AS "인물", 소속 AS "소속", 구문 AS "주요 구문"
WHERE contains(list(훈장), this.file.link)
SORT file.name
```
