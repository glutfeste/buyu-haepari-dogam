# ☁️ 구름

두 왕관 훈장의 3등급(Nuage). 구문으로 공적을 세운 구문사가 처음 받는 등급이며, 가슴에 약장을 패용한다. 세 등급 가운데 수훈자가 가장 많다. 새 공적을 세우면 별 등급으로 승급한다.

## 이 등급의 인물

```dataview
TABLE WITHOUT ID file.link AS "인물", 소속 AS "소속", 구문 AS "주요 구문"
WHERE contains(list(훈장), this.file.link)
SORT file.name
```
