# 🌙 달

두 왕관 훈장의 1등급(Lune)이자 최고 등급. 정원은 하늘의 달과 같은 다섯으로, 결원이 발생해야 별 수훈자 가운데서 승급한다. 목에 경식장을 걸고 어깨에 큰 띠를 두른다. 세간은 달 수훈자들을 제국의 다섯 기사라 부른다.

## 이 등급의 인물

```dataview
TABLE WITHOUT ID file.link AS "인물", 소속 AS "소속", 구문 AS "주요 구문"
WHERE contains(list(훈장), this.file.link)
SORT file.name
```
