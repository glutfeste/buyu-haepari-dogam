# 🌟 별

두 왕관 훈장의 2등급(Étoile). 구름을 받은 구문사가 새 공적을 세우면 오르는 등급이며, 가슴에 흉장을 패용한다. 수훈자가 드물다. 다시 큰 공적을 세우면 달 등급으로 승급하되, 달은 정원이 다섯이라 결원이 있어야 오른다.

## 이 등급의 인물

```dataview
TABLE WITHOUT ID file.link AS "인물", 소속 AS "소속", 구문 AS "주요 구문"
WHERE contains(list(훈장), this.file.link)
SORT file.name
```
