# ⚙️ 육치륜

[[보레아 영구기관]]의 삼주축 아래에서 강적과 직접 싸우는 여섯 구문사다. 각자의 마법과 실전 능력이 임명의 기준이며, 침투·시설 방호·원정의 주요 교전을 수행한다.

## 재임과 승계

자히라와 골롬트 시기에는 [[발도]], [[루모]], [[아르민 델케시]], [[요제프 바우어]], [[베스나 라디치]], [[에밀로]]가 재임한다. 발도가 골롬트에서 죽은 뒤 [[마그누스 카르빌리우스]]가 그의 직위를 승계한다. 루모가 무질서축으로 승격한 뒤에는 [[클라라]]가 육치륜에 임명된다.

## 이 등급의 인물

```dataview
TABLE WITHOUT ID file.link AS "인물", 소속 AS "소속", 구문 AS "주요 구문"
WHERE contains(list(등급), this.file.link)
SORT file.name
```
