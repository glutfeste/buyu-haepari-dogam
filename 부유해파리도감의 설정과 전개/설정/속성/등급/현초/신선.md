# 신선

> 도술에서 최고 경지에 도달한 도사를 높여 부르는 민간의 구전 호칭.

신선은 도술([[도술]] 참고, 현초의 구문 전통)에서 최고 경지에 도달한 도사를 높여 부르는 민간의 호칭이다. 도사의 수련과 명성이 깊어져 문파와 마을 사람들이 그를 신선으로 추대할 때 그 호칭이 정착된다. 신선은 구전으로 전해지는 존칭이므로, 그 권위는 한 도사의 행적과 그를 따르는 사람들의 공통된 추존에서 비롯한다.

## 이 등급의 인물

```dataview
TABLE WITHOUT ID file.link AS "인물", 소속 AS "소속", 구문 AS "주요 구문"
WHERE contains(list(등급), this.file.link)
SORT file.name
```
