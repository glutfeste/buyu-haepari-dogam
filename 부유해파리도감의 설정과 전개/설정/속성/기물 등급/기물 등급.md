# 기물 등급

> 기물이 얼마나 드문지를 별 하나에서 다섯으로 매긴 등급. 같은 기물을 재현할 수 있는지와 현존하는 수로 구분한다. 일성(보급)에서 오성으로 오른다.

기물 등급은 [[구문]]으로 제작한 기물이 얼마나 드문지를 별 하나(일성)에서 다섯(오성)으로 매긴 값이다. 제작할 수 있는 구문사가 드물수록, 현존 수가 적을수록 별이 많다. 재현이 불가능한 기물의 값어치는 희소성과 전래 내력에서 비롯한다. 대부분의 기물은 일성(보급)에 속하여 등급 표기를 생략하고, 그 위로 [[이성]]·[[삼성]]·[[사성]]·[[오성]]을 표기한다.

## 등급

| 등급     | 뜻                          |
| ------ | -------------------------- |
| ★★ [[이성]] | 양산품을 솜씨로 능가한 기물. 동시대에 흔하다     |
| ★★★ [[삼성]] | 당대 최상급 구문사라야 제작하는 기물. 동시대에 수십 점 |
| ★★★★ [[사성]] | 제작할 구문사가 한 시대에 몇뿐인 기물. 그 시대에 몇 점만 현존     |
| ★★★★★ [[오성]] | 지금은 재현이 불가능한 기물. 여러 시대에 하나, 전설로 전한다    |

## 등급이 매겨진 기물

```dataview

WHERE 기물-등급
```
