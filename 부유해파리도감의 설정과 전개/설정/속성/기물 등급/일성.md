# 일성
> ★

**전술적 위력**

전장과 일상에서 기초 기능을 수행하는 보급형 표준 장비다. 규격화된 공정을 거쳐 제작되어 어디서나 균일한 성능을 발휘한다. 조작이 단순하여 갓 훈련을 마친 신병이나 일반 여행자도 짧은 연습으로 숙달한다. 다수를 무장시켜 부대의 기본 화력과 방어력을 구성하는 기간 장비로 운용된다.

**경제적 가치**

대량 생산되어 항구의 일반 상점과 거리의 좌판에 흔히 진열된다. 일반 노동자나 평범한 뱃사람도 약간의 여윳돈으로 구매하며, 상단은 선단 단위로 유통하여 꾸준한 수익을 얻는다. 부초 경제를 지탱하는 기초 소비재이며, 대량 거래로 시장 물가를 안정시키는 기준재가 된다.

**사회적 파장**

시민의 일상에 널리 보급되어 사회의 기본 편의를 증진한다. 평범한 사람들의 고된 노역을 경감하고 생활 수준을 높인다. 군대나 상단은 구성원에게 일괄 지급하여 조직의 소속감을 강화한다. 민간과 군부에 두루 퍼져 부초 전체의 기초 생활 양식을 구성한다.
