# 🌐 권역
부초 안을 크게 나눈 단위. 지리·문화·정치로 하나의 단위를 구성하는 큰 지방으로, 한 부초는 대개 여러 권역으로 나뉜다. 권역 아래에 지역과 도시가 속하며, 세력의 영토는 여러 권역에 걸치기도 한다.

## 이 구분의 지역

```dataview
TABLE WITHOUT ID file.link AS "지역", 상위-지역 AS "상위 지역", 지배-세력 AS "지배 세력"
WHERE contains(list(지리-구분), this.file.link)
SORT file.name
```
