# 지리 구분

> 지리 단위의 위계상 위치를 구분하는 값. 부초·권역·지역·도시·강으로 나뉜다.

## 구분

| 구분 | 뜻 |
| --- | --- |
| [[🪨 부초]] | 하늘에 떠 있는 대륙. 위계의 최상위 단위 |
| [[🌐 권역]] | 부초 안을 크게 나눈 단위 |
| [[🏞️ 지역]] | 권역보다 작은 중간 단위 |
| [[🏙️ 도시]] | 사람이 모여 사는 최하위 단위 |
