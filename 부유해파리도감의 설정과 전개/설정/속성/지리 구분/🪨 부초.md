# 🪨 부초
하늘에 떠 있는 대륙. 지리 위계의 최상위 단위이며, 세계의 육지는 모두 부초다. 한 부초 아래에 권역과 지역, 도시가 속한다. 부초 사이는 허공으로 이격되어 왕래가 하늘길에 의존한다.

## 이 구분의 지역

```dataview
TABLE WITHOUT ID file.link AS "지역", 상위-지역 AS "상위 지역", 지배-세력 AS "지배 세력"
WHERE contains(list(지리-구분), this.file.link)
SORT file.name
```
