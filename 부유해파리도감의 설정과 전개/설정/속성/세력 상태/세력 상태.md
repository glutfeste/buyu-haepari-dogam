# 세력 상태

> 세력이 작중 현재 시점에 실재하는지로 구분하는 값. 현존·멸망·계승됨·변환으로 나뉜다.

세력 상태는 한 세력이 이야기가 진행되는 시점에 이름과 정부, 영토를 유지하는지로 구분하는 값이다.

## 상태

| 상태 | 뜻 |
| --- | --- |
| [[🟢 현존]] | 작중 현재 시점에 활동하는 세력 |
| [[🔴 멸망]] | 후계 없이 완전히 소멸한 세력 |
| [[⚪ 계승됨·변환]] | 다른 세력으로 이어지거나 형태를 바꾼 세력 |

## 이 상태의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 지위 AS "지위"
WHERE 상태
SORT file.name
```
