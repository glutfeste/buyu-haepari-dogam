# ⚪ 계승됨·변환

다른 세력으로 계승되거나 형태를 변경하여, 그 이름으로는 소멸한 세력. 영토와 주민, 제도의 상당 부분이 후계 세력으로 이전된 경우를 가리킨다. 국호 변경이나 연합 편입, 왕조 교체 등이 이 상태에 해당한다.

## 이 상태의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 지위 AS "지위"
WHERE contains(list(상태), this.file.link)
SORT file.name
```
