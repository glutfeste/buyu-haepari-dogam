# 문헌 종류

> 문헌을 제정 주체와 성격에 따라 나눈 분류. 저서·조약·법령·문학으로 나뉜다.

한 문서에 두 종류를 함께 표기하기도 한다.

## 종류

| 종류 | 뜻 |
| --- | --- |
| [[📖 저서]] | 한 사람이 자기 이름으로 펴낸 저작 |
| [[📜 조약]] | 둘 이상의 세력이 맺은 약정 |
| [[⚖️ 법령]] | 주권자가 자기 영토와 백성에게 내린 규정 |
| [[📝 문학]] | 지은 이가 상상으로 지어낸 글 |

## 종류가 매겨진 문헌

```dataview
TABLE WITHOUT ID file.link AS "문헌", 문헌-종류 AS "종류"
WHERE 문헌-종류
SORT file.name
```
