# 꿰기

> 꿴 구슬을 매체로 하여 구문을 운용하는 [[오르다]]의 전통.

꿰기는 [[오르다]]의 [[구문]] 전통이다. 구문을 조상이 대대로 물려 꿰는 재산으로 인식하고, 구문을 운용하는 자를 꿰미꾼이라 부른다. 매체는 고래 뼈와 이빨을 깎아 꿴 구슬로, 구슬의 재질·형태·새김과 꿰는 순서가 구문을 이룬다. 장치는 [[셈꿰미]]다. 꿰미꾼은 무리 안에서 도제로 학습하고, 죽은 꿰미꾼의 구슬은 상속자의 꿰미에 옮겨 꿰어진다. 오르다는 고래를 구문으로 사역하는 것을 금기로 여기므로([[오르다]] 참고), 꿰기의 구문은 [[💪 증폭|몸의 증폭]]과 날씨·방위의 관측, 야영의 살림에 집중된다.

## 이 전통의 구문사

```dataview
TABLE WITHOUT ID file.link AS "인물", 등급 AS "등급", 구문 AS "주요 구문"
WHERE 구문-전통 = this.file.name
SORT file.name
```
