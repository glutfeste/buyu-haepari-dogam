# 태엽술

> 태엽과 톱니 장치를 매체로 하여 구문을 운용하는 전통.

태엽술은 [[글루트페스테]]와 [[보레아 영구기관]]의 [[구문]] 전통이다. 구문을 순수한 계산으로 규정하고, 매체는 태엽이며 장치는 회중시계다. 태엽의 배열이 곧 구문이다. 글루트페스테는 태엽 기술을 숙달한 전문가를 태엽사라 부르고, 도제식으로 양성된 이들 가운데 한 분야의 경지에 도달한 이를 장인, 그 위를 명장이라 부른다.

## 이 전통의 구문사

```dataview
TABLE WITHOUT ID file.link AS "인물", 등급 AS "등급", 구문 AS "주요 구문"
WHERE 구문-전통 = this.file.name
SORT file.name
```
