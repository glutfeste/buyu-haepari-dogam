# 신성술

> 악보를 매체로 하여 구문을 신께 올리는 성가로 운용하는 전통.

신성술은 [[뤼메리-훈디아 이중제국]]의 [[구문|구문]] 전통이다. 구문을 신께 올리는 성가로 규정한다. 매체는 악보로, 음높이와 길이와 화음과 셈여림을 함께 담아 조밀하다. 장치는 [[조율기]]다. 핀을 옮겨 꽂는 일을 조율이라 한다. [[영원한 태양 성좌]]의 사제와 황제-왕 직속 기사단의 기사가 신성술을 운용한다.

## 이 전통의 구문사

```dataview
TABLE WITHOUT ID file.link AS "인물", 등급 AS "등급", 구문 AS "주요 구문"
WHERE 구문-전통 = this.file.name
SORT file.name
```
