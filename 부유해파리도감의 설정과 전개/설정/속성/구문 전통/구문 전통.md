# 구문 전통

> 구문을 무엇으로 규정하고 어떤 매체로 운용하는지로 구분하는 값. 태엽술·연금술·신성술·노질·도술로 나뉜다.

구문 전통은 나라와 집단마다 [[구문]]을 무엇이라 규정하고 어떤 매체와 장치로 운용하는지로 구분하는 값이다. 전통마다 매체와 장치, 구문을 운용하는 사람의 명칭과 양성 방식이 다르다.

## 전통

| 전통 | 뜻 |
| --- | --- |
| [[태엽술]] | 태엽과 톱니 장치를 매체로 운용하는 전통 |
| [[연금술]] | 성장시킨 결정을 매체로 운용하는 전통 |
| [[신성술]] | 악보를 매체로 성가로 운용하는 전통 |
| [[노질]] | 노에 새긴 홈을 매체로 운용하는 기술 |
| [[도술]] | 부적을 매체로 운용하는 전통 |

## 이 전통의 구문사

```dataview
TABLE WITHOUT ID file.link AS "인물", 등급 AS "등급", 구문 AS "주요 구문"
WHERE 구문-전통
SORT file.name
```
