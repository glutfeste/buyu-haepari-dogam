# 도술

> 부적을 매체로 하여 구문을 운용하는 부초 [[현초]]의 전통.

도술은 부초 [[현초]]의 [[구문|구문]] 전통이다. 구문을 수행자가 도와 합일하는 조화로 규정하며, 매체는 부적으로 구문을 조밀하게 새겨 소지한다. 도술을 수련하는 사람을 도사라 부르며, 그 가운데 최고 경지에 도달한 도사를 민간에서 [[신선]]이라 높여 부른다.

## 이 전통의 구문사

```dataview
TABLE WITHOUT ID file.link AS "인물", 등급 AS "등급", 구문 AS "주요 구문"
WHERE 구문-전통 = this.file.name
SORT file.name
```
