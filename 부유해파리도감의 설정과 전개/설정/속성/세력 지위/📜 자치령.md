# 📜 자치령
법적으로 상위 국가의 영토에 속하면서, 내정에 한하여 높은 수준의 자치권을 보장받는 지역. 자체 의회와 행정 기구를 설치하여 행정·입법·재정 같은 내정을 스스로 처리하며, 외교와 군사 같은 주권은 상위 국가가 행사한다.

## 이 지위의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE contains(list(지위), this.file.link)
SORT file.name
```
