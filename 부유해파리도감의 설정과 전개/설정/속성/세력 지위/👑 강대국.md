# 👑 강대국
자국 영토를 넘어 국제 질서와 타국에 정치적, 경제적, 군사적 영향력을 투사할 수 있는 국가. 주변 약소국의 외교와 내정에까지 자국의 의사를 관철한다. 부초 사이의 교역로와 자원, 구문사 인력을 놓고 경쟁하며, 조약의 체결과 전쟁의 결과를 결정한다.

## 이 지위의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE contains(list(지위), this.file.link)
SORT file.name
```
