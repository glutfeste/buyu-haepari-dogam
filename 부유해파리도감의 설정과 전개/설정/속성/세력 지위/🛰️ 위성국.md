# 🛰️ 위성국
국제법상 완전한 주권을 보유한 독립국으로서, 특정 강대국과의 군사·정치적 동맹 관계에 깊이 의존하여 그 영향력 아래 있는 국가. 외교권과 군사권을 스스로 행사하며, 군사 보호와 교역을 한 강대국에 의존한다.

## 이 지위의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE contains(list(지위), this.file.link)
SORT file.name
```
