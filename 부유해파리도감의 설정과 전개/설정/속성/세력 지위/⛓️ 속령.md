# ⛓️ 속령
상위 국가가 주권을 전부 행사하며 직접 통치하는 지역. 상위 국가가 총독이나 관리를 파견하여 내정까지 관장하고, 본토와 구별되는 법적 지위를 적용한다. 주민의 시민권과 정치 참여권은 본토 주민보다 좁게 인정된다.

## 이 지위의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE contains(list(지위), this.file.link)
SORT file.name
```
