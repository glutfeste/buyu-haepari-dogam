# 세력 지위

> 세력이 보유한 주권의 범위와 다른 세력에 대한 종속의 정도로 구분하는 값.

세력 지위는 한 세력이 자국의 외교와 군사, 내정을 스스로 결정하는 권한을 어느 정도 보유하는지로 구분하는 값이다. 완전한 독립을 보유한 주권국이 기준이며, 그 권한을 일부 또는 전부 다른 세력에 위임한 정도에 따라 보호국·자치령·속령으로 나뉜다.

## 지위

| 지위 | 뜻 |
| --- | --- |
| [[👑 강대국]] | 타국의 외교와 내정에까지 영향력을 투사하는 국가 |
| [[🛰️ 위성국]] | 주권을 보유하며 한 강대국에 깊이 의존하는 국가 |
| [[🎭 괴뢰국]] | 독립국의 외형을 갖추고 주권을 외세가 장악한 국가 |
| [[🏢 특허회사]] | 국가의 특허로 교역과 통치를 대행하는 기업 |
| [[🌖 조공국]] | 자율을 보유하며 종주국에 공물을 바치는 국가 |
| [[🏰 주권국]] | 외교권과 군사권을 온전히 보유한 독립 국가 |
| [[🤝 구성국]] | 더 큰 정치체의 주권에 참여하는 구성원 |
| [[📜 자치령]] | 상위 국가에 속하며 내정 자치를 보유한 지역 |
| [[⛓️ 속령]] | 상위 국가가 내정까지 직접 통치하는 지역 |
| [[🛡️ 보호국]] | 주권의 일부를 상위 국가에 위임한 주권국 |

## 이 지위를 가진 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE 지위
SORT file.name
```
