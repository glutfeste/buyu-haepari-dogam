# 🌖 조공국
실질적으로 독립국과 거의 동등한 자율성을 보유하면서, 의례적·형식적으로 종주국을 상위 국가로 인정하고 정기적으로 공물과 사절을 보내는 국가. 내정과 외교는 스스로 처리한다. 증여와 답례가 오가는 교역의 이익이 커서, 조공국이 종속 관계를 자국의 이익으로 유지하는 사례가 많다.

## 이 지위의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE contains(list(지위), this.file.link)
SORT file.name
```
