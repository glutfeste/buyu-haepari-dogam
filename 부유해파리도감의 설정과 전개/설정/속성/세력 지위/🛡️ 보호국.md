# 🛡️ 보호국
국제법상 주권국으로 인정되며, 조약에 의해 외교권·군사권 등 주권의 일부를 상위 국가에 위임하거나 상위 국가의 제한을 받는 국가. 보호 조약에 따라 상위 국가가 외교와 방위를 대행하고, 보호국은 그 대가로 자율을 일부 위임하며 내정을 스스로 처리한다.

## 이 지위의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE contains(list(지위), this.file.link)
SORT file.name
```
