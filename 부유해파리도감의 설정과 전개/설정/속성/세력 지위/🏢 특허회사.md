# 🏢 특허회사
국가로부터 특정 지역에 대한 독점적 무역권, 식민지 경영권, 행정권을 위임받은 민간 또는 반관반민 형태의 기업. 국가가 직접 통치하기 어려운 먼 부초나 변경 권역에서 특허장에 근거해 교역과 통치를 대행한다. 군대와 관리를 스스로 보유하며, 일부는 한 지방을 사실상 지배한다.

## 이 지위의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE contains(list(지위), this.file.link)
SORT file.name
```
