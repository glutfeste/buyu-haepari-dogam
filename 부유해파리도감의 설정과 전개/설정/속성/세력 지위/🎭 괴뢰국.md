# 🎭 괴뢰국
독립 국가의 외형을 갖추고, 정치·군사를 비롯한 모든 실질적 주권을 외세가 장악하여 통제하는 국가. 자국의 정부와 국기, 주권자를 유지하며, 정책과 군대는 장악한 외세의 명령을 따른다.

## 이 지위의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE contains(list(지위), this.file.link)
SORT file.name
```
