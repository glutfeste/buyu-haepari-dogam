# 🤝 구성국
연방이나 연합 왕국 등 더 큰 정치체의 핵심 구성원으로서 그 주권에 참여하는 단위. 자체 법과 의회, 행정을 갖추고 내정을 스스로 통치하며, 외교와 군사 같은 주권은 상위 정치체와 함께 행사한다.

## 이 지위의 세력

```dataview
TABLE WITHOUT ID file.link AS "세력", 상태 AS "상태", 종주-세력 AS "종주"
WHERE contains(list(지위), this.file.link)
SORT file.name
```
