# 화폐

> 은이 가치의 기준이고, 리브라가 하늘 교역의 공용 화폐다.

## 은 본위와 리브라

대륙 사이 교역의 결제 기준은 [[벡실리아 공화국]]의 은화 리브라(Libra)다. 리브라 한 닢은 은 12그램을 함유한다. 벡실리아는 국가 기밀인 연금술 공정으로 은화에 위조하기 어려운 보안 장치를 새겨 화폐의 신용을 유지한다.

리브라의 100분의 1은 **센티모(Centimo)**다. 벡실리아에서는 센티모 단위의 구리돈을 주조하고, 대륙 교역에서도 잔돈과 장부 계산에는 이 명칭을 널리 쓴다. 지역에 따라 구리돈의 별칭과 모양은 달라도 환산할 때는 센티모로 적는다.

은은 [[질버하임 공국]]을 비롯한 소수의 산악 광산에서 산출되어 공급량이 일정하고, 중량 대비 가치가 높아 비행선으로 운반하기에 적합하다.

## 각국 화폐와 환산

| 화폐 | 발행 | 가치의 근거 | 환산 |
|---|---|---|---|
| 리브라(Libra) | [[벡실리아 공화국]] | 은 본위, 연금술 보안 장치 | 기준 |
| 휠던(Gulden) | [[뤼흐트스타트]] | 은 본위, 평의회의 신용 | 1리브라 ≈ 2휠던 |
| 페스테 마르크(Feste Mark) | [[글루트페스테]] | 국가 보증 | 1리브라 ≈ 3마르크 |
| 에퀴(Écu) | [[뤼메리-훈디아 이중제국]] | 은 본위, 함량이 낮다 | 1리브라 ≈ 5에퀴 |
| 그리브나(Grivna) | [[스톨코비아]] | 국가 보증 | 1리브라 ≈ 8~20그리브나 |

리브라와 휠던은 어느 항구에서나 통용된다. 페스테 마르크는 국내에서 가치가 안정되고, 통제 경제의 화폐라 국외 상인은 할인하여 수령한다. 에퀴는 재정난 때마다 은 함량을 축소하여 신용이 낮다. 그리브나는 재정이 불안정할 때마다 가치가 함께 변동하여 환산 폭이 넓다.

## 물가

가격은 모두 벡실룸 시세다.

| 품목 | 가격 |
|---|---|
| 빵 한 덩이 | 2센티모 |
| 선술집의 한 끼와 맥주 | 10센티모 |
| 여인숙 하루 | 20센티모 |
| 비숙련 노동 하루 일당 | 30센티모 |
| 숙련 장인 하루 일당 | 1리브라 |
| 수병 한 달 급료 | 6리브라 |
| 3급 연금술사 한 달 보수 | 25리브라 |
| 2급 연금술사 한 달 보수 | 60리브라 |
| 소총 한 정 | 8리브라 |
| 부초 사이 3등 뱃삯(아우렐리아→아비도라) | 15리브라 |
| 소형 행상선 한 척 | 9,000리브라 |
| 싸구려 소형 비행선 한 척 | 3,000리브라 |
| 호위함 한 척 | 120,000리브라 |
| 순양함 한 척 | 350,000리브라 |
| 하급 부상석 1톤 | 300리브라 |
| 상급 부상석 1톤 | 6,000리브라 |

부초 사이 뱃삯이 비숙련 노동자의 50일 일당에 이르므로, 평민은 평생 자신의 부초에서 생활하는 사례가 흔하다. [[넬라 베린디스]]처럼 뱃일을 담당하여 뱃삯을 대신하고 동승하는 사례도 있다. 호위함 한 척이 상급 부상석 십수 톤을 소모하고, 그 가격이 선가의 절반 가까이 된다.

## 신용

은화와 함께 지폐가 통용된다. [[뤼흐트스타트]]의 어음은 신용이 높아 대륙 곳곳에서 통용되고, 벡실리아의 상인 길드와 은행이 발행하는 신용 증서도 널리 수용된다. 환율과 금리는 벡실룸의 대유체 거래소가 실시간으로 산출한다([[벡실리아 공화국]] 참고).

벡실리아 사법에서 채무는 노역으로도 변제하므로, [[추심원]]은 채무자의 노역 하루를 몇 리브라로 환산할지 기능 등급별로 정해 둔 환산표를 사용한다.

## 은의 유입 위험

[[아스틀로아]]의 [[시발룬 제국]]은 은을 채굴하여 도시를 통째로 은으로 건조했다. 그 은이 일시에 시장에 유입되면 은 본위 화폐의 가치가 불안정해진다. 그래서 벡실리아 이사회는 아스틀로아 방면의 인양과 사략을 허가제로 제한하여 은의 유입 속도를 통제한다.
