# 생득 구문

> 발생 과정에서 형성된 생체 회로가 자기 몸이나 연결된 조직에 고정된 배열을 실행하는 구문.

## 저장과 실행

생득 구문의 세대 간 기록은 유전 물질에 포함된다. 이 기록은 발생 과정에서 신경세포나 흥분성 세포의 연결, 신호 역치, 전달 지연과 되먹임 고리를 형성한다. 성체에서 고정된 회로 구조가 구문의 배열을 보존하고, 회로를 흐르는 전기·화학 신호가 그 배열을 연산한다.

한 조직이 매체와 연산망의 기능을 함께 담당한다. 세포 사이의 고정된 연결 관계는 호출 순서를 보존하고, 순간마다 변하는 신호 상태는 입력을 전달하고 하위 절차를 평가한다. 유전 물질은 손상 뒤 회로를 다시 형성하고 다음 세대로 전달하는 발생 기록으로 기능한다.

## 몸에 결속된 매개변수

생득 구문의 회로 단위는 자신이 접촉한 막·기낭·근육·균사와 감각기관을 입력으로 삼는다. 각 단위의 물리적 위치가 작용 대상을 미리 지정하므로 전신의 부위를 중앙에서 일일이 특정하는 연산이 줄어든다.

부유 해파리의 막에는 같은 국소 회로가 여러 구역에 반복된다. 각 회로는 자신이 연결된 막의 장력과 기낭 압력을 읽고, 인접 회로와 신호를 교환하며, 전신을 도는 동기화 신호에 맞추어 부양이나 재생의 하위 절차를 실행한다. 고래의 부레 신경총, 익낭수류의 익막 신경절과 창공균사의 흥분성 균사망도 같은 방식으로 자기 조직을 매개변수에 결속한다.

구문에 소요되는 힘은 생물의 대사와 몸에 전달되는 외력에서 공급된다. 부양 구문은 섭취한 에너지를 소모하고, 익막 안정 구문은 비막에 작용하는 공기력을 재배분하며, 균사 응력 분산 구문은 군락에 전달된 풍압을 연결된 줄기로 분산한다.

## 기재 구문과 생득 구문

사람의 구문사는 외부 매체에 기록된 배열을 두뇌로 판독한다. 지각으로 임의의 대상을 지정하고 범위·세기·거리·지속 시간을 바꾸며, 배열을 개량하고 새 구문을 제작해 다른 사람에게 전수한다. 이 방식의 구문을 기재 구문이라 부른다.

생득 구문은 발생 과정에서 형성된 고정 회로와 감각 입력을 사용한다. 적용 대상은 자기 몸이나 물리적으로 연결된 군체로 한정되고, 매개변수의 범위도 회로가 형성된 기관 안에서 변한다. 개체는 이 배열을 의식적으로 고치거나 다른 구문으로 교체하지 않는다.

사역 구문으로 생물의 신경계에 폐쇄된 조건 회로를 각인하면 후천적인 생체 회로도 자율적으로 실행된다. 이 회로는 외부에서 기입된 배열이며 유전되는 생득 구문과 구분한다.

## 진화

생득 구문은 짧고 완결된 국소 회로에서 시작한다. 막 장력을 조금 보정하거나 상처 가장자리의 수축을 촉진하는 회로가 생존에 기여하면, 그 회로의 복제와 연결을 형성하는 발생 형질이 보존된다. 완결된 회로가 여러 구역에 반복되고 동기화 절차가 추가되면서 전신 규모의 효과가 생긴다.

반복되는 몸 구조와 분산 연산망은 이 진화에 적합하다. 같은 국소 절차를 여러 부위에 복제할 수 있고, 일부 구역의 손상 뒤에도 나머지 회로가 실행을 지속한다. 부유 해파리는 얇은 막, 다실 기낭, 반복 촉수와 전신 신경 그물을 함께 지녀 생득 구문이 여러 차례 분화했다.

중앙 신경계가 발달한 동물에서도 특정 기관의 자율신경총이 고정 구문을 실행할 수 있다. 이때 중앙 두뇌는 행동과 감각을 통합하고, 기관의 생득 회로는 압력·장력·혈류 같은 국소 상태를 처리한다.

## 판정 기준

생리 현상을 생득 구문으로 판정하려면 같은 개체와 근연종에서 반복 가능한 증거를 모은다.

| 검사 | 판정 자료 |
|---|---|
| 정량 결손 | 알려진 해부 구조·기체량·근력·탄성만으로 산출한 값과 실제 효과 사이에 일정한 차이가 남는다. |
| 회로 폐쇄 | 고정된 연결과 신호 순서가 완결된 호출 관계를 이루고 같은 입력에서 같은 출력을 낸다. |
| 선택적 차단 | 회로의 특정 연결이나 동기화 신호를 차단하면 해당 효과가 중지되고 주변의 통상 생리는 유지된다. |
| 입력 재현 | 외부 구문이나 전기 자극으로 같은 입력을 기입했을 때 회로의 하위 절차와 효과가 같은 순서로 재현된다. |
| 발생과 계승 | 유체에서 회로가 형성되는 순서와 근연종 사이의 잔여 절차가 반복 관찰된다. |
| 에너지 수지 | 실행 전후의 섭식량·체온·대사 산물과 외력 전달량이 산출에 소요된 힘과 대응한다. |

반사 행동과 호르몬 조절도 신호 회로를 사용한다. 생득 구문은 통상적인 생리 작용을 제외한 정량 결손, 완결된 호출 구조와 선택적 차단 결과가 함께 확인될 때 확립된다.

## 알려진 사례

| 생물과 현상 | 확실도 | 근거 |
|---|---|---|
| 부유 해파리의 부양 | 확립 | 기체 부력의 부족량, 신경 그물의 반복 회로, 회로 차단과 외부 신호 재현이 일치한다. |
| 거품해파리의 빠른 재생 | 개체 작동 확립·계통 분포 유력 | 보글이와 왕보글이에서 재생 회로가 관측되며, 일반 개체에는 발생 흔적과 불완전한 잔여 회로가 남는다. |
| 고래의 평압 조절 | 유력 | 부레별 자율신경총과 압력 보정량이 대응하고, 국소 차단한 부레에서만 보정이 지연된다. |
| 용·활공수의 익막 안정 | 잠정 | 익막 구획의 신경절과 장력 보정 신호가 공통 발생부에서 확인되며 선택적 차단 자료가 부족하다. |
| 창공균사의 응력 분산 | 유력 | 살아 있는 균사망의 하중 분산이 같은 형상의 죽은 균사망을 초과하고, 흥분성 신호 차단 뒤 그 차이가 사라진다. |

## 넬라의 발견

[[넬라 베린디스]]는 부유 해파리의 무게와 기낭 부피를 측정하여 기체 부력만으로 설명되지 않는 부양량을 산출했다. 이어 투명한 막에서 신경 신호의 전달 순서를 관측하고, 특정 연결을 방해한 개체에서 부족한 부양량만 사라지는 현상을 확인했다. 사람의 [[부양의 구문]]과 호출 관계를 대조하여 생물이 타고난 회로로 구문을 실행한다는 결론을 세웠다.

이 발견 뒤 고래 잠수 기록, 익막의 장력 신호와 창공균사의 하중 전달을 같은 기준으로 다시 조사했다. 해파리는 사람 밖의 구문이 처음 확립된 계통이며, 생득 구문의 종류와 계통 변이가 가장 풍부하게 기록된 연구 대상이다.

넬라가 정립한 관찰·차단·재현·발생 비교법은 마법생물의 특이한 능력을 측정 가능한 생리와 구문 구조로 기술하는 비교 구문생리학의 출발점이 된다.
