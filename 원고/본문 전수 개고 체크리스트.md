## 1. 이번 정정에서 고정할 보호항목

아래 여섯 항목은 이전 감사의 오판이다. 이후 개고에서 다시 수정 대상으로 올리지 않는다.

- [ ] **10화:** 에피소드 문서에 남은 테오도어의 `담보물 번호부터 틀리지 않는 게 좋겠군`을 복구하지 않는다. 현재 본문의 `그래서 저 군인들이 아까 그 아가씨를 계속 살폈군`은 바로 앞의 군인 반응과 논리적으로 연결된다.

- [ ] **19화:** `가출`, `사춘기`, `네 침대는 안 치울 테니까`를 유지한다. 농담 완화가 아니라 코르베르가 아멜리의 결별을 아이의 일시적 반항으로 오판하는 관계 지표다.

## 2. 원래 감사에서 유지할 전역 지적

### 2.1 넬라의 연구 방법을 확립한 뒤에도 다시 설명하는 문제

1~8화는 넬라의 방법론을 독자에게 세우는 구간으로 본다. 특히 8화의 `직접 / 마르톤 / 주민` 분리는 이후 감사의 기준점이다. **9화 이후**에는 같은 정확성을 말로 다시 정의하기보다 기록의 모양, 추가 표본 선택, 빈칸 때문에 생기는 갈등, 잘못된 증언으로 인한 우회, 판정 보류의 비용으로 보여 준다.

- [ ] 9화 이후에 `직접관찰/구술`, `관찰/원인`, `확인/미정`, `개체/종`을 다시 정의하는 문장이 있는가?
- [ ] 정의를 삭제해도 표·표찰·행동·결정으로 같은 구분이 보이는가?
- [ ] 정확성을 없애지 않고 **설명 방식만** 행동으로 바꾸었는가?
- [ ] 새 학술 개념인 진화론·자연선택까지 이미 배운 방법론 반복으로 오판하지 않았는가?

### 2.2 `손·손가락·펜이 멈추다/멎다/굳다` 계열의 누적

같은 어휘만이 아니라 같은 기능을 본다. `손이 멈춤`, `펜끝이 멎음`, `매듭 위에서 굳음`, `허공에서 손이 멈춤`이 모두 놀람·당혹·충격의 기본 애니메이션으로 반복되면 변주한다.

- [ ] 5·9·10·13·15·16·18·19화의 정지 동작을 한꺼번에 비교했는가?
- [ ] 인물의 감정이 그 장면의 실제 작업에 오차·흔적·미완성 상태를 남기게 바꿀 수 있는가?
- [ ] 이름을 숨기는 마르톤의 엄지, 베르나르가 빗장을 여는 직전의 손처럼 **고유 기능이 있는 정지**는 남겼는가?
- [ ] `멈추다`를 `굳다/멎다`로 치환하는 가짜 변주를 하지 않았는가?

### 2.3 연구·거래·설명 장면의 골격 반복

- [ ] `도착 → 질문 → 전문가의 정확한 답 → 넬라 기록`이 가까운 화에서 반복되는가?
- [ ] `관찰 → 가능한 원인 나열 → 다음 시험 선언`이 반복되는가?
- [ ] `문제 → 티키타카 → 한 줄 농담`으로 장면이 닫히는가?
- [ ] 다음 장면에서는 정보가 말이 아니라 손상, 실패, 가격표, 잘못된 증언, 다른 인물의 선행 발견에서 나오게 바꿀 수 있는가?
- [ ] 같은 골격을 유지해야 하는 경우 두 번째 장면이 관점 전환·역전·개그·관계 변화라는 새 기능을 갖는가?

### 2.4 설명을 삭제하지 말고 전달 구조를 감사

- [ ] 설명의 길이가 아니라 화자의 동기와 장면 목적을 먼저 확인했는가?
- [ ] 법률·학술·기술 인과를 줄여 의미를 바꾸지 않았는가?
- [ ] 한 인물이 모든 층위를 연속 강의할 때 문단 구획, 소품, 창밖 반응, 상대의 실제 이해관계로 호흡을 나눌 수 있는가?
- [ ] 독자의 질문 순서를 대신하는 `그게 뭐야? → 왜? → 그래서?` 문답을 새로 만들지 않았는가?
- [ ] 10화의 제1강대국 정보, 21화의 자연선택 우선 가설, 23화의 기만 계산처럼 뒤에서 보여 줄 수 있다는 이유로 지금 필요한 프레임을 삭제하지 않았는가?

### 2.5 유머와 웃음의 반복 박자

유머 자체를 약화시키지 않는다. 기능 있는 관계 표현과 전력차 장면은 보존한다. 다만 같은 장면에서 매 대사 뒤 `웃음/헛웃음/입꼬리`가 붙어 박자가 평평해지는지 본다.

- [ ] 18화의 첫 용서 재연은 집단 공연과 아멜리의 오해를 보여 주므로 보존했는가?
- [ ] 19화의 `가출/사춘기`를 농담 삭제 대상으로 올리지 않았는가?
- [ ] 20화의 무손실 전투를 위협 강화를 이유로 바꾸지 않았는가?
- [ ] 20화 결별 대화에서 같은 군중 웃음 표지가 연속되는 부분만 줄였는가?
- [ ] 유머를 줄인 자리에 서술자 평가나 `침묵`을 자동으로 넣지 않았는가?

### 2.6 부정형 경계·억지 대조·격언식 단문

- [ ] 실제 부재·금지·정정이 핵심이 아닌데 `아니다/없다/아니라`로 먼저 경계를 치는가?
- [ ] 의미 없는 A/B 대칭을 문장 맛을 위해 만들었는가?
- [ ] 원인·조건·결과가 이어지는 설명을 격언처럼 잘게 잘랐는가?
- [ ] **15화의 `종국적으로/현실적으로`는 실제 법률관계의 두 층위를 구분하므로 억지 대조로 판정하지 않았는가?**

### 2.7 문두·호흡·서술 재료의 반복

- [ ] `넬라는/마르톤은/테오도어는/파비아는` 문두가 2~4문단 안에서 연속되는가?
- [ ] 동작 중심 문단 뒤에 다시 동작 중심 문단이 이어지는가?
- [ ] 소리·빛·냄새·공간 변화·소품·앞 문장의 결과가 문두를 나눠 가졌는가?
- [ ] 긴 설명 뒤 짧은 서술자 요약·평가·농담을 기본 종결법으로 쓰는가?

### 2.8 화 분량

- [ ] 실제 한국어 문자 수를 공백·문장부호 포함, 줄바꿈 제외 기준으로 계수했는가?
- [ ] 5천~6천자 범위를 벗어나면 먼저 중복 설명·행정 절차의 문장 밀도를 점검했는가?
- [ ] **23화는 구조를 분할하지 않고 내부 중복을 줄이는 안을 먼저 적용했는가?**
- [ ] 자연스러운 결정·발견·위기가 없는 곳에서 숫자만 맞추려고 자르지 않았는가?

# 3. 화별 개고 체크리스트와 대안

## 1화. 해파리 당직

**보존:** 화물칸 물성, 뱃삯 대신 당직을 택하는 거래, 졸업식의 진로 선택, 떼우산해파리 통로 개방.

- [ ] 초기 방법론 확립 장면으로 보존했는가?
- [ ] 후속 화에서 같은 `관찰 → 설명 → 재시험` 골격이 반복될 때 1화를 기준점으로 비교했는가?
- [ ] 이 화 자체를 후속 화의 반복 때문에 불필요하게 줄이지 않았는가?

**권고:** 본문 강제 수정 없음. 후속 화의 전역 패턴 감사 기준으로 사용한다.

## 2화. 거품형 기낭 해파리 — 임시 표제

**보존:** 식용 처리와 화기 위험, 접안 흥정, 붕괴 군락의 생태, 다실 기낭 발견.

- [ ] 다음 부정형 경계만 직접형으로 바꿀지 검토했는가?

현재:
> 렌즈가 흐려진 것도 아닌데 넬라는 망원경을 내렸다가 다시 들었다.

대안:
> 막 안쪽의 방이 너무 잘게 갈라져 있어 넬라는 망원경을 내려 렌즈 표면을 한 번 확인한 뒤 다시 들었다. 두 번째 개체도 같은 다실 구조를 보였고, 세 번째에서는 작은 방들이 막 가장자리 가까이까지 퍼져 있었다.

- [ ] 놀라서 자기 시야를 의심하는 행동은 보존했는가?
- [ ] 임시 표제와 다음 확인 항목은 초기 방법론 확립이므로 자동 삭제하지 않았는가?

## 3화. 죽어 가는 섬

**보존:** 안전 우선, 보글이 추종 시험, 실제 기초수업, 승선 조건, 마지막에 기록보다 개체를 먼저 보는 선택.

- [ ] 구문학 수업을 길다는 이유로 축약하지 않았는가?
- [ ] 매체·연산·힘·대상 결속·복잡도의 구분을 온전히 보존했는가?
- [ ] 마지막 `수첩을 꺼내려던 손`은 연구자 넬라의 선택 변화라는 고유 기능이 있는지 확인했는가?

**권고:** 강제 수정 없음. 이 화는 설명 허용의 기준 사례다.

- [ ] `배 해파리`와 정식 종명의 차이는 최초 확립 장면으로 보존했는가?
- [ ] 초롱 경고의 불완전한 그림과 실제 위협의 차이를 살렸는가?
- [ ] 이후 화에서 같은 분류 유보 설명을 다시 말하지 않도록 기준점으로 삼았는가?

## 5화. 등불을 따라가지 말 것

**보존:** 초롱해파리 전투, 마르톤의 행동 우선 첫 등장, 넬라와 마르톤의 협업, 전신 미관측 기재.

- [ ] 마르톤이 이름을 숨길 때 검집을 닦던 엄지가 잠깐 멎는 동작은 남겼는가?
- [ ] 뒤의 펜 정지 동작만 변주했는가?

현재:
> 안개에 가렸던 상부 몸체를 그리려던 펜끝은 종이 위에서 멈췄고, 선체와 비교해 실제로 본 범위까지만 윤곽을 닫자 그림 위쪽은 넓게 비었다.

대안:
> 안개에 가렸던 상부 몸체에는 선을 더 잇지 않았다. 선체와 비교해 실제로 본 범위까지만 윤곽을 닫자 그림 위쪽은 넓게 비었다.

- [ ] 전투 뒤 표본 채취가 지나치게 긴 별도 연구 장면처럼 느껴지지 않는지 호흡만 확인했는가?
- [ ] 표본 부위별 목적은 기술적 의미가 다르므로 삭제하지 않았는가?

- [ ] 넬라의 장황한 변명 뒤 `내기 싫었어요. 연구해야 하니까`가 충동성과 자기합리화를 드러내므로 보존했는가?

- [ ] 실제 규정 위반을 넬라의 정의로움 때문에 순화하지 않았는가?

- [ ] **26 대사·몸짓 결속:** 대사와 실제 작업이 같은 호흡에서 움직인다.
- [ ] **27 유머 질감:** 농담뿐 아니라 사물의 꼴과 진지함에서도 위트가 난다.

## C. 호흡 패스

- [ ] **28 누적문:** 감각·행동·공간이 인과 순서로 이어진다.
- [ ] **29 병렬 운율:** 동시에 일어나는 소리·빛·운동을 필요할 때 묶는다.
- [ ] **30 길이 변주:** 빠른 동작과 느린 관찰의 문장 길이가 다르다.
- [ ] **31 단문 재검사:** 이어지는 시선과 인과를 중문·복문으로 묶었다.
- [ ] **32 건조한 위트:** 마지막 한 줄이 아니라 관찰 방식에 배어 있다.
- [ ] **33 절제:** 구체 사실을 태연하게 놓아 곤란과 우스움을 만든다.
- [ ] **34 의사 비장미:** 사소한 일의 잠깐 엄숙함이 인물을 살린다.
- [ ] **35 규모 병치:** 큰 걱정과 생활 걱정이 실제로 함께 있을 때만 나란히 둔다.
- [ ] **36 장단 펀치:** 짧은 문장이 실제 충격·결단·전환을 만든다.
- [ ] **37 장소 감각:** 공간마다 냄새·온도·소리·빛·촉감이 다르다.
- [ ] **38 인물 렌즈:** 비유와 관심 대상이 시점 인물의 성격을 통과한다.

## D. 패턴 감사

- [ ] **39 패턴 피로:** 동사 배열·농담·정지 동작·서술자 논평이 반복되지 않는다.
- [ ] **40 단문 연속:** 인접 문단과 화 전체에서 단문이 기본 박자가 아니다.
- [ ] **41 문두 변주:** 인물 이름 외의 재료가 문두를 나눠 가진다.
- [ ] **42 재료 교체:** 동작 문단 다음에는 감각·공간·소품 등 다른 재료가 온다.
- [ ] **43 긴 묘사 뒤 한 줄:** 같은 골격을 가까이 반복하지 않는다.
- [ ] **44 직유 소재:** 모든 인물을 같은 생활 사물·동물에 빗대지 않는다.
- [ ] **45 대사 몸짓:** 눈썹·미소·고개 같은 장식이 대사마다 붙지 않는다.
- [ ] **46 장면 구성:** 도착→질문→정답, 관찰→설명→기록이 반복되지 않는다.
- [ ] **47 넬라 흥분 변주:** 질문 연타와 수첩만으로 흥분을 표현하지 않는다.
- [ ] **48 연구 리듬 변주:** 관찰·설명·기록 순서를 장면마다 바꾼다.
- [ ] **49 확립된 방법 암시화:** 9화 이후 기존 방법론을 행동으로 보여 준다.
- [ ] **49a 기능 있는 반복 보존:** 관점·개그·역전이 생기면 반복을 남긴다.
- [ ] **50 인물 소개 변주:** 새 인물 외양을 같은 순서와 밀도로 소개하지 않는다.
- [ ] **51 콜백 변형:** 같은 문장이 새 관계·역할·오해를 만들거나 의도적으로 반복된다.

## E. 정본·인물·장면 운영

- [ ] **52 관련 정본 재확인:** 전체 완독 뒤 해당 화 문서를 다시 봤다.
- [ ] **53 지식 시점:** 인물이 현재 아는 것만 말한다.
- [ ] **54 미래 결과 역수입 금지:** 후대 발견을 초반 논거로 쓰지 않는다.
- [ ] **55 정보 필요성:** 지금 필요한 정보만 공개한다.
- [ ] **55a 기초 프레임 보존:** 실제 수업·브리핑의 체계를 당장 안 쓴다는 이유로 자르지 않는다.
- [ ] **56 묘사의 자립:** 대사를 지워도 공간과 행동이 그려진다.
- [ ] **57 대사가 묘사 대체 금지:** 손상·분위기를 말로만 설명하지 않는다.
- [ ] **58 물리 연속성:** 대화 중에도 배·몸·물건이 움직인다.
- [ ] **59 불완전한 현지인:** 현지인은 정답 전달 기계가 아니다.
- [ ] **60 직업 거래:** 노동에 가격·조건·거절·경계가 있다.
- [ ] **61 대안과 거래비용:** 선택지를 유일한 운명으로 만들지 않는다.
- [ ] **62 미래 해파리 구문 금지:** 넬라가 아직 모를 원리를 미리 알지 않는다.
- [ ] **63 위험 우선:** 위기에서는 연구 호기심보다 생존 판단이 먼저다.
- [ ] **64 충동적 학자:** 넬라를 언제나 침착하고 정의롭게 순화하지 않는다.
- [ ] **65 마르톤의 기사도:** 소년다움 아래 진지한 낭만과 책임이 보인다.
- [ ] **66 말높임 연속성:** 관계에 맞는 높임말이 이어진다.
- [ ] **67 문화별 마법명:** 생활 속에서 각 문화의 이름을 자연스럽게 쓴다.
- [ ] **68 매체·연산·힘·산출 분리:** 마법 작동을 한 덩어리로 쓰지 않는다.
- [ ] **68a 기초수업 완결성:** 이후 공통 문법에 필요한 개념을 충분히 가르친다.
- [ ] **69 화 분량:** 실제 문자 수를 계수하고 자연스러운 흐름을 우선한다.
- [ ] **70 현재 구조 비성역화:** 바꿀 이유가 있을 때만 구조를 바꾸고, 이유 없는 재구성도 하지 않는다.
- [ ] **71 제도 환원 금지:** 추심원을 금융 회수 직역으로 축소하지 않는다.
- [ ] **72 벡실리아 법언어:** 채무·불법행위·추심·국외 권한을 정본대로 쓴다.
- [ ] **73 영향 추적:** 같은 전제가 다른 문서에 남지 않았다.
- [ ] **73a 전역 패턴 감사:** 일반 원리가 나오면 원고 전체를 다시 봤다.
- [ ] **74 전 원칙 대조:** 적용 가능한 원칙 하나라도 미충족이면 완료 처리하지 않는다.
