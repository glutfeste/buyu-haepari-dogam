# 01-23화 개고 실행 체크리스트

> 상태: **지시 확정 / 원고 미수정**
>
> 작업 정본: **`main`**
>
> 운영: 실제 개고를 진행하면서 완료 항목을 `[x]`로 바꾼다. **마지막 전역 감사까지 전부 완료하면 이 파일을 삭제하고, 완료 이력은 Git 커밋과 diff에만 남긴다.** 완료된 체크리스트의 보관본·사본·백업본은 만들지 않는다.
>
> 범위: 현재 01~23화 원고 검토에서 사용자가 승인한 수정과 보존 지시만 실행한다. 아래 `보존 확정` 항목은 수정 후보가 아니라 **다시 문제 삼지 말아야 할 잠금 항목**이다.

## 0. 작업 전 공통 가드레일

- [ ] 실제 원고 개고 직전에 최신 `원고/집필 원칙.md`를 처음부터 EOF까지 다시 읽는다. 이번 체크리스트·원칙 변경 뒤의 최신본을 기준으로 한다.
- [ ] `main`만 작업 정본으로 사용한다. 리뷰·백업·실험용 브랜치를 새로 만들지 않는다.
- [ ] 새 정본을 이해했다는 증거를 원고에 추가하지 않는다. 기존 장면이 새 정본에서도 성립하면 그대로 둔다.
- [ ] 01~20화에 첫그물·수문층 기록·첫그물의 장기 육종·벨테린 등을 복선 명목으로 새로 넣지 않는다.
- [ ] 모든 대안 문장과 실제 개고문에도 `[RULE:PROSE-SEMANTIC-PRECISION]`, `[RULE:PROSE-POSITIVE-DIRECT]`, `[RULE:PROSE-NO-FORCED-CONTRAST]`를 적용한다. `A가 아니라 B` 식 정정형, 의미 없는 대조, 넓고 안전한 어휘로 후퇴하지 않는다.
- [ ] 설명·반복을 삭제하기 전에 `[RULE:PROCESS-FUNCTION-BEFORE-REDUNDANCY]`, `[RULE:DIALOGUE-MOTIVATED-EXPOSITION-SCOPE]`, `[RULE:REPETITION-POV-COMEDY]`, `[RULE:INFO-FOUNDATIONAL-FRAME]`를 먼저 대조한다.
- [ ] 법률 장면은 쉬운 요약보다 법적 성질·책임 근거·위험 배분의 정확성을 우선한다. 같은 금액이 겹쳐 보여도 원채무와 다른 책임을 하나의 `빚`으로 합치지 않는다.
- [ ] 수정한 대목마다 `가드레일 → 문체 생성 → 호흡 → 패턴 감사` 네 패스를 수행하고, 마지막에 적용 가능한 `RULE:*` 전부를 다시 감사한다.

## 1. 보존 확정 — 다시 수정 후보로 올리지 않는다

- [x] **03-A 유지.** 연금술 기초수업은 이후 작품에서 쓸 공통 구문학 문법을 세우는 실제 교육 장면이다. 호출·배열·매체·연산·대상 결속·힘 공급·복잡도·무매체 사용을 `당장 젖은 천 실습에 쓰이지 않는다`거나 `정보가 많다`는 이유로 분해·삭제·지연하지 않는다. 다른 문화 고유 매체의 후속 발견을 선점하지만 않으면 된다.
- [x] **10-A 유지.** 추심관에 대한 장문의 설명은 의도된 세계관 기준점이다. 추심관의 직무·권한에서 벡실리아의 세계적 위상까지 이어지는 범위를 `설명량이 많다`, `뒤에서 보여 줄 수 있다`는 이유로 축소하지 않는다.
- [x] **10-B 유지.** 10화에서 추심원과 벡실리아의 제도적·국제적 위상을 설명하는 기능을 보존한다. 이 장면을 단순 직무 소개로 축소하지 않는다.
- [x] **15-A 유지.** 15화 법률 설명의 내용과 문답 구조를 쉬운 설명으로 갈아엎지 않는다. **대공의 원채무는 대공의 채무이고, 넬라는 대공의 채무를 인수·보증·대납하는 사람이 아니다. 넬라가 부담하는 것은 자신의 오감정 때문에 채권단에 귀속된 회수위험에 관한 자기 책임이다.** 같은 금액이 겹쳐 보이거나 한쪽 이행이 다른 책임 범위를 줄여도 법적 의무의 발생 근거와 성질을 합치지 않는다.
- [x] **15-A 의미 잠금.** `대신 부담`, `대공 몫`, `대공 채무까지`, `회수위험도 추가로 부담`처럼 원채무 인수나 추가 채무 부담으로 읽히는 표현으로 바꾸지 않는다. 간결화·친절한 설명·판타지식 법률 단순화 명목으로 이 관계를 왜곡하지 않는다.
- [x] **15-B 유지.** 현재 장면의 법률 논증이 필요하다는 사용자 판단을 따른다. 길다는 이유로 삭제하지 않는다. 문장 교열을 하더라도 법률관계와 논증 기능을 1:1로 보존한다.
- [x] **16-A 유지.** 15화에서 들은 설명을 16화에서 화자·입장을 바꿔 다시 설명하는 것은 의도된 반복개그와 역할 반전이다. `독자가 이미 안다`는 이유로 삭제·압축하지 않는다.
- [x] **16-B 유지.** 동료들이 넬라의 행동을 두고 반응·평가하는 대목도 장면의 개그 기능을 가진다. `인물들이 넬라를 채점한다`는 표면만 보고 삭제하지 않는다.
- [x] **23-A 기각 유지.** `대치 → 연기였음 공개 → 작전회의 회수 → 실행`의 비선형 공개 순서를 시간순으로 재배열하지 않는다. 트릭을 독자가 체험한 뒤 구조를 회수하는 순서를 보존한다.
- [x] **23-C 유지.** 파비아가 젊은 추심관리에게 탄중 사뭇 봉쇄·분기점·보급 계산을 설명하는 대목은 파비아의 판단이 합리적이었음을 보여 주고, 뒤의 하층풍 기만이 `파비아가 멍청해서 성공한 것`이 되지 않게 하는 기능이 있다. 설명 장면이라는 이유로 삭제하지 않는다.
- [x] **23-E 기각 유지.** 현재 23화를 분량만으로 둘로 나누지 않는다. 대치·기만·탈출·아쿠아 알타 도착의 추진력을 보존한다.
- [x] **13화 유지 중심.** 현재 배의 한계는 가격·하자·적재·정비·운용에서 이미 물질적으로 드러난다. 벨테린을 준비하려고 `이 배는 곧 한계다` 같은 설명·복선을 새로 넣지 않는다.
- [x] **19화 대화 구조 유지.** 베르나르와 아멜리의 짧은 문답은 독자 질문 대행이 아니라 아멜리가 상대가 아는 범위와 선택을 시험하는 장면이다. 핑퐁이라는 이유로 구조를 해체하지 않는다.

## 2. 승인된 개고 — 실제 수정 항목

### 04화 `불러도 답하지 않음`

- [ ] **04-A** 보글이 이름 반응·상처 재측정·초롱해파리 위험은 유지한다. 한 화 안에서 `개체/성체 기록 분리`, 원인 물음표, 형태분류 빈칸 등 이미 전달된 연구 유보 원칙을 문장으로 겹쳐 확인하는 부분은 실제 문맥에서 골라 줄인다.
- [ ] 줄인 자리에 넬라의 방법론을 새 설명으로 치환하지 않는다. 기록 형식과 행동이 이미 보여 주는 정보는 그대로 맡긴다.

### 05화 `등불을 따라가지 말 것`

- [ ] **05-A** 협전 행동으로 이미 성립한 의미를 서술자가 바로 판정하는 문장(`서로 이름조차 모르지만 … 같은 뜻으로 읽었다` 계열)을 제거하거나 장면 자체가 운반하도록 개고한다. 전투 인과와 협업 방식은 그대로 둔다.
- [ ] **05-B** 경고문이 실제로 다음 배의 판단을 돕도록 구체화된 뒤, 서술자가 그 기능을 다시 설명하는 문장을 제거한다. 경고문 내용 자체는 유지한다.

### 08화 `땅해파리`

- [ ] **08-A** 기록 형식에서 현지명과 몸의 특징이 이미 분리되어 보인 뒤 마르톤이 독자 대신 `이름하고 몸 특징 따로 적는 거야?`라고 확인하고 넬라가 다시 설명하는 대목을 삭제·재구성한다. 주민의 생활지식과 `그건 네가 알아내`의 기능은 보존한다.
- [ ] **08-B** 원인·계통 빈칸과 출처 분리를 같은 화 안에서 반복해서 방법론으로 해설하는 부분을 줄인다. 새 출처 정보 자체는 남기고 `빈칸을 비웠다`는 연구 신중함 인증을 반복하지 않는다.

### 12화 `정확한 평가`

- [ ] **12-A** 11화에서 이미 익힌 선 시작점·앞뒤 방향·기부 위치 같은 판정 기준을 다시 완주하는 설명을 줄인다.
- [ ] 붉은 밑선, 원본에 맞추면 계속 지워야 하는 해파리설 도해, 보존기록 등 **실제 물증과 넬라가 지우고 고치는 조사 행동**은 중심에 남긴다. 조사 논리를 약화하거나 판정 근거를 생략하지 않는다.

### 14화 `노을해파리`

- [ ] 지지촉수 위치·이동 순서 비교와 마지막 살아 있는 노을해파리의 반전 관찰은 그대로 살린다.

### 17화 `도난 목록`

### 18화 `공모 혐의`

- [ ] **18-A** 넬라의 원고를 읽는 장면의 중심을 **아멜리**에게 돌린다. `도적들이 넬라의 연구법을 읽고 평가한다`는 장면으로 바꾸지 않는다.

- [ ] **20-A 전체 초점 재설계.** 넬라의 합류 제안은 아멜리를 구원·용서·배려하거나 아멜리의 꿈을 이루어 주기 위한 관용 장면으로 쓰지 않는다. **넬라는 자기 『부유해파리도감』을 만들 사람이고, 아멜리의 수정관·항로 능력이 그 일에 필요해서 아멜리를 선택한다.**

- [ ] `네가 내 원고를 훔쳤다`, `그건 안 잊는다` 같은 뒤끝·심판 대사를 새로 넣지 않는다. 넬라를 쫌팽이로 만드는 설정을 발명하지 않는다.
- [ ] `네 꿈을 내가 이루어 줄게`, `갈 곳 없는 너를 받아 줄게` 같은 구원자 프레임도 만들지 않는다. 코르베르가 앞서 아멜리를 `아무도 받아 주지 않는다`, `훈장은 무슨 훈장`이라고 조롱한 사실은 **넬라가 반박해 주는 도덕적 장면**이 아니라, 넬라가 아멜리의 실제 쓸모를 발견했다는 사실과 자연스럽게 맞물리게 한다.
- [ ] 장면의 핵심 박자는 **`수정관 아멜리 모렐로. 세계일주를 하는 거야. 그리고 같이 만드는 거야.`**라는 방향을 보존한다. 실제 문장은 전체 문체에 맞게 다듬을 수 있지만 `수정관으로서 필요하다 → 함께 세계를 돈다 → 함께 도감을 만든다`의 인과를 바꾸지 않는다.

- [ ] 아멜리의 본명 `아멜리 모렐로`와 직함 `수정관`이 합류 순간에 함께 힘을 얻도록 한다. 이름을 불러 주는 이유를 자비·용서로 설명하지 않는다.
- [ ] **20-B** 아멜리가 18화에서 본 넬라의 날짜·고도·수정 기록과 연구 습관을 다시 장문으로 설명하지 않는다. 원고를 돌려준 행동과 실제 전문성으로 충분히 연결한다.
