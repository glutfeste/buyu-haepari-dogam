# 개고 반영 체크리스트 — 대화 원문 기준 최종본

> **이 문서가 이번 개고의 작업 정본이다.**
>
> 근거는 사용자가 이 대화에 직접 다시 붙여 넣은 ① 최초 Mxx/Axx/Dxx 구체 수정안과 전수 재감사 기록, ② 그 뒤 사용자가 항목별로 정정·반려·보완한 내용, ③ 그 후 합의한 보정안, ④ 2026-08-19 현재 대화에서 추가 확정한 최근 논의다.
>
> 이전의 임시 재구성본, 과거 커밋 메시지, 모델의 기억·요약이 이 문서와 충돌하면 **이 문서가 우선**한다. 커밋 기록은 수정사항을 추정하는 근거로 쓰지 않고, 실제 반영 여부를 확인하는 보조 수단으로만 쓴다.
>
> **완료 판정 규칙:** `[x]`는 현재 `main`의 실제 문장을 직접 읽어 해당 항목과 주변 문맥까지 확인했을 때만 붙인다. 계획·후보문·과거 커밋·기억만으로 `[x]` 처리하지 않는다.
>
> **작업 순서:** 원고를 우선한다. 설정·전개 문서는 원고 정본과 충돌하는 사실만 최소한으로 동기화하며, 원고보다 긴 메타 해설을 새로 만들지 않는다.

## A01 — 1화 「해파리 당직」

- [ ] **A01-1** `현금 대신 해파리 당직`이 아니라 **`뱃삯 대신 해파리 당직`**으로 쓴다.
- [ ] 당직 중 기록은 풍향·먹이층 이동·개체 고도·섭식 행동 등 실제 관찰항목으로 쓴다. `자료가 쌓였다` 같은 범용 요약으로 후퇴하지 않는다.
- [ ] 졸업식에서 넬라가 남들이 꺼리는 해도청을 자신 있게 고르는 사건과 선택 순서를 보존한다. 이 사건은 10화 파비아의 `호구/자신만만` 콜백 원본이다.
- [ ] `신경계에 하강 신호를 기입했다`는 정본상 맞는 표현이므로 유지한다.

## A02 — 2화 「처음 보는 해파리」

- [ ] **A02-1** 작은 기낭실은 격막으로 **나뉜 여러 방**이다. `격막이 기낭실 사이를 이어 준다`고 쓰지 않는다.
- [ ] 몸을 돌렸을 때 보이는 것은 `방 사이 연결부`가 아니라 **기낭실을 나누는 격막의 경계/분지**다.
- [ ] **A02-2** 손상 실험은 **막 일부가 찢어졌을 때 손상되지 않은 기낭실에도 기체가 남는지**를 확인하는 실험으로 쓴다. `따로 버틴다`로 뭉개지 않는다.
- [ ] **A02-3** `균사 이완`처럼 생리 상태를 단정하지 않고, 실제로 관찰한 **느슨해진 균사 다발** 등으로 쓴다.

## A03 — 3화 「죽어 가는 섬」

- [ ] **A03-1** 대학 실습 장면이 대상 결속·배열·연산체·대사 에너지 공급을 이미 보여 준 뒤, `매체가 배열을 보존하고 몸이 연산과 힘을 맡는다`처럼 다시 합쳐 설명하는 문단은 두지 않는다. 회상 뒤 바로 현재 갑판으로 복귀한다.
- [ ] 배열 보존 매체 / 두뇌·신경망의 연산 / 대사 에너지·외력의 에너지 공급을 서로 다른 역할로 유지한다.
- [ ] **A03-2** 보글이를 데려갈 결정을 보여 주기 위해 표본 가방 병을 옮겨 `자리`를 만드는 인위적 동작이나 `이미 데려갈 준비를 하고 있었다`는 서술자 해석을 넣지 않는다. 먹이·상처·선호 고도·성장 관찰 계획과 `같이 가자`가 결정을 보여 주게 한다.

## A04 — 4화 「돌아갈 곳 없는 해파리」

- [ ] 현재 장면 구조는 유지한다. 불필요한 개고로 흔들지 않는다.
- [ ] 보글이 호명 반응의 원인을 확정하지 않는다.
- [ ] 상처 회복은 같은 자세·축척의 재측정으로 기록한다.
- [ ] 오래된 `초롱` 수첩은 위치·발광·신호 불응처럼 실제 남은 정보만 사용한다.

## A05 — 5화 「등불을 따라가지 말 것」

- [ ] **A05-1** 촉수 중간부에서 보는 것은 `일반 조직`이 아니라 **촉수 조직의 구조와 자포낭형·분포** 등 실제 조사 대상이다. 끝부분은 점착 구조·분비물을 별도 관찰한다.
- [ ] **A05-2** 상부 몸체가 안개에 가려 전신을 보지 못했으므로 전체 체격을 추정하지 않는다. **`전신 미관측 — 측정 불가`**로 남긴다.
- [ ] 발광 기관은 정본 용어 **`발광기`**를 쓴다.
- [ ] 표본은 촉수 중간부·점착성이 강한 끝부분·피부 접촉부 가까운 표면 시료 등 실제 채집 부위를 구분한다.

## A06 — 6화 「미확인 대형 부유생물」

- [ ] **A06-1** 전날 초롱해파리 관찰을 길게 복습하지 않고, 새 연구 공백인 **전신 미관측/크기 측정 불가와 다음에는 더 멀리서 살아 있는 개체를 오래 보고 싶다는 계획**을 중심으로 둔다.
- [ ] 기록의 크기 항목은 **`전신 미관측 — 크기 측정 불가`**다.
- [ ] **A06-2** 공용 경고는 **`황색/노란 발광기, 긴 점착 촉수`** 등 멀리서 확인 가능한 특징과 실제 위험을 쓴다. `발광부`, `장대형 점착 촉수`로 후퇴하지 않는다.
- [ ] **최근 확정 R06-1** 선장 작별: 넬라가 첫 항해가 이 배라 좋았다고 감사하고, 선장은 세계 최초 『부유 해파리 도감』이 자기 배에서 시작했다는 사실을 기뻐한다.
- [ ] **최근 확정 R06-2** 선장은 도감이 나오면 한 권 사겠다고 하되, 해파리 내용보다 **책장에 꽂을 예쁜 표지**를 요구하는 농담을 한다.

## A07 — 7화 「사진사 찾을 것」

- [ ] **A07-1** 사진 한 장은 움직임의 **순서**가 아니라 **한 순간의 자세·겹침**을 남긴다. `지나가 버린 순서를 다시 확인`한다고 쓰지 않는다.
- [ ] **A07-2** `사진`을 처음 배운 직후에는 `노출 시간/노출` 같은 전문어를 먼저 쓰지 않는다. `얼마나 짧은 순간까지 선명하게 남길 수 있는지`처럼 평어로 질문하고, 사진술을 배운 뒤 전문어를 쓴다.
- [ ] 사진은 실제 겹침을 남기고 그림은 기부를 읽기 위해 겹침을 정리할 수 있다는 차이를 유지한다.

## A08 — 8화 「땅해파리」

- [ ] **A08-1** 외부 관찰만으로 `접촉면 비후`라고 조직학적 판정을 하지 않는다. `지지촉수 끝의 접촉면 — 몸 쪽 조직보다 두꺼움`, `표면이 두껍고 거칠다` 등 관찰 가능한 사실을 쓴다.
- [ ] 7화에서 배우기 전 사진 전문어를 소급해 쓰지 않는다.
- [ ] **최근 확정 R08-1** 마르톤의 훈디아 구술은 `훈디아 — 젤리다람쥐`로 출처를 분리한다.
- [ ] **최근 확정 R08-2** 주민에게 묻기 전 현재 마을의 이름은 `현지명 미확인`, 과수원 주민에게 직접 들은 뒤 `현재 마을 — 땅해파리`로 고친다.
- [ ] 지역 통칭과 생물학적 분류는 별개 자료로 기록한다.

## A09 — 9화 「사진사」

- [ ] **A09-1** 테오도어가 이미 설명한 `가공 태엽=배열 기록`, `굵은 태엽=탄성력 저장`을 서술자가 다시 복창하지 않는다. 위치를 확인하는 행동 정도만 남긴다.
- [ ] 배열 보존 매체와 실행 에너지원은 역할을 합치지 않는다. 은침의에서는 은판이 배열을 보존하고 넬라의 대사 에너지가 실행에 공급된다. 정시기는 배열 기록용 가공 태엽과 별도의 힘 저장용 태엽을 갖는다.
- [ ] **A09-2** 사진 한 장에서 `촉수 앞뒤가 계속 바뀐다`고 판정하지 않는다. 사진의 한 순간과 살아 움직이는 보글이를 함께 보고 앞뒤 순서가 고정되지 않음을 확인한다.
- [ ] **A09-3** `관찰 순간에 제가 골라 버린 세부`처럼 넓게 말하지 않는다. 그림을 정리하면서 **생략하거나 분리해 그린 부분**을 사진으로 재검토한다.
- [ ] 사진관 장부는 `영업장부`다.
- [ ] 테오도어의 용 지식은 직접 본 크기·속도·상처·야생 개체 위치 범위에 한정한다. 전함과의 전투력은 `군인에게 물으시오. 나는 사진사요.`로 경계를 친다.

## A10 — 10화 「사천 리브라」

### A10-A. `호구` 계약 복선 — 최근 최종 합의

- [ ] 파비아의 `호구`는 4,000리브라 보수가 크다는 뜻이 아니라 **넬라가 계약의 실제 책임 위험을 이해하지 못했을 가능성**을 찌른다.
- [ ] `넬라는 즉시 계약 내용을 설명했다`가 아니라 넬라가 보수 조건부터 들며 **변명**하는 기능을 드러낸다.
- [ ] 파비아는 **`보수 얘기하는 게 아니야.`**라고 끊는다.
- [ ] 이어 **`감정이 틀렸을 때 생기는 손해까지 감당할 각오는 물론 있겠지?`**라고 묻는다. `물론`을 유지한다.
- [ ] 넬라는 파비아와 반말로 **`해파리라면 내가 틀릴 리 없어.`**라고 답한다.
- [ ] `넬라는 조금도 망설이지 않았다` 같은 상투적 부정형 서술을 두지 않는다.
- [ ] 파비아는 **`그렇다면 됐어.`**라고 절차적 질문을 닫는다.
- [ ] 졸업식 콜백은 `다들 꺼리던 해도청이 네 눈에는 제일 좋은 자리였고, 네가 집어 간 덕분에 뒤 순번 애들은 선택지가 한 칸씩 좋아졌다`는 구조다.
- [ ] 넬라의 주관적 자신만만함은 `호구`를 반박하지 않고 오히려 강화한다.
- [ ] 최종 비꼼은 **`그렇게 자신만만한 걸 보니 호구라는 말은 취소할 필요가 없겠네. 네가 제일 자신 있을 때 계약서를 내밀면 되는 거였어. 대공도 아는 모양이고.`**의 기능과 수위를 유지한다.
- [ ] `파비아는 마르톤을 처음으로 조금 오래 바라봤다` 같은 기능 없는 응시 비트는 넣지 않는다.

### A10-B. 추심 법리 — 후속 정정이 기존 A10-2를 대체

- [ ] 추심은 법적으로 성립한 채무가 문서에만 남지 않고 실제 사람·재산에 이행되게 만드는 국가 강제집행 과정으로 설명한다.
- [ ] 사기·살인·해적질 등으로 큰 채무를 남기고 도주한 사람도 추적한다.
- [ ] 재산을 숨기면 찾아 **압류**하고, 필요하면 **환가**해 그 대금을 채무 이행에 충당한다.
- [ ] **일반 금전채무에서는 재산이 선순위다.** 재산을 모두 추심·환가하고도 채무가 남을 때에만 **신체를 최후담보로 압류**한다.
- [ ] 신체는 **강제노역의 노동을 환가해 잔여 채무의 이행에 충당**한다. 사람의 몸까지 담보가 되는 공포를 흐리지 않는다.
- [ ] `사람의 인도가 채무 내용이면 신병을 확보한다`는 식으로 일반 금전채무와 별도 인도 의무를 이 장면의 중심처럼 설명하지 않는다.

### A10-C. 모렌타·추심관 전투력 — 후속 정정 + 최근 최종 합의

- [ ] **A10-3 최종** 모렌타 후작은 `후국군`이라는 새 고유명보다 **군대/후작의 군대**를 동원해 추심에 격렬히 저항한다. 추심관들이 **그 저항을 제압**한 뒤 땅과 도시를 압류한다.
- [ ] `섬멸`은 전멸·대량 살상까지 정본화하는 단어이므로 현재 합의에서는 쓰지 않는다.
- [ ] 비연금술사 추심관의 존재를 독자에게 굳이 설명하지 않는다. 등장 추심관의 대부분이 연금술사인 상황에서 지면을 낭비하는 예외 설명을 앞세우지 않는다.
- [ ] **기본적으로 추심관 자체가 국가의 군사·강제력으로 이해되는 직군**임을 훼손하지 않는다.
- [ ] 중요한 차이는 `군사전력이냐 아니냐`가 아니라 **군사전력의 급**이다. 군대와 맞붙어 이길 만큼 강한 연금술사 추심관들이 존재한다.
- [ ] 그중 극소수는 **개인 한 명의 국외 배치 자체가 벡실리아가 그 사건 때문에 상대국과 전쟁까지 감수할 의지가 있는지 판단하게 만드는 위상**을 가진다.
- [ ] 이를 `주둔군을 옮긴다/대응 계획을 다시 짠다` 정도로 축소하지 않는다. 작가적 스케일은 항공모함 입항·전략핵 재배치에 준하는 **지위/신호 효과**다. 작품 안에서 현대 용어를 쓰라는 뜻은 아니다.
- [ ] 머릿수·개인별 실력차 분류는 이 장면의 논점이 아니므로 설명하지 않는다.
- [ ] **군인 시선 장면을 유지한다.** 글루트페스테 군인들이 파비아의 짙은 청색 외투와 은침의를 확인하고 서로 말을 주고받는다. 이것은 파비아가 전략급이라는 뜻이 아니라 외국 추심관 신분 자체가 경계 대상이라는 뜻이다.
- [ ] 마르톤은 `추심관들이 군대까지 제압한 거야?`처럼 전투가로서 실제 관심을 보인다.
- [ ] 테오도어는 군인들의 경계를 이해한 뒤 자기 구체 업무로 돌아와 **`담보물 번호부터 틀리지 않는 게 좋겠군.`** 같은 건조한 농담을 한다.
- [ ] 화말에서 담보 절차를 다시 요약하지 않고 열차가 산지로 들어가는 물리적 장면에서 끝낸다.

## A11 — 11화 「시조의 용」

- [ ] 명화 감정은 그림에서 직접 볼 수 있는 **선의 시작점·방향·겹침 순서·몸통 윤곽과의 접속·설정한 앞뒤 방향 안에서의 양립 여부**를 근거로 한다.

- [ ] **최근 확정 R11-1** 역 앞 조각은 외부에서 보이는 앞다리 네 개와 별도 날개를 말한다. 비교 근거는 넬라가 메디아나에서 본 **벨카리스 사진**의 부착 위치다. 넬라가 용을 직접 여러 마리 봤다고 쓰지 않는다.
- [ ] **최근 확정 R11-2** 마르톤 농담은 **`조각사는 팔다리 하나 붙일 때마다 돈을 더 받았나?`**로 유지한다.

- [ ] 정정 소견은 살아 있는 여러 개체의 지지촉수·겹주름·위협 자세와 명화 밑선의 대응을 근거로 한다.

## A16 — 16화 「구상」

- [ ] **A16-1 최종** 첫 설명은 채권단의 현재 요구가 핵심이다. **`채권단이 24,000리브라 상당의 적격 담보를 더 제공하거나 채무를 이행하라고 요구했어요. 제 첫 소견이 반영된 담보가치를 기준으로 이미 돈을 지급했는데, 제가 정정한 뒤에는 그 가치가 24,000리브라만큼 하락했다네요. 그래서 그 부족분에 대해서는 저도 대공과 연대채무를 진대요.`**의 인과를 유지한다. 대화에서는 이미 법률관계를 밝힌 뒤 `대공가` 반복을 줄여 `대공`을 자연스럽게 쓸 수 있다.
- [ ] 연대채무 정의와 5,000리브라 산수 전체를 다시 강의하지 않는다.
- [ ] 마르톤의 반발은 **`그래도 그 돈은 대공이 빌린 거잖아. 채권자들이 대공한테 받으면 되지. 왜 네가 같이 갚아?`**처럼 실제 부당감에서 나온다.
- [ ] 넬라는 파비아에게 방금 들은 논리를 자기 것처럼 사용한다. `채권자들도 똑같이 말할 수 있죠. 왜 자기들이 대공한테 받아야 하냐고요...`의 기능을 유지한다.
- [ ] 넬라가 먼저 **구상**을 꺼낸다.
- [ ] **A16-5** `구상?` → `제가 채권단에 먼저 이행한 만큼을 대공한테 돌려 달라고 청구하는 거예요.`처럼 정확한 의미를 한 번만 설명한다. 1,000리브라 예시는 삭제한다.
- [ ] **A16-6 핵심 콜백** 마르톤은 반드시 **`그럼 대공한테 어떻게 받아?`**에 도달한다. 넬라는 한 박자 늦게 **`……그 질문을 채권자들도 하고 있대요.`**라고 답한다. 15화 파비아↔넬라 대화의 역할 반전이 핵심이다.
- [ ] **A16-7 최종** 대공재판원 명칭을 반복 학습시키지 않는다. 테오도어는 `대공의 채무액 자체는 주둔군에게 중요하지 않지만, 대공의 주권을 무시한 외국의 직접 압류는 글루트페스테가 막을 것`이라고 설명한다. 동맹을 지키지 못하면 글루트페스테 영향권과 평판이 훼손되므로 전쟁까지 갈 수 있고, 벡실리아도 그 사실을 안다는 논리다.
- [ ] 이 주권 설명 뒤 서술자가 `그래서 채권단이 담보가를 따졌다`고 다시 요약하지 않는다. 최근 개고에서 삭제한 상태를 유지한다.
- [ ] **A16-8 최종 복선** 테오도어의 아버지 하인리히와 가족 연좌가 훗날 드러났을 때 재독 의미가 생기도록, 다음 두 대사를 유지한다.
  - `보기 드물게 정직한 사람이군.`
  - `정직한 사람은 종종 볼 수 있지. 하지만 그 뒤에 따라올 대가까지 혼자 감당하려는 정직한 사람은 별로 본 적이 없소.`
- [ ] `사진관도 오늘 밤 출항했소`, 단순 짐 불평 등으로 이 복선을 대체하지 않는다.
- [ ] **A16-9** 수정관 농담, 프로펠러 이상, 실해파리 촉수 제거, `실해파리 — 현장명`, 촉수 제거 뒤 같은 회전 위치의 걸림, `추정 지름`/직접 뽑은 촉수 길이, 포르도레행은 유지한다.

# D — 설정·전개·투고문서 동기화

> 원고 정본을 먼저 맞춘 뒤 필요한 사실만 동기화한다. 설정 문서를 장황한 메타 해설서로 만들지 않는다.

- [ ] **D01 모렌타/추심원/추심법/파비아 최소 동기화**: 모렌타 후작이 군대를 동원해 추심에 무력 저항했고 추심관들이 **그 저항을 제압**한 뒤 땅과 도시를 압류했다. `후국군`을 정본 고유명처럼 만들지 않는다.
- [ ] 같은 문서에서 추심관의 비연금술사 예외를 굳이 전면 설명하지 않는다. `모든 추심관이 연금술사는 아니지만` 같은 메타 분류를 서사 핵심처럼 반복하지 않는다.
- [ ] 같은 문서에서 전략적 위상을 `최상급 연금술사`라는 분류표 하나로 끝내거나 `주둔군 재배치` 정도로 축소하지 않는다. 강한 연금술사 추심관 중 일부는 **개인 국외 배치 자체가 전쟁 의지 신호가 될 만큼 큰 군사적 무게**를 가진다는 사실만 정확히 남긴다.
- [ ] 추심법/추심원/파비아의 일반 금전채무는 **재산 우선 → 압류·환가 → 부족 시 신체 최후담보 → 강제노역 노동 환가**로 통일한다. `신병 인도 자체가 일반 금전채무의 원래 채무형태`처럼 쓰지 않는다.
- [ ] **D02 에피소드05 테오도어 지식범위**: 벨카리스의 직접 관찰 범위만 답하고 군사적 전투력 평가는 모른다고 하는 9화 원고에 맞춘다.
- [ ] **D03 에피소드05 추심 기능**: 추심원의 본래 기능은 법적으로 성립한 채무를 실제로 이행시키는 국가 집행이며, 신용·보험·장거리 거래 발달은 결과다.
- [ ] **D04 에피소드07/15~16화 전개**: 15화의 실제 구상 원본 대화, 16화의 `구상? → 대공한테 어떻게 받아? → 그 질문을 채권자들도 하고 있대요` 역할 반전으로 맞춘다. 도주 전 공조 설명은 없고 도주 뒤 공조가 시작된다.
- [ ] **D05 투고 완결 시놉시스 정본화**: 현행 1~16화와 충돌하는 `들해파리 비교`, `테오도어 단순 거절`, `2급 연금술사 시험`, `루모 사건`, `시험 뒤 오르텔라행` 구버전을 제거한다. 사진 발견 → 테오도어의 500리브라 선급+수익지분 조건 → 다른 사진사 견적 비교 → 4,000리브라 오르텔라 감정으로 이어진다.
- [ ] 땅해파리 설정/에피소드04는 `현재 마을=땅해파리 / 훈디아=젤리다람쥐 / 지역 통칭과 분류 별도`로 유지한다.
- [ ] 기간 표기는 관련 에피소드/줄거리/시놉시스에서 **두 주쯤**으로 동기화한다.

- [ ] **G02** 각 대체문은 `실제 사건/대상 → 가장 좁은 정본 명사·동사 → 물리·법률·생물학적 관계 → 화자 지식·말투 → 그다음 반복·리듬·유머` 순으로 재검사한다.
- [ ] **G03** 바뀐 문장 주변 2~4문단을 다시 읽어 말투·물리 연속성·정보 공개 순서·리듬을 확인한다.
- [ ] **G04** 실제 부재·거절·오판·정정이 아닌데 서술자가 `~않았다`, `~아니다`로 안전하게 빠지는 습관을 줄인다.
- [ ] **G05** 행동·대사가 이미 보여 준 뜻을 서술자가 뒤에서 다시 요약·평가하지 않는다.
- [ ] **G06** `긴 묘사 → 한 줄 서술자 논평/농담` 패턴, 질문 자판기, 같은 수첩 동작, 같은 시선 비트가 반복되는지 화 전체에서 확인한다.
- [ ] **G07** 넬라는 관찰→가설→추가 시험/표본→수정 순서를 지키며, 모르는 항목은 빈칸·물음표·미확정으로 남긴다.
- [ ] **G08** 사진은 한 순간을 기록한다. 그림은 관찰자가 구조를 읽기 위해 겹침을 정리할 수 있다. 두 매체의 정보량을 전 화에서 뒤섞지 않는다.
- [ ] **G09** 넬라/파비아 반말, 마르톤의 짧고 상식적인 반발, 테오도어의 구체 업무·돈·장비에서 나오는 건조한 농담을 유지한다. 16화 정직 콜백은 억지 농담으로 평평하게 만들지 않는다.
- [ ] **G10** 설정·전개 동기화는 원고보다 덜 중요하며, 원고 사실을 짧게 지지하는 범위를 넘겨 메타 설명을 늘리지 않는다.
