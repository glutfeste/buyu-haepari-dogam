# 개고 반영 체크리스트

> 이 문서는 2026-08-18 대화에서 확정한 **구체적인 원고 수정사항과 그 뒤의 정정·추가 논의**를 다시 잃지 않기 위한 작업 추적표다.
> 
> 과거 대화에서 `A1~A14`, `A16-8` 등으로 부르던 번호별 원문 전체는 현재 대화 기록에 완전하게 남아 있지 않으므로, 번호를 억지로 재구성하지 않는다. 대신 당시 최종 장별 결정, 후속 정정, 최근 합의 사항을 **실제 원고에 요구되는 최종 상태**로 통합해 적는다. 앞으로 관련 문장을 바꿀 때는 이 파일도 같은 작업에서 갱신한다.
> 
> `[ ]` = 현재 main 재검증 전 / `[x]` = 현재 main에서 직접 확인 완료.

## 1화 — 해파리 당직

- [ ] 승선 거래는 `현금 대신`이 아니라 **`뱃삯 대신 해파리 당직`**으로 쓴다.
- [ ] 넬라가 관찰하는 자료는 풍향·먹이층 이동·개체 고도·섭식 행동 등 실제 항목으로 적고 `자료가 쌓였다` 같은 범용 요약으로 피하지 않는다.
- [ ] 졸업식에서 넬라가 남들이 꺼리는 해도청을 고르는 사건과 수석/차석 선택 순서를 보존한다.
- [ ] `신경계에 하강 신호를 기입했다`는 정본상 맞는 표현이므로 건드리지 않는다.

## 2화 — 처음 보는 해파리

- [ ] 작은 기낭실은 서로 `이어지는` 것이 아니라 **격막으로 나뉜 여러 방**으로 묘사한다.
- [ ] 손상 실험은 **막 일부가 찢어진 뒤 손상되지 않은 기낭실에 기체가 남는지**를 확인하는 실험으로 쓴다.
- [ ] `균사 이완`처럼 원인을 판정하는 말 대신 느슨해짐·부패·파열 등 관찰 가능한 상태를 쓴다.
- [ ] 기낭실의 분포·격막 분지·수축 때 변형 등 실제 관찰 항목을 구체적으로 쓴다.

## 3화 — 죽어 가는 섬

- [ ] 은판/배열 설명에서 **배열 보존 매체, 연산 주체(두뇌), 실행 에너지**를 하나의 기능처럼 합치지 않는다.
- [ ] 장갑 말리기 실습은 대상 결속·호출·배열·에너지 공급을 각 역할에 맞게 쓴다.
- [ ] 먹이 반응과 넬라 추적 행동을 분리해 관찰하고, 서술자가 행동의 상징이나 의미를 뒤에서 재설명하지 않는다.
- [ ] 기낭실 독립성은 관찰→가설→추가 확인 순서로 남긴다.

## 4화 — 돌아갈 곳 없는 해파리

- [ ] 현재 정본은 통과 대상으로 유지한다. 불필요한 개고로 장면을 흔들지 않는다.
- [ ] `보글이` 호명 반응의 원인은 단정하지 않고 물음표로 남긴다.
- [ ] 상처 회복은 같은 자세·축척의 재측정으로 기록한다.
- [ ] `초롱` 항로수첩은 위치·발광·신호 불응과 현재 관측의 일치를 확인하되 오래된 그림에서 보이지 않는 형태를 만들어내지 않는다.

## 5화 — 등불을 따라가지 말 것

- [ ] 초롱해파리 전투는 넬라가 실제로 본 **촉수 수축 순서와 연동 신호**를 기준으로 사역한다.
- [ ] 전신이 안개에 가렸다면 전체 크기를 추정하지 않는다. 필요하면 **`전신 미관측 — 측정 불가`**를 쓴다.
- [ ] 표본/시료는 촉수 중간부, 점착성이 강한 끝부분, 접촉 부위 표면 등 실제 채집 부위로 구분한다.
- [ ] 빛 기관은 `발광부`가 아니라 **`발광기`**로 쓴다.
- [ ] 마르톤의 큰 체격은 기준 없는 `비정상적 체격`이 아니라 관찰 가능한 비교로 제시한다.

## 6화 — 미확인 대형 부유생물

- [ ] 초롱해파리의 전신 크기는 계속 측정 불가로 유지한다.
- [ ] `장대형 점착 촉수` 같은 분류명처럼 들리는 표현 대신 **`긴 점착 촉수`**를 쓴다.
- [ ] 항로 경고는 **`황색 발광기, 긴 점착 촉수`** 등 멀리서 확인할 특징과 실제 위험을 먼저 쓴다.
- [ ] 선장과의 작별은 넬라가 첫 항해에 감사를 말하고, 선장이 세계 최초 도감이 자기 배에서 시작했다는 사실을 기뻐하는 장면으로 유지한다.
- [ ] 선장은 도감을 사겠다고 하되 해파리 내용보다 **책장에 꽂아 둘 예쁜 표지**를 요구하는 농담을 한다.

## 7화 — 사진사 찾을 것

- [ ] 넬라는 `사진`이라는 말을 배우기 전에는 사진 전문용어를 쓰지 않는다.
- [ ] 사진은 **한 순간의 겹침과 자세**를 남기는 매체이며 움직임의 연속 자체를 기록하지 않는다.
- [ ] 사진과 그림의 차이는 실제로 가려진 선·겹침·빈칸을 통해 보여 준다.
- [ ] 벤다발 경고문은 `황색 발광기, 긴 점착 촉수`를 유지한다.

## 8화 — 땅해파리

- [ ] 외부 관찰만으로 `접촉면 비후` 같은 조직학적 판정을 하지 않는다. **몸 쪽보다 표면이 두껍고 거칠다**처럼 관찰 가능한 차이로 쓴다.
- [ ] 이 시점까지 배우지 않은 사진 전문용어를 소급해 쓰지 않는다.
- [ ] 마르톤의 훈디아 구술은 **`훈디아 — 젤리다람쥐`**로 출처를 붙여 기록한다.
- [ ] 현재 마을 이름은 주민에게 묻기 전에는 **`현지명 미확인`**으로 둔다.
- [ ] 과수원 주민에게 직접 물은 뒤 **`현재 마을 — 땅해파리`**로 고친다.
- [ ] 지역 통칭과 생물학적 분류는 별개 자료로 기록한다.

## 9화 — 사진사

- [ ] 가공 태엽은 **배열을 기록/보존**하고, 굵은 태엽은 **탄성력을 저장**한다.
- [ ] 실행 에너지는 테오도어의 대사 에너지와 필요시 저장된 힘/외부 힘에서 공급된다. 기록 매체와 에너지원 역할을 합치지 않는다.
- [ ] 감광판은 대상에서 온 빛의 차이를 받아 상을 남기는 매체다.
- [ ] 보글이 사진 한 장은 한 순간만 남기므로, 앞뒤 촉수 순서 변화는 살아 있는 보글이를 반복 관찰해 확인한다.
- [ ] 사진관의 거래 기록은 **`영업장부`**라고 쓴다.

## 10화 — 사천 리브라

### 계약·호구 복선

- [ ] 파비아의 `호구`는 **4,000리브라 보수의 크기**를 비웃는 말이 아니라 넬라가 계약의 실제 책임 위험을 이해하지 못했을 가능성을 찌르는 말이다.
- [ ] `넬라는 즉시 계약 내용을 설명했다`가 아니라 넬라가 보수 조건을 들며 **변명하는 기능**이 드러나야 한다.
- [ ] 파비아는 **`보수 얘기하는 게 아니야.`**라고 넬라의 오해를 끊는다.
- [ ] 이어 **`감정이 틀렸을 때 생기는 손해까지 감당할 각오는 물론 있겠지?`**라고 묻는다.
- [ ] 넬라는 파비아와 반말을 쓰며 **`해파리라면 내가 틀릴 리 없어.`**라고 답한다. 이 부정은 서술자 도피가 아니라 넬라의 의도적인 오만/확신이므로 유지한다.
- [ ] 파비아는 **`그렇다면 됐어.`**라고 더 설명하지 않고 넘어간다. 훗날 연대채무를 다시 읽게 만드는 복선이어야 한다.
- [ ] 졸업식 콜백은 `남들이 예상하지 않은 계약`이 아니라 **다들 꺼리던 해도청을 넬라가 자신만만하게 좋은 자리라고 고른 사건**이다.
- [ ] 해도청 선택으로 뒤 순번 학생들의 선택지가 좋아졌다는 결과를 말한다.
- [ ] 현재 넬라의 자신만만함은 `호구` 평가를 반박하는 게 아니라 강화한다.
- [ ] 최종 비꼼은 **`그렇게 자신만만한 걸 보니 호구라는 말은 취소할 필요가 없겠네. 네가 제일 자신 있을 때 계약서를 내밀면 되는 거였어. 대공도 아는 모양이고.`**의 기능을 유지한다.
- [ ] `넬라는 조금도 망설이지 않았다` 같은 상투적 부정형 서술은 넣지 않는다.
- [ ] `파비아는 마르톤을 처음으로 조금 오래 바라봤다` 같은 기능 없는 응시 비트는 넣지 않는다.

### 추심 법리

- [ ] 추심은 법적으로 성립한 의무가 실제 재산·사람에게 도달하게 만드는 국가 강제집행 과정이다.
- [ ] 일반 금전채무에서는 **책임재산을 먼저 압류·환가**한다.
- [ ] 재산을 다 환가하고도 채무가 남을 때에만 **신체까지 최후담보로 압류**한다.
- [ ] 남은 채무는 **강제노역의 노동을 환가**해 이행시킨다. 공포가 흐려지지 않게 한다.
- [ ] 사람의 신병 인도/호송을 일반 금전채무의 독립적인 원래 채무 유형처럼 설명하지 않는다. 별도 법적 의무가 있는 예외와 집행절차를 구분한다.

### 모렌타·추심관 전투력

- [ ] 모렌타 후작은 **군대/후작의 군대**를 동원해 추심에 무력 저항했다. `후국군`은 쓰지 않는다.
- [ ] 벡실리아의 추심관들이 **그 저항을 제압**한 뒤 땅과 도시를 압류했다.
- [ ] 추심관 중에는 **군대와 맞붙어 이길 만큼 강한 연금술사**가 존재한다.
- [ ] 그중 일부는 개인 한 명의 국외 배치 자체가 **벡실리아가 필요하면 그 나라와 전쟁까지 치를 의사가 있다는 신호**로 받아들여질 만큼 위상이 높다.
- [ ] 이 위상을 `주둔군을 조금 옮긴다`, `대응 계획을 다시 짠다` 정도의 결과로 축소하지 않는다.
- [ ] `최상급 연금술사` 같은 분류표식이나 `모든 추심관이 연금술사는 아니지만` 같은 예외 설명을 본문에서 굳이 꺼내지 않는다.
- [ ] 마르톤이 군대를 제압한 추심관 이야기에 전투가로서 실제 관심을 보이게 한다.
- [ ] 글루트페스테 군인들이 파비아의 외투·은침의를 확인하고 서로 말을 주고받는 **군인 시선 장면을 유지한다.** 파비아가 전략급이라는 뜻으로 삭제하거나 축소하지 않는다.
- [ ] 테오도어는 군인들의 경계를 보고 추심관의 위상을 연결한 뒤 **`담보물 번호부터 틀리지 않는 게 좋겠군.`**이라고 자기 구체 업무로 농담한다.

## 11화 — 시조의 용

- [ ] 명화 감정은 그림에서 실제로 보이는 **선의 시작점, 방향, 겹침, 몸의 앞뒤 방향, 외형 배치**로 검증한다.
- [ ] 그림 한 장에서 내부조직·내부해부를 안다고 쓰지 않는다.
- [ ] 최근 해파리 그림/사진은 보조자료이며 원본 자체의 증거를 대신하지 않는다.
- [ ] 역 앞 용 조각의 앞다리 네 개+별도 날개는 외부에서 확인 가능한 부착 위치 차이로 설명한다.
- [ ] 마르톤의 농담은 **`조각사는 팔다리 하나 붙일 때마다 돈을 더 받았나?`**로 유지한다.

## 12화 — 정확한 평가

- [ ] 해파리설 검증은 외형의 선 시작점·겹침·방향으로 한정한다.
- [ ] 테오도어가 잔광 촬영을 제안할 수 있으나, 보존 담당자가 작품 상태와 검증 부족을 이유로 허가하지 않는다.
- [ ] 불허된 촬영을 실제로 시행한 것처럼 쓰지 않는다.
- [ ] `맞지 않는다`를 추상적으로 반복하기보다 어느 선의 시작점/방향이 어떤 가정과 양립하지 않는지 구체화한다.
- [ ] `해파리 해부학으로 성립하는 구조`처럼 그림이 보여 주는 범위를 넘는 표현 대신 **원본 선이 해파리의 외형 배치로 성립하는지**를 다룬다.
- [ ] 거래 기록은 `영업장부`를 쓴다.

## 13화 — 첫 배

- [ ] 넬라는 대공가 감정 보수에서 **500리브라를 테오도어에게 실제로 선급 지급**한다.
- [ ] 장기 동행 계약에는 사진 사용 범위와 출판 수익 지분을 명시한다.
- [ ] 테오도어의 장부는 `영업장부`다.
- [ ] 선박 구매는 가격·정비 기록·기낭·밸브·프로펠러 축·적재 여유·시험운항을 실제로 확인하는 전문 거래 장면으로 유지한다.
- [ ] `기록만 믿지 않고` 같은 불필요한 부정형 대신 확인 뒤 직접 검사하는 행동을 쓴다.

## 14화 — 노을해파리

- [ ] 산지 조사는 **두 주쯤** 이어진 것으로 통일한다.
- [ ] 지지촉수 보행→막 전개→부상/활강→착지의 실제 순서를 반복 관찰한다.
- [ ] 루케타 시각 차폐와 기관 출력 변화는 소리·진동·바람 변수를 분리하기 위한 관찰로 쓴다.
- [ ] 땅해파리와 산지 개체는 바로 같은 종으로 확정하지 않고 **근연 가능성**만 남긴다.
- [ ] 비교 항목은 `기관의 기부 위치 | 조직 연결 | 작동 순서`로 두되, **조직 연결은 외부 관찰만으로 확인할 수 없어 빈칸**으로 남긴다.
- [ ] 같은 증거 단계에서 `미확정`이라고 쓴 뒤 곧바로 `검증`했다고 뒤집지 않는다.
- [ ] 결정적 위협 자세에서 **위로 선 두 촉수↔그림의 뿔 선, 뒤로 휜 긴 촉수↔꼬리 선, 깊은 겹주름↔비늘 아래 붉은 밑선**을 실제 위치·방향으로 대응시킨다.
- [ ] 발견 의미를 서술자가 다시 요약하지 말고 넬라의 `제가 틀렸어요`가 관찰 뒤 직접 나오게 한다.

## 15화 — 정정 소견

- [ ] 산지 조사 기간은 **두 주쯤**으로 유지한다.
- [ ] 정정 소견은 살아 있는 여러 개체의 지지촉수·겹주름·위협 자세와 명화 밑선의 대응을 근거로 한다.
- [ ] 첫 소견과 정정 소견은 모두 당시 판단 기록으로 편철한다.
- [ ] 채권단은 첫 감정 반영 담보가로 이미 추가융자 자금을 지급했고, 정정 뒤 현재 계산으로 24,000리브라 담보부족을 청구한다.
- [ ] 연대채무는 **전문 감정을 반영한 담보가를 전제로 자금이 지급된 뒤 오감정으로 담보부족이 생긴 범위**에서 설명한다.
- [ ] 넬라의 `구상이 뭐야?` 질문과 파비아의 설명을 유지해 16화 콜백의 원본 장면을 보존한다.
- [ ] `그럼 대공한테 어떻게 받아?` → `그 질문을 채권자들도 하고 있지`의 회수 위험 농담을 유지한다.
- [ ] 파비아는 넬라가 도망치기 전에 국외 공조 절차를 강의하지 않는다.
- [ ] 자진출석한 넬라를 현재 허가된 현장 절차 안에서 **직접 신병 확보하려 손을 뻗고**, 넬라는 루케타를 켜 도주한다.
- [ ] 80년 계산은 **1490년**, 배와 현금을 넣으면 **1478년**으로 당기는 계산을 유지한다.

## 16화 — 구상

- [ ] 도주 직후 파비아는 항구에 **국외 추심공조 통지서 사본**을 들고 나타난다. 도주 후 공조가 시작된다는 순서를 유지한다.
- [ ] 15화의 연대채무 설명을 길게 재강의하지 않고, 마르톤의 상식적 반발을 통해 관계를 변형해 되짚는다.
- [ ] `구상?` → 넬라의 설명 → `그럼 대공한테 어떻게 받아?` → `그 질문을 채권자들도 하고 있대요`의 역할 반전을 유지한다.
- [ ] 넬라는 몇 시간 전 배운 법률용어를 자기 지식처럼 설명하는 코미디를 유지한다.
- [ ] 테오도어의 주권 설명은 **대공의 채무액과 별개로, 글루트페스테가 대공의 주권을 무시한 외국의 강제 압류를 막을 이유**를 말한다.
- [ ] 그 뒤 서술자가 `그래서 채권단이 담보를 따졌다`고 다시 해설하지 않는다.
- [ ] 마르톤의 정직 평가와 테오도어의 **`보기 드물게 정직한 사람이군`**, **`그 뒤에 따라올 대가까지 혼자 감당하려는 정직한 사람은 별로 본 적이 없소`**를 유지한다.
- [ ] 실해파리 촉수가 프로펠러 축에 감기는 장면과 축 정렬/마모 점검으로 이어지는 선박 수리 꼬리를 유지한다.
- [ ] 촉수 제거 뒤에도 같은 회전 위치에서 걸림이 남는다는 관찰을 유지한다.
- [ ] 작은 해파리 막은 `대략적인 크기`가 아니라 **추정 지름**, 직접 뽑은 촉수는 실제 길이로 기록한다.

## 전체 원고 반복 감사

- [ ] 현재 원고 1~16화에서 위 구체 항목을 전부 직접 대조한다. 과거 커밋 메시지나 기억만으로 통과시키지 않는다.
- [ ] 새 대체문은 의미가 맞는지만 보지 않고 주변 2~4문단을 다시 읽어 인물 말투·리듬·반복 패턴까지 확인한다.
- [ ] 실제 부재·거절·오판이 아닌데 `~않았다`, `~아니다`로 서술자가 안전하게 빠지는 문장을 줄인다.
- [ ] 이미 행동/대사가 보여 준 뜻을 서술자가 뒤에서 다시 요약·평가하지 않는다.
- [ ] 같은 `긴 묘사 → 한 줄 서술자 논평/농담`을 반복하지 않는다.
- [ ] 넬라의 연구는 관찰→가설→추가 표본/시험→수정 순서를 지키며, 모르는 항목은 빈칸·물음표·미확정으로 남긴다.
- [ ] 사진은 한 순간, 그림은 구조를 정리할 수 있는 매체라는 차이를 전 화에서 일관되게 지킨다.
- [ ] 넬라/파비아 반말, 넬라/마르톤의 말투, 테오도어의 건조한 실무 농담 등 인물별 말투를 유지한다.
- [ ] 테오도어의 농담은 구체적인 돈·장비·계약·기록 책임에서 나오게 하되, 16화 정직 콜백처럼 깊은 장면은 억지로 농담으로 평평하게 만들지 않는다.

## 설정·전개 동기화

- [ ] `땅해파리` 설정과 에피소드 04에 **현재 마을=땅해파리 / 훈디아=젤리다람쥐 / 지역 통칭과 분류 별도 기록**을 유지한다.
- [ ] 모렌타 관재령에서 `후국군`을 없애고 **군대/후작의 군대가 저항했고 추심관들이 제압**했다고 쓴다.
- [ ] 모렌타/추심원/파비아/추심법/에피소드05/줄거리/완결 시놉시스에서 `모든 추심관이 연금술사는 아니지만` 같은 예외 분류를 전면에 내세우지 않는다.
- [ ] 같은 문서들에서 `최상급 연금술사` 같은 분류형 표현으로 전략적 위상을 설명하지 않는다.
- [ ] 강한 추심관의 상한은 **군대를 이길 수 있는 연금술사**, 그중 일부는 **개인의 국외 배치가 전쟁 의지 신호로 읽히는 수준**으로 통일한다.
- [ ] 추심법/추심원/파비아에서 사람의 신병 확보·호송을 일반 금전채무의 원래 채무형태처럼 쓰지 않는다.
- [ ] 일반 금전채무의 집행은 **재산 우선→재산 환가→부족 시 신체 최후담보→강제노역 노동 환가**로 통일한다.
- [ ] 파비아는 넬라와 반말을 쓰고, 오르텔라에서 도주 전에는 국외 추적 절차를 설명하지 않으며 도주 후 공조가 시작된다.
- [ ] 줄거리·완결 시놉시스는 10화 호구 복선, 15~16화 연대채무/구상, 두 주쯤의 산지 조사, 도주 후 공조 순서와 충돌하지 않게 유지한다.
