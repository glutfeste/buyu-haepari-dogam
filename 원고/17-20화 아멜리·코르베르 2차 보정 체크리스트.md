# 17~20화 아멜리·코르베르 2차 보정 체크리스트

> 1차 문체 개고 이후 확정된 셀라리온·루케타·아멜리·코르베르 해석을 원고와 정본에 빠짐없이 반영하기 위한 **작업 기록**이다. `원고/집필 원칙.md`의 축약판이나 대체 판정표가 아니며, 완료 판정은 현재 원고의 각 수정단위에 적용 가능한 모든 `RULE:*`과 문체 작업 절차를 직접 대조해 내린다.

## 절대 기준

- [x] 셀라리온의 인과를 왜곡하지 않는다: **라비니우스가 납치된 딸을 찾기 위해 제작 → 셀라리온은 처음부터 원거리 대상을 탐지하는 오성 탐지기물이며 탈취된 대상을 전 세계 범위로 추적하는 탐탈을 고유 기능으로 지님 → 딸의 사망을 알게 된 뒤 대성소에 봉헌 → 대성소가 기존 탐탈을 도난 성물 회수에 활용 → 수백 년간 포르도레의 대성소 절도를 억제하는 유명한 억제력으로 자리 잡음.**
- [x] 셀라리온을 `위험 탐지 전용` 기물로 축소하지 않는다. 기본적으로 원거리 대상을 방위·거리·고도로 탐지하며 은폐된 함선도 기본 탐지에서 빠지지 않는다. 위험점 표시는 항해·전투 운용의 한 방식이다.
- [x] `탐탈`의 정확한 발동 조건은 외부에 알려지지 않았지만, **탈취된 대상을 끝까지 찾아낸다는 기능과 그 억제력은 어린이도 알 만큼 유명한 오래된 사실**로 취급한다.
- [x] 탐탈을 `대성소에서 훔친 물건만 찾는 기능`으로 축소하지 않는다.
- [x] 17화에서 마르톤이 정본의 라비니우스·루킬라 설화를 자기 지식으로 한 호흡에 설명한다. 독자 대신 단계별 질문을 받는 문답 구조를 만들지 않는다.
- [x] `탐탈`이라는 전문명은 필요하면 17화에서 한 번 정도 소개하고, 이후에는 기능과 사회적 효과를 생활 언어와 실제 행동으로 전달한다.
- [x] 루케타는 희귀한 삼성 기물이며 8,000리브라에 이르는 고가품이지만 일반 대중과 도적들이 이름·정확한 정체를 알고 있는 물건으로 쓰지 않는다.
- [x] 도적단에게 루케타는 우선 `배를 통째로 보이지 않게 하던 신기한 등불/기물`이다. 아멜리와 코르베르도 이름을 즉시 알아맞히지 않는다.
- [x] 루케타가 선체를 시야에서 지워도 **셀라리온에는 선체의 방위·거리·고도가 직접 표시된다.** 아멜리는 이 탐지값을 읽어 보이지 않는 배까지 들어간다. 바람·소리·냄새 같은 물리 흔적은 남지만 셀라리온 탐지의 필수 보조수단으로 만들지 않는다.
- [x] 아멜리는 차폐 안에서 옅은 경계와 중심 위치를 보고 이름 모르는 놋쇠 등이 은폐를 유지한다는 사실을 현장에서 파악한다.
- [x] 도적단은 원고·그림철·감광판뿐 아니라 **루케타도 실제로 훔친다.** 루케타를 끄는 순간 차폐가 풀려 배가 다시 드러나는 물리적 결과를 반영한다.
- [x] 17화 도난 목록, 18화 장물 분류, 20화 반환 목록에 루케타 도난·보관·반환을 연쇄 반영한다.
- [x] 베르나르의 직접화법은 아멜리에게도 일관된 높임말로 유지한다. 정본에 적힌 `바르게 쓰라고 당부했다` 같은 취지 요약을 반말 직접인용으로 잘못 고정하지 않는다.
- [x] 베르나르를 직접 찌른 사람이 아멜리가 아니라는 사실은 **작가가 인과와 책임을 왜곡하지 않기 위한 정본 가드레일**로만 유지한다. 이를 아멜리가 `나는 직접 찌르지 않았다`고 자기 책임을 정산하거나 면책하는 대사·내면으로 만들지 않는다.
- [x] 마르톤의 행동을 `일반 도적단이면 감당 가능하다`는 전력평가로 동기화하지 않는다. 넬라가 가야 하므로 먼저 앞에 서며, 상대와의 전력 차는 실제 싸움에서 드러난다.

## 아멜리와 넬라 — 원고를 통한 선행 인식

- [x] 18화에서 아멜리가 넬라의 도감 본문 원고와 관찰 그림철을 실제로 읽는 장면을 넣는다.
- [x] 아멜리는 도적단 안의 지적·교양 있는 인물이며 글과 전문 기록을 자연스럽게 읽는 사람으로 쓴다.
- [x] 생물학을 전부 이해하는 척하지 않되, 날짜·고도·기류·방위·재관찰·수정 흔적·실패 기록 등 자신이 알아볼 수 있는 요소를 통해 넬라의 집요함과 전문성을 읽는다.
- [x] 아멜리가 원고를 읽자마자 회개하거나 반환을 결심하지 않는다. 우선 넬라가 몇 년 동안 재관찰과 정정을 반복해 실제 기록을 쌓아 온 사람임을 알아보는 정도로 둔다.
- [x] 20화에서 넬라가 세계의 부유 해파리를 직접 보고 잘못된 분류와 비어 있는 생활사를 확인해 『부유 해파리 도감』을 완성하겠다고 말할 때, 아멜리가 이미 그 작업의 실물을 읽어 본 사람이라는 연결을 살린다.
- [x] 원고 반환은 베르나르 사건으로 인한 결별 결심이 직접 동력이며, 원고 독서는 피해자를 구체적인 사람으로 알게 한 보조선으로 유지한다.
- [x] 넬라의 승선 제안은 `수정관 자리가 비었다`는 파티 보직 충원이 아니다. 도감을 끝내려면 계속 대양과 낯선 공역을 건너야 하고, 넬라는 그 항해에 **아멜리의 탐지·항행 능력이 실제로 필요하다고 판단해 아멜리 개인을 선택한다.**

## 바스티앵 코르베르 — 정본 캐릭터 유지

- [x] 코르베르를 새로 `교양 있는 인물로 만든다`고 서술하거나 재설정하지 않는다. **원래부터 책을 많이 읽고 반어·논리를 구사하는 교양 있는 도적**이라는 정본을 장면에서 적극 활용한다.
- [x] 코르베르는 아멜리의 실제 양부에 가깝다. 어린 아멜리를 거두어 먹이고 씻기고 재우고, 교재·연습용 수정·고급 교육비까지 댄 실제 은혜와 애정을 보존한다.
- [x] 동시에 코르베르는 결국 도적이며 잔혹성과 소유욕을 가진다. 은혜를 `떠날 수 없는 채무`처럼 사용하는 문제를 살린다.
- [x] 코르베르의 의적/로빈후드/홍길동 컨셉은 **진지한 정치철학이 아니라 반쯤 진심이고 반쯤 멋 부리는 도적단 컨셉질**로 쓴다.
- [x] 이 컨셉에는 코미디가 있어야 한다. 도적단 구성원들도 익숙한 슬로건이나 두목의 폼 잡기로 받아들일 수 있다.
- [x] 그러나 아멜리를 실제로 거리에서 구하고 교육한 일이 있으므로 의적 컨셉이 완전히 빈말은 아니다.
- [x] 코르베르와 아멜리의 관계는 `가디언즈 오브 갤럭시`의 거칠고 소유욕 강하지만 실제 애정과 양육의 역사가 있는 양부-양녀 관계 같은 감각을 참고하되, 기존 정본과 세계관 안에서 독자적으로 구현한다.
- [x] 코르베르는 셀라리온을 `위험 탐지 기물`로만 이해하지 않는다. 도적단이 아멜리의 **원거리 탐지·항행 능력**에 실제로 의존해 왔다는 기존 관계를 유지한다.

## 18화 「공모 혐의」

### 셀라리온 앙상블과 억제력 해제
- [x] 베르나르 흉내와 도적단 코러스의 뮤지컬식 앙상블은 유지·강화한다.
- [x] 아멜리가 재연하는 베르나르의 말은 `무얼 찾고 있습니까?`, `가져가십시오`, `바르게 써 주십시오`처럼 한 높임말 체계 안에서 자연스럽게 이어지게 한다.
- [x] 대성소 약도가 등장할 때 도적들은 탐탈 기능을 새로 배우는 사람이 아니라 **이미 너무 잘 아는 포르도레 도적들**로 행동한다.
- [x] `탐탈`이라는 용어를 반복해 기술 강의하지 않는다.
- [x] 수백 년 동안 `성소 물건을 들고 튀어도 결국 찾아낸다`는 사실 때문에 접어 둔 약도를 다시 펴는 순간으로 만든다.
- [x] 셀라리온이 이제 성소에 없다는 사실이 오래 접어 둔 성소 약도를 실제 침입 약도로 되돌리는 행동으로 이어진다.

### 루케타 장물
- [x] `루케타 안의 배까지 찾아냈다며?`처럼 코르베르가 이름을 아는 대사를 제거한다.
- [x] 도적들은 `배를 지워 버리던 등`, `신기한 등불` 등 관찰 가능한 사실로 부른다.
- [x] 아멜리는 `셀라리온에는 선체가 그대로 잡혔고 방위·거리·고도를 맞춰 들어갔다`고 실제 탐지 과정을 말한다.
- [x] 코르베르는 교양과 장물 경험으로 세공·수정·희귀성을 알아보되 정확한 이름이나 기능 체계를 전지적으로 알아맞히지 않는다.
- [x] 코르베르는 값 모르는 장물상에게 헐값에 넘기지 말라고 별도로 보관시키며, 이것이 20화까지 루케타가 남아 있는 이유가 된다.

### 아멜리의 원고 독서
- [x] 코르베르가 원고를 실제로 몇 장 읽어 문서의 성격과 훈련된 글임을 알아보게 한다. 단순히 첫 장 보고 `돈이 안 된다`로 끝내지 않는다.
- [x] 코르베르는 문서의 종류·교육 수준·시장성을 읽고, 아멜리는 그 글을 쓴 넬라라는 사람에게 호기심을 갖는 차이를 만든다.
- [x] 아멜리는 다른 도적들이 장물을 만지는 동안 원고와 그림철을 몇 장 더 읽고, 어느 순간 남들보다 오래 붙들고 있는 모습이 자연스럽게 드러나게 한다.
- [x] 넬라가 실패한 관찰도 버리지 않고 재관찰해 앞선 수치를 고치는 집요한 연구자라는 인상을 아멜리가 받는다.
- [x] 이 독서는 감상문이나 독자용 인물 소개가 아니라 실제 종이·주석·그림·관찰 수치와 아멜리의 전문 관심을 통해 보여 준다.
