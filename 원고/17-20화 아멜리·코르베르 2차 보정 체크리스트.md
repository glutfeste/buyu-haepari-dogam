# 17~20화 아멜리·코르베르 2차 보정 체크리스트

> 1차 문체 개고 이후 확정된 셀라리온·루케타·아멜리·코르베르 해석을 원고와 정본에 빠짐없이 반영하기 위한 체크리스트다. 완료 시 `원고/집필 원칙.md`의 적용 가능한 모든 `RULE:*`을 다시 대조한다.

## 절대 기준

- [ ] 셀라리온의 인과를 왜곡하지 않는다: **라비니우스가 납치된 딸을 찾기 위해 제작 → 셀라리온은 처음부터 탈취된 대상을 전 세계 범위로 추적하는 고유 기능을 지님 → 딸의 사망을 알게 된 뒤 대성소에 봉헌 → 대성소가 기존 기능을 도난 성물 회수에 활용 → 수백 년간 포르도레의 대성소 절도를 억제하는 유명한 억제력으로 자리 잡음.**
- [ ] `탐탈`의 정확한 발동 조건은 외부에 알려지지 않았지만, **탈취된 대상을 끝까지 찾아낸다는 기능과 그 억제력은 어린이도 알 만큼 유명한 오래된 사실**로 취급한다.
- [ ] 탐탈을 `대성소에서 훔친 물건만 찾는 기능`으로 축소하지 않는다.
- [ ] 17화에서 마르톤이 정본의 라비니우스·루킬라 설화를 자기 지식으로 한 호흡에 설명한다. 독자 대신 단계별 질문을 받는 문답 구조를 만들지 않는다.
- [ ] `탐탈`이라는 전문명은 필요하면 17화에서 한 번 정도 소개하고, 이후에는 기능과 사회적 효과를 생활 언어로 전달한다.
- [ ] 루케타는 희귀한 삼성 기물이며 8,000리브라에 이르는 고가품이지만 일반 대중과 도적들이 이름·정확한 정체를 알고 있는 물건으로 쓰지 않는다.
- [ ] 도적단에게 루케타는 우선 `배를 통째로 보이지 않게 하던 신기한 등불/기물`이다. 아멜리와 코르베르도 이름을 즉시 알아맞히지 않는다.
- [ ] 아멜리는 셀라리온과 수정관 실력으로 루케타의 차폐 한가운데 숨은 배와 은폐 중심의 등불 위치를 특정한다.
- [ ] 도적단은 원고·그림철·감광판뿐 아니라 **루케타도 실제로 훔친다.** 루케타를 끄거나 들어 올리는 순간 차폐가 풀려 배가 다시 드러나는 물리적 결과를 반영한다.
- [ ] 17화 도난 목록, 18화 장물 분류, 20화 반환 목록에 루케타 도난·보관·반환을 연쇄 반영한다.

## 아멜리와 넬라 — 원고를 통한 선행 인식

- [ ] 18화에서 아멜리가 넬라의 도감 본문 원고와 관찰 그림철을 실제로 읽는 장면을 넣는다.
- [ ] 아멜리는 도적단 안의 지적·교양 있는 인물이며 글과 전문 기록을 자연스럽게 읽는 사람으로 쓴다.
- [ ] 생물학을 전부 이해하는 척하지 않되, 날짜·고도·기류·방위·수정 흔적·실패 기록 등 자신이 알아볼 수 있는 요소를 통해 넬라의 집요함과 전문성을 읽는다.
- [ ] 아멜리가 원고를 읽자마자 회개하거나 반환을 결심하지 않는다. 우선 `이 여자 정말 이것 하나에 미쳐 있구나`라는 호기심과 인식이 생기는 정도로 둔다.
- [ ] 20화에서 넬라가 부유 해파리 도감을 완성하겠다는 거대한 꿈을 말할 때, 아멜리가 이미 그 꿈의 실물을 읽어 본 사람이라는 연결을 살린다.
- [ ] 원고 반환은 베르나르 사건으로 인한 결별 결심이 직접 동력이며, 원고 독서는 피해자를 구체적인 사람으로 알게 한 보조선으로 유지한다.

## 바스티앵 코르베르 — 정본 캐릭터 유지

- [ ] 코르베르를 새로 `교양 있는 인물로 만든다`고 서술하거나 재설정하지 않는다. **원래부터 책을 많이 읽고 반어·논리를 구사하는 교양 있는 도적**이라는 정본을 장면에서 적극 활용한다.
- [ ] 코르베르는 아멜리의 실제 양부에 가깝다. 어린 아멜리를 거두어 먹이고 씻기고 재우고, 교재·연습용 수정·고급 교육비까지 댄 실제 은혜와 애정을 보존한다.
- [ ] 동시에 코르베르는 결국 도적이며 잔혹성과 소유욕을 가진다. 은혜를 `떠날 수 없는 채무`처럼 사용하는 문제를 살린다.
- [ ] 코르베르의 의적/로빈후드/홍길동 컨셉은 **진지한 정치철학이 아니라 반쯤 진심이고 반쯤 멋 부리는 도적단 컨셉질**로 쓴다.
- [ ] 이 컨셉에는 코미디가 있어야 한다. 도적단 구성원들도 익숙한 슬로건이나 두목의 폼 잡기로 받아들일 수 있다.
- [ ] 그러나 아멜리를 실제로 거리에서 구하고 교육한 일이 있으므로 의적 컨셉이 완전히 빈말은 아니다.
- [ ] 코르베르와 아멜리의 관계는 `가디언즈 오브 갤럭시`의 거칠고 소유욕 강하지만 실제 애정과 양육의 역사가 있는 양부-양녀 관계 같은 감각을 참고하되, 기존 정본과 세계관 안에서 독자적으로 구현한다.

## 17화 「도난 목록」

- [ ] 마르톤의 셀라리온 설명을 정본의 라비니우스·루킬라 설화 중심으로 재작성한다.
- [ ] 설명은 `셀라리온이면 모를 수 없다`는 마르톤의 자발적 발화로 이어지고, 넬라가 `왜?/그래서?/탐탈이 뭐야?` 식으로 독자 질문을 단계별로 대신하지 않는다.
- [ ] 라비니우스가 해적에게 납치된 딸을 찾으려고 평생 셀라리온을 만들었다는 제작 목적을 정확히 전달한다.
- [ ] 셀라리온이 처음부터 탈취된 대상을 세계 어디서든 추적하는 기능을 지녔다는 점을 정확히 전달한다.
- [ ] 완성 무렵 딸이 이미 죽었다는 소식을 듣고 셀라리온을 포르도레 대성소에 봉헌했다는 순서를 유지한다.
- [ ] 대성소가 그 기존 기능을 도난 성물 회수에 사용했고, 도둑들이 도망쳐도 결국 발각된다는 사실이 수백 년간 축적돼 대성소 절도의 강력한 억제력이 됐음을 설명한다.
- [ ] 독자는 17화 안에서 `왜 포르도레 도적들이 대성소를 건드리지 않았는지`를 이해할 수 있어야 한다.
- [ ] 루케타를 켜 배를 숨기는 기존 장면은 유지한다.
- [ ] 아멜리는 밖에서 차폐 흔적과 셀라리온의 정보로 보이지 않는 배의 위치를 특정한다.
- [ ] 도적들이 차폐 안으로 들어가도 루케타의 이름을 알지 못한다.
- [ ] 아멜리가 은폐의 중심에 있는 등불의 위치까지 찾아내며 그 물건이 차폐를 유지한다는 사실을 현장에서 파악한다.
- [ ] 루케타는 마지막 도난품 가운데 하나로 챙긴다. 들어 올리거나 끄는 순간 배 전체가 다시 시야에 나타나는 장면을 활용한다.
- [ ] 귀환한 넬라가 루케타의 부재를 즉시 인지한다.
- [ ] 도난 목록에 본문 원고, 관찰 그림철, 테오도어 감광판/장비와 함께 루케타를 포함한다.
- [ ] 루케타의 금전적 가치가 매우 크더라도 넬라에게 원고가 더 대체 불가능하다는 우선순위를 자연스럽게 보여 준다.

## 18화 「공모 혐의」

### 셀라리온 앙상블과 억제력 해제
- [ ] 베르나르 흉내와 도적단 코러스의 뮤지컬식 앙상블은 유지·강화한다.
- [ ] 대성소 약도가 등장할 때 도적들은 탐탈 기능을 새로 배우는 사람이 아니라 **이미 너무 잘 아는 포르도레 도적들**로 행동한다.
- [ ] `탐탈`이라는 용어를 반복해 기술 강의하지 않는다.
- [ ] 수백 년 동안 `성소 물건을 들고 튀어도 결국 찾아낸다`는 사실 때문에 접어 둔 약도를 다시 펴는 순간으로 만든다.
- [ ] 셀라리온이 이제 성소에 없다는 사실이 `오래된 억제력이 사라졌다`는 집단적 흥분으로 이어진다.

### 루케타 장물
- [ ] 현재의 `루케타 안의 배까지 찾아냈다며?`처럼 코르베르가 이름을 아는 대사를 제거한다.
- [ ] 도적들은 `배를 지워 버리던 등`, `신기한 등불` 등 관찰 가능한 사실로 부른다.
- [ ] 코르베르는 교양과 장물 경험으로 세공·수정·희귀성을 알아보되 정확한 이름이나 기능 체계를 전지적으로 알아맞히지 않는다.
- [ ] 코르베르는 값 모르는 장물상에게 헐값에 넘기지 말라고 별도로 보관시키며, 이것이 20화까지 루케타가 남아 있는 이유가 된다.

### 아멜리의 원고 독서
- [ ] 코르베르가 원고를 실제로 몇 장 읽어 문서의 성격과 훈련된 글임을 알아보게 한다. 단순히 첫 장 보고 `돈이 안 된다`로 끝내지 않는다.
- [ ] 코르베르는 문서의 종류·교육 수준·시장성을 읽고, 아멜리는 그 글을 쓴 넬라라는 사람에게 호기심을 갖는 차이를 만든다.
- [ ] 아멜리는 다른 도적들이 장물을 만지는 동안 원고와 그림철을 몇 장 더 읽고, 어느 순간 남들보다 오래 붙들고 있는 모습이 자연스럽게 드러나게 한다.
- [ ] 넬라가 실패와 수정 흔적까지 남기는 집요한 연구자라는 인상을 아멜리가 받는다.
- [ ] 이 독서는 감상문이나 독자용 인물 소개가 아니라 실제 종이·주석·그림·관찰 수치와 아멜리의 전문 관심을 통해 보여 준다.

### 코르베르의 의적 컨셉 씨앗
- [ ] 18화에서 코르베르가 `부자에게서 가져와 우리 같은 사람을 먹인다`는 식의 의적 컨셉을 가볍게 드러낼 기회를 만든다.
- [ ] 선언문처럼 장황하게 말하지 않고 장물 분류·간식·조직 농담 속에 넣는다.
- [ ] 부하들이 익숙하게 흘려듣거나 받아치는 반응으로 컨셉의 코미디를 살린다.
- [ ] `우리의 보물`은 애정 어린 양부의 칭찬이면서 훗날 소유욕으로 뒤집힐 수 있는 모티프로 유지한다.

## 19화 「뒷문」

- [ ] 베르나르의 두 번째 관용과 죽음이 아멜리 결별의 직접 원인이라는 중심을 흔들지 않는다.
- [ ] 넬라 원고 독서를 아멜리의 회심 원인으로 승격하지 않는다.
- [ ] 코르베르와의 1차 결별 대화에서 필요하면 `우리 가족/우리가 널 키웠다` 모티프를 살짝 예고하되 20화 최종 충돌의 힘을 빼앗지 않는다.
- [ ] 코르베르는 아멜리가 결국 돌아올 것이라 보는 양부의 오만과 가벼운 농담을 유지할 수 있다.

## 20화 「반환 목록」

### 도난품 반환
- [ ] 반환 물품에 루케타를 포함한다.
- [ ] 아멜리는 반환 시점까지 루케타라는 이름을 몰라도 된다.
- [ ] 넬라가 자기 물건을 보고 처음 `루케타`라고 부르면 아멜리가 이름을 처음 듣는 자연스러운 반응을 줄 수 있다.
- [ ] 루케타의 높은 가격과 희귀성은 장면을 압도하는 설명문이 아니라 넬라의 확인 행동·아멜리/코르베르의 장물 판단을 통해 드러낸다.
- [ ] 원고가 넬라에게는 루케타보다도 대체 불가능하다는 정서적 우선순위를 유지한다.

### 코르베르 vs 아멜리 — 의적 컨셉 리프라이즈
- [ ] 코르베르가 `부자를 털어 가난한 사람을 돕는 우리 약속/우리 방식`을 꺼내되, 지나치게 철학적·정치적인 진지함으로 끌어올리지 않는다.
- [ ] 아멜리가 `그래서 우리가 언제 가난한 사람을 도왔는데?`라는 취지로 의적 컨셉의 허술함을 찌른다.
- [ ] 코르베르는 코믹한 박자로 곧바로 **`너! 아멜리!`**라고 받아칠 수 있다.
- [ ] 그 웃기는 첫 박자에서 실제 양육의 기억으로 감정이 상승한다: 거리에서 데려옴, 씻김, 먹임, 잠자리, 책/교재, 연습용 수정, 교육비.
- [ ] 코르베르의 `내가 널 키웠다`는 자부심과 사랑은 사실로 인정한다.
- [ ] 아멜리는 `날 구한 건 맞아/고마운 것도 맞아`라는 사실을 부정하지 않는다.
- [ ] 아멜리의 반론은 `그 은혜가 다른 사람을 해칠 권리나 나를 평생 소유할 권리가 되지는 않는다`는 선택으로 간다.
- [ ] 18화에서 읽은 넬라 원고를 콜백으로 활용해 의적 컨셉의 맹점을 구체적인 피해자와 연결할 수 있다.
- [ ] 다만 코르베르를 논쟁에서 완전히 무능하게 만들지 않는다. 그는 자기 컨셉의 허술함보다 아멜리의 이탈과 배은망덕에 더 감정적으로 반응할 수 있다.
- [ ] `우리의 보물` 모티프가 18화의 애정 어린 칭찬에서 20화의 애정+소유욕으로 변주되게 한다.
- [ ] 필요하면 아멜리가 `보물`이 아니라 자기 이름을 가진 사람이라는 의미를 대사나 행동으로 드러내되, 정답 문장처럼 해설하지 않는다.

### 큰 꿈 듀엣
- [ ] 코르베르가 과거의 `우리`와 은혜를 들이민 뒤, 아멜리가 **이제 자기 이름으로 무엇이 될지**를 큰 꿈으로 선언하는 순서를 유지한다.
- [ ] 세계일주, 수정관으로서의 위업, 황실과 군중 앞에서 `아멜리 모렐`로 공개적으로 인정받겠다는 꿈을 구름장 하나로 축소하지 않는다.
- [ ] 넬라는 그 꿈을 비웃지 않고 자기 부유 해파리 도감이라는 불가능한 꿈을 같은 높이에서 내놓는다.
- [ ] 아멜리는 18화에서 넬라의 원고를 읽었기 때문에 넬라의 선언이 허풍이 아니라 이미 진행 중인 집요한 작업임을 알아볼 수 있다.
- [ ] 코르베르의 `과거의 은혜로 묶는 우리`와 넬라의 `미래를 함께 선택하는 우리`가 대비되게 한다.

## 정본 업데이트

- [ ] `부유해파리도감의 설정과 전개/설정/인물/일행/아멜리 모렐.md`에 원고 독서, 루케타 도난·반환, 코르베르 의적 컨셉과 실제 양육의 충돌을 반영한다.
- [ ] 아멜리 정본에 남은 `구름 수훈이 최종 목표` 식 옛 표현을 제거하고, 공개적인 황실 영예와 자기 이름으로 큰 위업을 이루는 꿈이 상위 목표임을 정렬한다.
- [ ] `부유해파리도감의 설정과 전개/설정/인물/포르도레 도적단/바스티앵 코르베르.md`에 로빈후드/의적 컨셉이 반쯤 폼 잡기이면서 아멜리 구조·양육 때문에 완전히 허언은 아니라는 톤을 반영한다.
- [ ] 코르베르 정본에서 아멜리와의 최종 대립을 `의적 컨셉 → 너! 아멜리! → 실제 양육의 열거 → 은혜와 소유의 충돌`로 갱신한다.
- [ ] `부유해파리도감의 설정과 전개/설정/기물/루케타.md`에 포르도레에서 도난당했다가 반환되는 사건을 추가한다.
- [ ] `부유해파리도감의 설정과 전개/설정/기물/셀라리온.md`는 기존 설화와 기능 정의를 훼손하지 않으며, 필요하면 대성소에서 수백 년간 억제력으로 작용했다는 사회적 효과를 더 명확히 한다.
- [ ] 관련 이야기/에피소드 정본에서 17~20화 사건 요약이 위 수정과 충돌하면 함께 갱신한다.

## 최종 감사

- [ ] 수정본 17→18→19→20을 연속으로 다시 읽는다.
- [ ] 셀라리온 설명이 제작 목적·기능·봉헌·대성소 활용·억제력을 하나의 잘못된 인과로 압축하지 않았는지 확인한다.
- [ ] 탐탈 기능의 적용 범위를 대성소 물건으로 축소한 문장이 없는지 확인한다.
- [ ] 루케타를 도적들이 이름으로 알고 있는 문장이 17~20화와 정본에 남아 있지 않은지 확인한다.
- [ ] 루케타 도난→장물 보관→반환의 물리적 연속성이 끊기지 않는지 확인한다.
- [ ] 18화 원고 독서가 아멜리의 지성과 넬라에 대한 선행 인식을 만들되 베르나르 아크를 침범하지 않는지 확인한다.
- [ ] 코르베르의 교양이 기존 정본의 성격으로 자연스럽게 작동하는지 확인한다.
- [ ] 코르베르의 의적 컨셉이 지나치게 엄숙한 정치철학이 되지 않고 코미디와 실제 양육의 진심을 동시에 갖는지 확인한다.
- [ ] 20화 논쟁에서 코르베르의 은혜가 거짓으로 지워지지 않고, 동시에 그 은혜가 아멜리의 자유에 대한 소유권으로 정당화되지 않는지 확인한다.
- [ ] 18화 `우리의 보물` → 20화 소유욕 → 아멜리의 자기 이름 → 넬라와 새 `우리`의 리프라이즈가 작동하는지 확인한다.

- [ ] 마지막으로 `원고/집필 원칙.md`의 적용 가능한 모든 `RULE:*`을 다시 대조한다. 하나라도 위반하면 체크리스트를 완료 처리하지 않는다.
