# 17~23화 문체 전면 개고 체크리스트

> 17~23화 문체 개고를 빠짐없이 수행하기 위한 작업 기록이다. `원고/집필 원칙.md`의 축약판이나 대체 판정표가 아니며, 해당 원칙의 모든 적용 가능한 `RULE:*`을 실제 원고의 각 수정단위에 직접 대조한다.

## 완료 원칙

- [x] 각 수정단위는 `가드레일 → 문체 생성 → 호흡 → 패턴 감사` 네 패스를 모두 거친다.
- [x] 일부 원칙만 충족한 수정단위를 완료로 처리하지 않는다.
- [x] 금지어 삭제·낱말 치환으로 끝내지 않고 필요하면 문장 순서, 문단 경계, 대사 길이, 행동과 소품 배치를 다시 설계한다.
- [x] 한 수정에서 일반적인 반복 문제가 드러나면 17~23화 전체에서 같은 기능의 변형을 전수 감사한다.
- [x] 아멜리의 의도적인 뮤지컬적·극적 발화는 그 자체를 결함으로 보지 않는다. 감정 상승과 인물 아크에 기여하면 오히려 강화한다.
- [x] 반대로 모든 인물이 같은 재치와 극성을 가져 아멜리의 목소리가 평준화되면 고친다.
- [x] 작가가 정본 확인용으로 지켜야 할 금지·면책 조건을 등장인물의 자기해설로 역수입하지 않는다.
- [x] 작가의 `전투 안전성`, `파티 보직`, `장면 기능` 같은 기획 요약을 인물 대사로 바꾸지 않는다.

## 아멜리 아크 절대 기준

- [x] 아멜리의 죄책감을 `베르나르를 흉내 내고 웃은 일`로 축소하지 않는다.
- [x] 핵심 인과를 유지한다: **베르나르의 믿음 → 아멜리의 실제 배반 → 그 배반을 안 베르나르의 두 번째 관용 → 그 관용을 실행하던 과정에서 베르나르가 살해됨 → 아멜리가 마지막 믿음을 다시 배반하지 않겠다고 결심함.**
- [x] 베르나르가 죽을 것을 알고 희생한 것처럼 쓰지 않는다. 죽음은 관용의 의도된 대가가 아니라 그 과정에서 발생한 결과다.
- [x] 정본상 아멜리가 베르나르를 직접 찌른 인물이 아니라는 사실은 작가용 인과 가드레일로만 유지하고, 아멜리가 `나는 찌르지 않았다`고 자기 책임을 정산하는 대사·내면으로 만들지 않는다.
- [x] 아멜리의 목표를 `구름장 하나 받기`로 축소하지 않는다. 구름은 두 왕관 훈장의 낮은 단계일 뿐 최종 목표의 천장이 아니다.
- [x] 아멜리는 `아멜리 모렐`이라는 이름으로 세계일주 출발을 정오대장에 등록하고, 항행 공적을 쌓아 복권을 받은 뒤 봉헌순행 수정관과 두 왕관 훈장의 별·달까지 노린다.
- [x] 17화의 황실 봉헌순행과 구름 수훈식에서 순행선·통제문·수훈 칙서·황제-왕의 대리인·약장·군중이라는 구체적 의례를 보존한다.
- [x] 20화에서 넬라는 아멜리의 목표를 현실적인 취업이나 낮은 훈장으로 줄이거나 비웃지 않는다. 자신은 세계의 부유 해파리를 직접 보고 분류와 생활사의 빈칸을 채워 『부유 해파리 도감』을 완성하겠다는 실제 계획을 말한다.
- [x] 20화 승선은 `빈 수정관 자리`의 충원이 아니다. 넬라는 도감을 끝낼 항해를 계속하려면 아멜리의 탐지·항행 능력이 실제로 필요하다고 판단해 `네가 필요해`라는 선택으로 손을 내민다.
- [x] 아멜리에게도 자기 이름으로 세계를 돌며 항행기록을 쌓을 배와 선장이 필요하다. 두 사람의 실제 장기 목표가 같은 항해에서 이어지게 한다.
- [x] 21화 정오대장의 `수정관 — 아멜리 모렐` 서명을 그 목표의 첫 공식 기록으로 기능하게 하되 서술자가 의미를 해설하지 않는다.

## 셀라리온·루케타 절대 기준

- [x] 셀라리온을 `위험 탐지 전용`으로 축소하지 않는다. 셀라리온은 원거리 대상을 방위·거리·고도로 읽는 탐지기물이며 은폐된 함선도 기본 탐지에서 빠지지 않는다.
- [x] 위험점 표시는 탐지기물의 항해·전투 운용 중 하나이며, 탐탈은 탈취된 대상을 전 세계 범위로 추적하는 별도 고유 기능이다.
- [x] 라비니우스가 딸 루킬라를 찾으려 제작함 → 완성 때 딸의 사망을 들음 → 대성소에 봉헌함 → 대성소가 이미 존재하던 탐탈을 수백 년간 활용함 → 절도 억제력이 됨의 인과를 바꾸지 않는다.
- [x] 탐탈의 정확한 발동 조건은 비밀이지만 `훔친 것을 끝까지 찾아낸다`는 효과와 수백 년의 실적은 포르도레의 유명한 상식이다.
- [x] 루케타는 시각 차폐 기물이며 일반인과 도적은 정확한 이름을 모른다. 아멜리는 20화 반환 때 넬라에게서 이름을 처음 듣는다.
- [x] 루케타로 선체가 보이지 않아도 셀라리온에는 선체가 직접 탐지된다. 바람·소리·냄새는 루케타가 지우지 못하는 물리 흔적이지 셀라리온 탐지를 성립시키는 필수 우회 수단이 아니다.
