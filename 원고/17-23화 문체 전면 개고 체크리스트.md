# 17~23화 문체 전면 개고 체크리스트

> 17~23화 문체 개고를 빠짐없이 수행하기 위한 작업 기준이다. `원고/집필 원칙.md`의 축약판이 아니며, 해당 원칙의 모든 적용 가능한 `RULE:*`을 마지막에 다시 대조해야 한다.

## 완료 원칙

- [ ] 각 수정단위는 `가드레일 → 문체 생성 → 호흡 → 패턴 감사` 네 패스를 모두 거친다.
- [ ] 일부 원칙만 충족한 수정단위를 완료로 처리하지 않는다.
- [ ] 금지어 삭제·낱말 치환으로 끝내지 않고 필요하면 문장 순서, 문단 경계, 대사 길이, 행동과 소품 배치를 다시 설계한다.
- [ ] 한 수정에서 일반적인 반복 문제가 드러나면 17~23화 전체에서 같은 기능의 변형을 전수 감사한다.
- [ ] 아멜리의 의도적인 뮤지컬적·극적 발화는 그 자체를 결함으로 보지 않는다. 감정 상승과 인물 아크에 기여하면 오히려 강화한다.
- [ ] 반대로 모든 인물이 같은 재치와 극성을 가져 아멜리의 목소리가 평준화되면 고친다.

## 아멜리 아크 절대 기준

- [ ] 아멜리의 죄책감을 `베르나르를 흉내 내고 웃은 일`로 축소하지 않는다.
- [ ] 핵심 인과를 유지한다: **베르나르의 믿음 → 아멜리의 실제 배반 → 그 배반을 안 베르나르의 두 번째 관용 → 그 관용을 실행하던 과정에서 베르나르가 살해됨 → 아멜리가 마지막 믿음을 다시 배반하지 않겠다고 결심함.**
- [ ] 베르나르가 죽을 것을 알고 희생한 것처럼 쓰지 않는다. 죽음은 관용의 의도된 대가가 아니라 그 과정에서 발생한 결과다.
- [ ] 아멜리가 객관적으로 `내가 베르나르를 죽였다`고 인과를 왜곡하지 않는다.
- [ ] 아멜리의 꿈을 `구름장 하나 받기`로 축소하지 않는다. 구름은 두 왕관 훈장의 낮은 단계일 뿐 최종 꿈의 천장이 아니다.
- [ ] 아멜리가 원하는 미래는 자기 이름을 숨기지 않고 세계를 돌며 수정관으로 큰 위업을 이루고, 훗날 황실과 군중 앞의 공개 의례에서 `아멜리 모렐`이라는 이름으로 영예를 받는 삶이다.
- [ ] 17화의 떠들썩한 황실 봉헌순행·공개 수훈식을 이 꿈의 먼 종착점 이미지로 보존한다.
- [ ] 20화에서 넬라는 그 꿈을 현실적인 목표로 낮추거나 비웃지 않는다. 자기 역시 `부유 해파리 도감`을 완성하겠다는 말도 안 되게 큰 꿈을 내놓고 둘이 함께 불가능한 위업을 이루자고 한다.
- [ ] 20화의 승선은 구조·자선·취업보다 **두 불가능한 꿈의 동맹**으로 먼저 느껴지게 한다.
- [ ] 21화 정오대장의 `수정관: 아멜리 모렐` 서명을 그 큰 꿈의 첫 공식 기록으로 기능하게 하되 서술자가 의미를 해설하지 않는다.

# 17화 「도난 목록」

## 17-1. 프로펠러/축 이상 첫 문단
- [ ] `프로펠러가 선체를 툭 쳤다`가 실제 기계적 사건을 흐리지 않도록 축의 걸림과 충격 전달을 적확하게 쓴다.
- [ ] `PROSE-SEMANTIC-PRECISION`, `LEXICAL-ORDER`, `KINETIC-VERBS`, `PHYSICAL-CONTINUITY`를 재검사한다.

## 17-2. 입항 유도
- [ ] `중앙 쪽을 가리키지 않았다 → 남쪽 수리선석으로 유도했다`의 부정형 중복을 걷고 실제 행동으로 바로 들어간다.
- [ ] `PROSE-POSITIVE-DIRECT`, `SCENE-NO-REDUNDANCY` 재검사.

## 17-3. 정비소 접수대의 사르노·셀라리온 잡담
- [ ] 현지인의 서로 다른 기억과 잘못된 숫자 정정은 살린다.
- [ ] 황실 봉헌순행과 공개 수훈식이 아멜리의 먼 꿈과 연결될 만큼 생생한 생활 풍경으로 남게 한다.
- [ ] 한 줄 질문→즉답→정정이 오래 연속되는 곳을 묶되 정비소의 시끌벅적함은 죽이지 않는다.
- [ ] 볼트 분류·수레 기름칠·접수철 등 업무 동작과 대화를 한 호흡에 묶는다.
- [ ] 넬라가 무엇을 듣고 무엇에 반응하는지 시점 렌즈를 보강한다.
- [ ] 정비소·축제·관료 절차가 한 공간에서 겹치는 건조한 위트를 대사 밖에도 배분한다.
- [ ] 정비공·접수 직원·마르톤의 대사 목소리를 구별한다.
- [ ] `DIALOGUE-NO-PINGPONG`, `DIALOGUE-IDIOLECT`, `THREE-LAYER`, `CLOSE-CHARACTER-LENS`, `WRY-NARRATION`, `RHYTHM-VARIATION` 재검사.

## 17-4. 아멜리의 회피
- [ ] 반걸음 회피 뒤 `정확했다`고 능숙함을 채점하지 않고 타이밍·거리·셀라리온의 점으로 보여 준다.
- [ ] `NO-NARRATOR-VERDICT`, `NO-DOUBLE-EXPLAIN` 재검사.

# 18화 「공모 혐의」

## 18-1. 도적단 이층방 — 아멜리 주도의 뮤지컬 앙상블
- [ ] 현실적인 잡담으로 낮추지 않는다. 아멜리가 이야기를 이끌고 패거리가 코러스처럼 감정을 증폭하는 구조를 강화한다.
- [ ] 베르나르 흉내, 셀라리온 자랑, 방 전체의 웃음과 움직임을 더 음악적·극적으로 조직한다.
- [ ] 주변 도적의 대사는 아멜리의 이야기를 밀거나 증폭해야 하며 아무나 할 수 있는 재치만 덧붙이는 대사는 정리한다.
- [ ] 아멜리가 아직 베르나르가 준 믿음의 의미를 모르고 셀라리온을 최고의 도둑질 도구를 얻은 승리담처럼 소비하는 상태를 살린다.
- [ ] `조롱했기 때문에 죄책감`이라는 인과를 만들지 않는다. 조롱은 그 믿음을 이해하지 못한 표면적 장면일 뿐이다.
- [ ] 술병·식탁·감광판 상자·약도·셀라리온이 감정의 박자를 운반하게 한다.
- [ ] 코르베르가 들어올 때 장면의 박자가 달라지게 한다.
- [ ] `DIALOGUE-IDIOLECT`, `DIALOGUE-MOTIVATED`, `HUMOR-TEXTURE`, `THREE-LAYER`, `OBJECT-FRICTION`, `RHYTHM-VARIATION` 재검사.

## 18-2. 코르베르 첫 등장
- [ ] `장물상과 흥정하고 돌아온 사람답게` 같은 후행 판정을 물리적 세부로 바꾼다.
- [ ] 마른 외투, 장갑 끝 먼지, 과자 봉투 등으로 깔끔함과 양육자적 면을 보여 준다.
- [ ] `NO-NARRATOR-VERDICT`, `INTRO-ACTION-FIRST` 재검사.

## 18-3. 원고 회수가 시간 싸움으로 바뀌는 순간
- [ ] `돈이 안 돼서 찾기 어렵다`에서 멈추지 않는다.
- [ ] 가치가 없기 때문에 도둑이 보관할 이유도 없어 버리거나 태우거나 포장지 등으로 소모할 수 있다는 위험을 넬라가 즉시 깨닫는다.
- [ ] 가능한 처분법은 장면에 맞는 몇 개만 구체적으로 고르고 백과식 열거는 피한다.
- [ ] 원고가 몇 년의 관찰 시간이며 같은 해파리·같은 날·같은 조건을 돈으로 복구할 수 없다는 연구자의 공포를 시점에 넣는다.
- [ ] `시간 싸움이다`라고 추상적으로 이름 붙이지 않고 넬라의 즉각적인 수색·질문·결정으로 시한을 보여 준다.
- [ ] 이 긴급성이 19~20화 회수 플롯까지 이어진다.
- [ ] `POSITIVE-DIRECT`, `CLOSE-CHARACTER-LENS`, `FREE-INDIRECT`, `OBJECT-FRICTION`, `CUMULATIVE-SENTENCE` 재검사.

## 18-4. 마지막 재침입 계획
- [ ] 첫 앙상블과 똑같은 짧은 박자를 반복하지 않고 다음 행동으로 넘어가는 낮은 위험감을 만든다.
- [ ] `우리 보물` 호칭이 캐치프레이즈가 아니라 관계와 소유욕을 드러내게 한다.
- [ ] 아멜리가 베르나르를 다시 만나면 무슨 말을 들을지 궁금해하는 상태는 유지한다.
- [ ] `PATTERN-FATIGUE`, `DIALOGUE-IDIOLECT`, `RHYTHM-ALTERNATION` 재검사.

# 19화 「뒷문」

## 19-1. 두 번째 관용
- [ ] `기분을 긁었다`, `이유는 붙지 않았다` 같은 추상명사+범용 물리동사를 적확한 표현으로 바꾼다.
- [ ] `첫 번째에는… / 지금은 달랐다`라는 판정형 대조 대신 구체 사실이 압력을 만들게 한다.
- [ ] 베르나르는 이제 아멜리의 이름, 코르베르 패거리, 셀라리온을 범죄에 쓴 사실을 알고 있으며 그럼에도 다시 놓아준다는 차이를 장면으로 보여 준다.
- [ ] 아멜리가 문밖에 자기 패거리가 기다린다고 일부러 알려 주는 행동을 `이래도 보내 주느냐`는 시험으로 살린다.
- [ ] 베르나르가 이유를 장황하게 설명하지 않고 제구물을 두고 가게 한 뒤 실제로 뒷문을 여는 행동으로 관용을 보여 준다.
- [ ] 공격은 베르나르가 예상한 희생이 아니라 도적들이 얼굴을 보인 뒤 벌인 돌발 살해로 유지한다.
- [ ] `NO-SAFE-GENERIC-FALLBACK`, `NATIVE-KOREAN-COLLOCATION`, `NO-FORCED-CONTRAST`, `NO-NARRATOR-VERDICT`, `OBJECT-FRICTION` 재검사.

## 19-2. 창고 결별 고백 — 극적 솔로 강화
- [ ] `돌아가서 그 말을 흉내 내고 웃었고`를 죄책감의 주요 논거에서 제거한다.
- [ ] 핵심을 `믿음을 받음 → 셀라리온을 범죄에 써서 배반함 → 베르나르가 배반을 알고도 다시 놓아줌 → 그 과정에서 베르나르가 죽음`으로 재구성한다.
- [ ] `내가 죽였다`라고 사실관계를 왜곡하지 않는다.
- [ ] 아멜리의 결심은 `그 사람이 마지막으로 나에게 한 일을 내가 또 배반해 아무것도 아니게 만들 수 없다`에 둔다.
- [ ] `보람 없이 죽었다`가 죽음의 목적론처럼 들리면 더 적확하게 고친다.
- [ ] 이 발화는 뮤지컬의 솔로 넘버처럼 크게 솟아도 된다. 감정이 커질수록 기억·인과·결심이 길어진 호흡 속에서 서로 밀어 올리게 한다.
- [ ] 셀라리온 모서리, 젖은 피 묻은 외투, 갈비뼈의 답답함 등 몸과 소품을 고백에 결속한다.
- [ ] `이름 숨기지 않겠다`, `쥐구멍/뒷문으로 다니지 않겠다`는 이미지를 살려 20화의 공개적 꿈으로 연결한다.
- [ ] `THREE-LAYER`, `FREE-INDIRECT`, `OBJECT-FRICTION`, `MICROPHYSIOLOGY`, `CUMULATIVE-SENTENCE`, `RHYTHM-VARIATION` 재검사.

# 20화 「반환 목록」

## 20-1. 함정 논쟁
- [ ] 테오도어의 경계와 마르톤의 자신감은 살리되 `함정이면 뭐 → 도적단 → 보장 못 함 → 열 명이면`식 즉답 연쇄를 압축한다.
- [ ] 마르톤의 자신감 일부를 검집·몸 준비 행동으로 옮긴다.
- [ ] 18-3의 원고 소멸 시한이 넬라가 논의를 끊고 즉시 가는 결정에 이어지게 한다.

## 20-2. 낮의 창고지대
- [ ] `낮의 창고지대는 밤보다 초라했다`를 제거하고 젖은 밧줄·폐유·비린내·물웅덩이로 바로 공간을 세운다.
- [ ] `NO-FORCED-CONTRAST`, `SPACE-SENSORY-CONTRAST` 재검사.

## 20-3. 용서 → 큰 꿈 → 두 불가능한 꿈의 듀엣
### 용서
- [ ] 넬라가 `돌려줬다/문을 열었다/칼 앞에서 물러나지 않았다`고 이미 본 행동을 서술로 다시 채점하지 않는다.
- [ ] 구겨진 원고, 그림철, 가방의 되찾은 무게, 아멜리가 서 있는 위치로 판단을 보여 준다.
- [ ] 넬라의 화가 완전히 사라진 성인군자식 용서로 만들지 않는다.
### 아멜리의 꿈
- [ ] `세계일주 + 언젠가 구름`으로 축소하지 않는다.
- [ ] 세계일주, 자기 이름, 수정관으로서의 큰 위업, 황실과 군중 앞의 공개적 영예를 하나의 터무니없이 큰 꿈으로 말하게 한다.
- [ ] 17화에서 본 떠들썩한 황실 의례의 중앙에 언젠가 `아멜리 모렐`로 서고 싶다는 욕망을 살린다.
- [ ] 도둑 전과 때문에 그 길이 거의 막혀 있다는 현실은 꿈의 크기를 강화하되, 여기서 행정 절차를 길게 계산하지 않는다.
- [ ] 아멜리의 발화는 어린애처럼 거창하고 뮤지컬적으로 크게 솟아도 된다. `내 이름으로`를 핵심으로 둔다.
### 넬라의 응답
- [ ] 아멜리의 꿈을 비웃거나 현실적인 목표로 낮추지 않는다.
- [ ] 넬라도 자기 꿈을 같은 높이로 꺼낸다: 세계의 부유 해파리를 직접 보고 기존에 없는 도감을 완성한다.
- [ ] `네 꿈이 말도 안 되면 내 꿈도 말도 안 된다. 모두가 안 된다고 하는 위업을 둘 다 해 보자`라는 정서로 이어 간다.
- [ ] 승선 제안은 자선·구제·단순 채용보다 두 불가능한 꿈의 동맹으로 먼저 느껴지게 한다.
- [ ] 수정관이 필요한 배와 세계일주할 배가 필요한 수정관이라는 실무 궁합은 감정적 핵심을 보조하게 한다.
### 감정·호흡
- [ ] 큰 감정을 낮추지 않는다. 울음도 허용하되 `입술→눈가→코→눈물` 같은 익숙한 신체반응을 연쇄하지 않는다.
- [ ] 셀라리온, 원고 가방, 열린 큰 문, 아멜리의 여행 가방에 감정을 나눠 싣는다.
- [ ] `우리 배에는 수정관이 필요하고. 너는…`처럼 하나의 논리를 인위적으로 자르지 않는다.
- [ ] 아멜리의 큰 꿈 → 넬라의 큰 꿈 → 공동 제안이 점층적으로 커지는 호흡을 만든다.
- [ ] 큰 문이 열리고 낮빛이 들어오는 마지막 이미지를 살리되 `당당한 삶으로 나갔다`고 해설하지 않는다.
- [ ] `NO-DOUBLE-EXPLAIN`, `NO-NARRATOR-VERDICT`, `NO-APHORISTIC-CHOP`, `THREE-LAYER`, `OBJECT-FRICTION`, `CUMULATIVE-SENTENCE` 재검사.

# 21화 「정오선」

## 21-1. 아멜리의 정비 점검
- [ ] `망치나 렌치를 잡지 않았다. 대신…`의 부정형 대비를 걷고 운항자로서 이상을 찾아내는 행동으로 바로 시작한다.
- [ ] 밸브·수정 거치대·적재 불균형을 짚는 전문성을 살린다.

## 21-2. 시험운항 성공 뒤 중복 논평
- [ ] `한 바퀴. / 두 바퀴.`는 짧음이 긴장을 만드는지 보고 유지한다.
- [ ] 진동이 없다는 물리 묘사와 인물 대사가 이미 성공을 전달한 뒤 `자기 몸을 때리지는 않았다`로 다시 닫지 않는다.
- [ ] `NO-DOUBLE-EXPLAIN`, `POSITIVE-DIRECT`, `LONG-SHORT-PUNCH` 재검사.

## 21-3. 정오대장 서명
- [ ] `아멜리 모렐` 서명을 19화의 실명 선언과 20화의 큰 꿈이 제도 안에서 처음 실현되는 행동으로 보존·강화한다.
- [ ] 베르나르의 빈 주교석, 황동선, 태양상, 사건 서류와 같은 배경을 이용하되 의미를 해설하지 않는다.
- [ ] 잉크 번짐 같은 작은 물리적 흔적으로 감정을 운반한다.

# 22화 「첫 대양」

## 22-1. 아멜리 운항 전문성
- [ ] `자랑할 때는 말이 많았지만 항로를 읽을 때에는…`이라는 서술자 비교평가를 제거한다.
- [ ] 식사보다 기류를 먼저 보고 셀라리온·항해도·숫자를 확인한 뒤 조종하는 행동으로 전문성을 보여 준다.
- [ ] 큰소리와 실제 실력이 동시에 존재하는 인물로 보이게 한다.

## 22-2. 위험한 해파리 뒤 넬라·마르톤
- [ ] `왜 / 아무것도 / 웃었잖아 / 안 웃었어`를 그대로 두지 않는다.
- [ ] 마르톤이 넬라의 연구 충동을 재미있어하는 관계 유머는 몸·표정·한 번의 발화로 압축한다.
- [ ] 17~20화의 비슷한 티키타카와 다른 박자를 만든다.

## 22-3. 미세 신체반응
- [ ] 22화의 `웃음을 삼키느라 입술을 깨물다`와 23화의 유사 동작을 겹치지 않게 변주한다.

# 23화 「손바닥 위의 항로」

## 23-1. 파비아 고속정 대치
- [ ] `입안이 마르고 혀끝에 금속 맛`, `목소리 끝이 갈라졌다` 같은 공포의 물리화는 살린다.
- [ ] 바로 뒤에서 `굳어 있던 목에서 나온 소리`라고 같은 감정을 다시 해설하지 않는다.
- [ ] 포신이 돌아간 직후 마르톤·테오도어의 농담과 아멜리의 웃음이 위협을 너무 빨리 희석하지 않도록 순서를 재배치한다.
- [ ] 유머 자체는 남기되 거리 확보·추적 확인 등 전문성과 공포가 먼저 작동하게 한다.
- [ ] 22화와 같은 `입술 깨물어 웃음 참기`는 피한다.
- [ ] `NO-DOUBLE-EXPLAIN`, `HUMOR-NOT-THREAT-DILUTION`, `PATTERN-FATIGUE` 재검사.

## 23-2. 아쿠아 알타 입항 문두
- [ ] 연속된 `아멜리는… / 아멜리는…` 중 하나의 문두를 입항표·부두 배치도·공간 변화로 옮긴다.
- [ ] `SUBJECT-OPENING-VARIATION` 재검사.

# 17~23화 전체 패턴 감사

## 대화
- [ ] 17 정비소 / 18 앙상블 / 18 말미 / 20 함정 논쟁 / 22 왜·아무것도 / 23 대치 후 농담을 서로 비교한다.
- [ ] 아멜리의 의도적 앙상블은 살리고, 단순 친밀감용 한 줄 탁구는 압축한다.
- [ ] 넬라·마르톤·테오도어·아멜리·코르베르의 대사 길이·존대·재치·반응 방식을 구별한다.

## 보여 준 뒤 다시 설명
- [ ] 17 아멜리 회피 평가 / 18 코르베르 `~답게` / 20 용서 근거 재열거 / 21 시험운항 후 논평 / 22 운항 전문성 비교 / 23 갈라진 목소리 해설을 고친다.
- [ ] 같은 기능의 다른 문장을 17~23화 전체에서 다시 찾는다.

## 부정형·억지 대조
- [ ] `A가 아니라 B`, `~하지 않았다`로 앞 내용을 재정리, 낮/밤, 처음/지금, 돈 됨/안 됨, 자랑/전문성을 전수 감사한다.
- [ ] 부정·대조 자체가 사건 정보가 아니면 실제 상태와 행동을 긍정문으로 쓴다.

## 범용 물리동사의 추상 전용
- [ ] `기분을 긁다`, `이유가 붙다` 및 `잡다/닫다/열다/쥐다/받치다/걸다`의 추상적 사용을 전수 감사한다.
- [ ] 실제 사건을 특정한 뒤 가장 적확한 술어로 쓴다.

## 미세 신체반응
- [ ] 입술 깨물기, 입 안쪽 씹기, 코 훔치기, 눈가 붉어짐, 눈물 차오름, 손 멈춤/굳음, 어깨 굳음, 웃음 삼키기의 반복을 전수 감사한다.
- [ ] 인물별 반응을 구별하고 일부 감정을 소품과 실제 행동으로 옮긴다.

## 장면·문체 생성
- [ ] 각 주요 장면에서 정확한 기본 질감 + 몸/소품/자유간접화법 + 톤/호흡의 필요한 층이 실제로 작동한다.
- [ ] 장소마다 포르도레 정비소·대성소·창고·대양·아쿠아 알타의 냄새·온도·소리·빛·촉감이 구별된다.
- [ ] 넬라 시점에는 연구·표본·돈·해파리라는 관심이 어휘 선택과 비유에 스민다.
- [ ] 아멜리 장면에는 필요할 때 의도적 극성과 음악적 상승을 살린다.
- [ ] 유머를 마지막 한 줄 펀치나 대사 티키타카에만 맡기지 않고 사물·절차·생활의 물성에도 배분한다.
- [ ] 자연스럽게 이어지는 시선·인과·판단은 중문·복문으로 묶고, 단문은 짧음 자체가 충격·결단·행동전환을 만들 때만 쓴다.
- [ ] 인접 2~4문단 → 장면 전체 → 화 전체 → 17~23화 전체의 네 범위에서 문두·구문·직유·농담·행동·장면 골격 반복을 감사한다.

# 최종 통합 검수

- [ ] 수정본 17~23화를 다시 처음부터 끝까지 읽는다.
- [ ] 18→19→20→21의 아멜리 감정곡선이 `들뜬 앙상블 → 배반을 알고도 받은 두 번째 관용과 파국 → 불가능한 꿈의 듀엣 → 자기 이름의 첫 공식 기록`으로 이어지는지 본다.
- [ ] 18화의 조롱이 죄책감의 핵심으로 확대되지 않았는지 본다.
- [ ] 19화가 베르나르의 죽음을 의도적 희생으로 왜곡하지 않는지 본다.
- [ ] 20화가 아멜리의 꿈을 구름장·취업·현실적인 첫 목표로 축소하지 않았는지 본다.
- [ ] 넬라가 자기 불가능한 꿈을 같은 높이에서 내놓고 함께 위업을 이루자고 하는지 본다.
- [ ] 21화의 `아멜리 모렐` 서명이 그 감정곡선을 조용히 이어받는지 본다.
- [ ] 22~23화에서 아멜리가 실제 항해 능력으로 20화의 큰 꿈을 즉시 행동으로 시작하는지 본다.
- [ ] 극적인 장면을 현실적인 말투로 낮추지 않았는지, 반대로 일상 전체를 절정처럼 만들어 대비를 죽이지 않았는지 본다.
- [ ] 마지막으로 각 대목에 적용 가능한 `원고/집필 원칙.md`의 `RULE:*` 전부를 대조한다. 하나라도 어긋난 수정단위는 완료 처리하지 않는다.
